# 认识画布

认识画布上的节点和连线，学会放入资料、选择内容并交给 Agent 继续制作。

画布是放置和制作内容的工作区。上传的图片、写下的文字、参考视频，以及 Agent 生成的结果，都会直接保留在画布上。

画布由****节点****和****连线****组成。节点保存具体内容，连线表示内容之间的关系。

完整画布支持桌面浏览器、iPad 和 Android 平板。手机会使用适合小屏幕的访问方式，不显示完整画布操作。

## 什么是节点？

画布上的每一份内容都是一个节点，例如：

- 一张上传的产品图；
- 一段 Brief 或脚本；
- 一张 Agent 生成的图片；
- 一个视频或音频结果；
- 一份 Agent 整理出的研究内容。

节点彼此独立。你可以选中一个节点查看内容，也可以同时选择多个节点交给 Agent 使用。生成新结果时，原始节点仍然保留在画布上。

## 什么是连线？

连线用来表示节点之间的关系。例如，从产品图继续生成广告画面时，产品图节点和新图片节点之间会形成关联；再从这张图片生成视频时，视频节点会继续连接在后面。

一个简单的关系可以是：

****产品图节点 + 指令节点 → 图片结果节点 → 视频结果节点****

沿着连线，你可以看到一个结果从哪些内容继续制作而来。连线帮助你理解关系；真正开始生成前，仍要检查 Agent 当前引用的是哪些节点。

## 你会用到的主要界面

### 中央画布

| 你想做什么 | 鼠标或触控板操作 | Mac 快捷键 |
| --- | --- | --- |
| 移动画布 | 滚动鼠标滚轮，或在触控板上双指滑动。也可以按住鼠标中键或右键拖动 | — |
| 放大或缩小 | 在触控板上双指捏合；使用鼠标时，按住 `⌘` 再滚动滚轮；也可以拖动画布左下角的缩放条 | `⌘ + =` 或 `⌘ + +` 放大；`⌘ + -` 缩小 |
| 选择一个节点 | 单击节点 | — |
| 选择多个节点 | 按住 `Shift` 逐个点击节点；也可以在画布空白处按住鼠标左键拖出选区 | `Shift + 点击` |
| 移动节点 | 把鼠标放到节点上，按住左键拖到新的位置 | — |
| 查看全部节点 | 点击左下角的“适应画布”按钮，画面会自动调整到可以看到全部节点的位置 | — |
| 使用小地图定位 | 点击左下角的小地图按钮。打开后，点击小地图中的目标位置可以直接跳转；拖动白色视口框可以连续移动当前画面 | — |

在画布空白处按住鼠标左键拖动会开始框选，不会移动画布。需要移动画布时，使用滚轮、触控板双指滑动，或按住鼠标中键、右键拖动。

输入光标位于 Agent 输入框、文字节点或其他文本编辑区域时，`⌘ +` 和 `⌘ -` 不会调整画布缩放。先点击画布空白处，再使用快捷键。

### Agent

在 Agent 中描述任务，并把需要使用的节点交给它。Agent 会读取你明确选中的内容，并把新的结果继续放回画布。

引用节点时顺手写清用途：

使用 @产品正面标准图 保持瓶身结构和标签位置；@暖色灯光参考 只参考光线，不参考其中的产品。先给我 3 个构图方向，不要直接生成视频。

复制

这样 Agent 才能区分产品标准和风格参考，不会把两张图当成相同用途。

### 添加菜单

添加菜单可以创建文字、图片、视频和音频节点，也可以上传本地文件。加入后，内容会直接成为画布节点。

| 入口 | 鼠标操作 | Mac 触控板操作 |
| --- | --- | --- |
| 左侧添加按钮 | 点击画布左侧工具栏顶部的 `+`，再点击需要创建的内容类型 | 移动指针到 `+`，轻点触控板，再轻点需要创建的内容类型 |
| 在指定位置快速添加 | 在画布空白处双击，添加入口会出现在双击的位置 | 把指针移到目标位置，连续轻点或按下触控板两次 |
| 使用右键菜单 | 在画布空白处点击鼠标右键，再选择新建内容或添加工具 | 在空白处双指点按触控板，再从菜单中选择需要的内容 |

需要上传电脑里的图片、视频、音频或文档时，点击 `+`，选择****上传****，再从文件选择器中选取文件。上传完成后，文件会作为新节点出现在当前画布中。

菜单中显示的内容会根据当前账户和画布权限变化。某个选项无法点击或没有显示时，以页面上的提示为准。

### 素材库与模板

- ****素材库****保存以后还会使用的角色、场景、风格、声音或物品；
- ****主体库****把同一个人物、产品或角色的多份参考资料整理在一起，供支持的视频模型直接引用；
- ****模板****保存可以重复使用的节点和连线结构。

## 第一次进入画布，建议这样开始

1. 把一张图片或一份资料放到画布，它会成为一个节点；
2. 选中节点，打开 Agent，并说明要基于这份内容完成什么；
3. 如果选择了多份内容，分别告诉 Agent 每个节点的用途；
4. Agent 完成任务后，在画布上查看新生成的节点；
5. 沿着连线检查新结果使用了哪些输入；
6. 拖动节点整理位置，保持当前要使用的内容容易找到。

第一次不需要搭建复杂结构。先完成一次“选择节点 → 交给 Agent → 得到新节点”的操作，就能理解画布怎样工作。

## 保存状态

画布会显示保存或同步状态。关闭页面前，如果仍显示保存中、离线或同步失败，请等待恢复，并确认网络连接。

## 完成标准

- 知道画布上的内容会以节点保存；
- 可以选择一个或多个节点交给 Agent；
- 能沿着连线找到结果使用的输入；
- Agent 生成的新内容已经出现在画布上；
- 页面显示最近修改已经保存。
