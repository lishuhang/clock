# 认识 TapNow Agent

了解 TapNow Agent 如何读取上下文、调度 Apps、管理画布内容，并配合你完成创意开发与制作。

TapNow Agent 负责理解任务、组织上下文和推进执行。它可以读取你在对话中提供的文字、附件和画布节点，整理交付目标与限制，再根据任务选择合适的 App。

Agent 生成或整理的内容会进入画布，后续对话可以继续引用。你可以随时限定执行范围，例如只分析资料、先写脚本、先建立分镜，或在生成前暂停等待确认。

## 一次任务怎样推进？

一次常见的任务包含以下阶段：

1. ****读取上下文****：读取你明确提供的 Brief、附件和画布节点；
2. ****确认任务****：整理交付物、受众、规格、截止时间和限制条件；
3. ****制定步骤****：说明准备调用的 App、预计生成的内容和需要确认的位置；
4. ****执行任务****：生成、编辑或整理内容，并将结果写入画布；
5. ****定向修改****：根据反馈修改指定节点，保留已经确认的部分；
6. ****整理交付****：检查规格、整理版本并准备最终文件。

信息不足或存在冲突时，Agent 会先提出问题。涉及较高消耗、发布或外部同步时，建议使用手动确认模式。

## 选择 GPT-6 Astra

在 Agent 的模型选择器中看到 ****GPT-6 Astra**** 时，可以用它处理文字和图片输入。它不支持音频或视频输入；需要分析这类内容时，请改用当前页面提供的其他模型。发送任务前检查输入节点类型，避免把不支持的音频或视频连接到 Astra。

## Agent 可以帮你做什么？

### 整理资料与要求

将 Brief、会议纪要、参考素材和画布节点加入上下文后，Agent 可以汇总已确认要求、标记相互冲突的信息，并列出仍需补充的问题。

### 开发创意

在生成前阶段，Agent 可以通过[头脑风暴](https://docs.tapnow.ai/zh/docs/agent/find-ideas-with-brainstorm)发展脚本、角色、世界观、广告方案和视觉方向，并将确认的信息整理到画布。

### 执行制作任务

方向和规格明确后，Agent 可以写脚本、拆分镜头、创建图片或视频任务、编辑已有内容，并批量处理规格相同的素材。

### 修改与交付

你可以让 Agent 按包装一致性、文字准确性、镜头节奏和交付规格逐项检查结果。它也可以整理版本、生成交付说明，并通过可用 App 同步内容。

## 你、Agent 和画布分别负责什么？

| 参与者 | 负责内容 |
| --- | --- |
| ****你**** | 设定目标、选择方向、确认审美与品牌细节、检查素材权利和最终文件 |
| ****Agent**** | 读取资料、整理信息、拆解步骤、调用 Apps、执行和修改任务 |
| ****画布**** | 保存 Brief、参考素材、已确认标准、过程结果和交付文件 |

反馈时请同时说明需要修改和需要保留的部分。例如：“保留产品位置和包装，只把背景换成雨后的露营地。”

审美方向、品牌准确性、素材权利和最终发布由你确认。

## 什么时候该用哪种方式？

| 当前状态 | 建议 |
| --- | --- |
| 只有主题或模糊想法 | 使用[头脑风暴](https://docs.tapnow.ai/zh/docs/agent/find-ideas-with-brainstorm)开发方向 |
| 目标、参考和规格明确 | 直接发送任务指令 |
| 只需调整一个结果 | 选中对应节点并说明修改范围 |
| 需要比较模型或参数 | 在画布创建生成节点并手动设置 |
| 涉及较高消耗、发送或发布 | 使用手动确认模式 |

## 怎样写清任务？

任务指令建议包含五类信息：

1. ****交付物****：需要完成什么；
2. ****受众****：内容给谁看；
3. ****上下文****：使用哪些附件和画布节点；
4. ****限制条件****：比例、时长、语言，以及必须保持的产品或角色特征；
5. ****执行边界****：先给方案、先确认消耗，或直接生成。

## 哪些内容需要你确认？

以下内容应在生成或发布前确认：

- 哪个创意方向最符合品牌和受众；
- 哪些参考素材可以合法使用；
- 模型、生成数量、分辨率和预计消耗；
- 人物、文字、商标和产品细节是否准确；
- 最终文件是否满足发布平台的规格。

## 结果偏离时怎么办？

先确定发生偏差的节点和具体问题：

1. 选中出现偏差的节点；
2. 指出本轮只需修正的问题；
3. 列出必须保留的内容；
4. 引用作为标准的附件或节点；
5. 先生成一个候选，确认后再继续。

## 第一次使用建议

- 不确定模型时，先使用模型选择器中的 ****Auto****。
- 复杂任务优先使用 ****手动确认****。
- 将关键参考节点明确加入上下文。
- 一轮修改只处理一个主要问题。
- 确认少量候选后再批量生成。

## 怎样确认 Agent 已理解任务？

- 交付物、受众和规格已经写清；
- 使用的附件与画布节点正确；
- 计划调用的 App、生成数量和停止位置明确；
- 修改范围与验收标准明确；
- 下一步需要你确认的内容明确。
