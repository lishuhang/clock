# 认识 TapNow Creative OS

了解 Agent、Apps 和画布如何在同一套 AI 创作操作系统中完成真实创作。

创作很少从一个空白 Prompt 开始。

真实创作通常从一场会议、一份客户 Brief、一组产品图或一版已有脚本开始。接下来，团队要找方向、写脚本、生成视觉、修图、剪视频，再把结果发回工作群或团队文档。

我们把这条完整链路做成了 TapNow Creative OS。

Creative OS 是承载创作工作的操作系统。Agent 负责理解目标和调度任务；Apps 服务具体场景；画布保存创作资料、制作过程和最终结果。

## Creative OS 是怎么工作的？

| 部分 | 在创作里负责什么 |
| --- | --- |
| ****Agent**** | 读取目标和上下文，整理信息、拆解任务并调用 Apps |
| ****Apps**** | 服务具体创作与工作场景，执行生成、编辑、协作和资料读取 |
| ****画布**** | 保存 Brief、参考素材、制作过程、不同版本和交付文件 |

Agent 不需要把所有能力都装进一次对话。它会根据当前任务选择合适的 App，并使用画布中的创作上下文继续工作。

## 什么是 Apps？

Apps 是 Creative OS 用来扩展更多业务场景的应用。它们补全画布之外的工作空间和个性化能力，让 Agent 可以直接使用你已有的工具和资料。

例如，连接 Slack App 后，Agent 可以获取 Slack 对话中的上下文；连接 Lark（飞书）App 后，可以读取飞书文档或群聊内容，不需要你反复复制和粘贴资料。

TapNow 官方也提供了一系列创作 Apps，帮助用户生成、编辑和完成内容。

## 如何从已有工作开始？

一项产品广告可以这样推进：

1. 使用 Lark App 读取客户 Brief 和最新会议纪要；
2. 使用 Notion App 读取品牌规范、产品信息和已有脚本；
3. Agent 整理必须保留的内容，并建立脚本、镜头和制作任务；
4. 在画布中调用生成、修图和剪辑 Apps 完成内容；
5. 将画布链接、预览或最终文件同步回团队的工作平台。

资料进入画布后会一直留在上下文中。你不需要每次打开新对话都重新粘贴 Brief，也不用在多个软件之间手动搬运文件。

## 为什么是操作系统？

创作流程会持续变化。团队会使用新的模型、新的协作平台，也会形成自己的工作方法。如果每增加一种能力就重做一套工作流，工作会越来越分散。

Creative OS 提供稳定的 Agent、画布和权限体系，再通过 Apps 扩展具体场景。新 App 接入后，可以直接使用当前画布的资料和结果，也能和其他 Apps 连续工作。

对创作者来说，这意味着：

- 可以直接从会议、Brief、知识库和已有素材开始；
- 不用先把真实需求改写成一段“完美 Prompt”；
- 不用在多个软件之间重复上传、下载和整理文件；
- 不用每次都重新向 Agent 解释创作背景；
- 团队可以沿着同一份资料、画布和结果继续协作；
- 从创意开发到制作交付，过程和文件都留在同一张画布中。

Creative OS 将创作工具、团队协作、工作资料和 AI 能力放进同一个系统，让创作者把时间留给方向判断和作品本身。
