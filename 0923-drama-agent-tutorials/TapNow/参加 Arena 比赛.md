# 参加 Arena 比赛

阅读活动章程，根据活动类型完成报名、发布作品和投稿。

Arena 是 TapNow 社区里的主题活动。每个活动都有自己的开放时间、创作主题、投稿数量和作品要求。

开始制作前先打开活动详情页。页面上的活动章程决定这次可以提交什么、什么时候提交，以及是否需要先报名。

![Arena 活动页面](_files_参加 Arena 比赛/image_1.gif)

## 先确认活动类型

Arena 活动通常有两种参加方式：

| 页面显示 | 怎样参加 |
| --- | --- |
| ****立即投稿**** | 活动开放后可以直接选择已有作品，或发布新作品并投稿 |
| ****立即报名**** | 先填写报名信息；报名通过并且活动开始后，才能投稿 |

报名制活动提交资料后，按钮会显示 ****审核中****。通过后，如果活动还没开始，会显示 ****等待开始****；活动开放后，按钮会变为可投稿状态。

## 先读活动章程

进入活动页后，确认以下信息：

- 活动开始时间和投稿截止时间；
- 创作主题、可选赛道和评审说明；
- 视频时长等作品要求；
- 每位创作者最多可以提交多少件作品；
- 是否需要先报名，以及报名需要填写哪些资料；
- 奖励、结果公布方式和其他活动条款。

不同 Arena 的要求可能不同。活动详情页和页面展示的章程是本次活动的准确信息。

## 怎样参加？

1. 打开想参加的 Arena 活动页；
2. 读完活动介绍和章程；
3. 如果页面显示 ****立即报名****，先提交报名资料并等待审核；
4. 活动开放后，点击 ****立即投稿****；
5. 选择已经发布到 TapTV 的作品，或在当前窗口发布新作品；
6. 如果活动设置了赛道，选择与作品最匹配的赛道；
7. 确认作品和活动信息，然后提交。

提交后返回活动页，查看自己的投稿记录。能够在活动页看到作品和投稿状态，才表示这次投稿已经进入活动流程。

## 为什么现在不能投稿？

| 页面状态 | 代表什么 |
| --- | --- |
| ****即将开始**** | 活动还没有开放投稿 |
| ****审核中**** | 报名资料正在审核 |
| ****等待开始**** | 报名已经通过，等待活动开放 |
| ****已满**** | 已达到本次活动允许的投稿数量 |
| ****投稿截止**** | 活动已经进入评审，不再接受新作品 |
| ****活动结束**** | 本次活动已经结束 |

如果页面提示视频时长或作品信息不符合要求，按照当前活动章程调整后再提交。报名未通过时，可以在活动仍允许报名的情况下修改资料并重新报名。
