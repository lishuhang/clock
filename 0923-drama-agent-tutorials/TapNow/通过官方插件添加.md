# 通过官方插件添加

从 Agent 自己的官方市场安装 TapNow，授权一次后即可在对话中生成图片和视频，不需要手动填写连接地址。

部分 Agent 的官方市场里已经上架了 TapNow，从市场安装后即可使用，不需要手动填写连接地址。目前上架的是 WorkBuddy、千问办公和豆包工作。

## WorkBuddy

WorkBuddy 里的 TapNow 有两种形态，按需要选择：

| 形态 | 适合什么情况 |
| --- | --- |
| ****TapNow 连接器**** | 你已经有自己的工作流程，只需要 TapNow 的生成能力 |
| ****TapNow 创意工作室专家**** | 希望有现成的创作流程指引，由专家带着完成整套制作 |

1. 打开 WorkBuddy 的市场，搜索 `TapNow`。
2. 选择连接器或专家，点击安装。安装专家时会自动带上所需的连接器。
3. 首次使用时完成一次 TapNow 账户授权。

## 千问办公

千问办公里的 TapNow 以****专家套件****形式提供，名为「TapNow 创意工作室」。套件里带着 TapNow 的连接器和一组创作技能，安装后可以直接在对话中使用。

1. 打开千问办公的****应用市场****，搜索 `TapNow`。
2. 打开「TapNow 创意工作室」，查看它包含的技能与适用场景。
3. 选择安装。套件会一并安装 TapNow 连接器。
4. 首次使用时，按提示完成一次 TapNow 账户授权。授权在浏览器中完成，用你的 TapNow 账户登录并同意。

安装后，在对话中可以直接描述创作需求，也可以使用套件自带的技能，例如精品单图、电商组图、配图套件。

## 豆包工作

豆包工作里的 TapNow 以****插件****形式提供，名为「TapNow 创意工作室」。插件带着 TapNow 的连接器，安装后可以直接在对话中使用。

1. 打开豆包工作的****插件市场****，搜索 `TapNow`。
2. 打开「TapNow 创意工作室」，查看它的能力与适用场景。
3. 选择安装。插件会一并安装 TapNow 连接器。
4. 首次使用时，按提示完成一次 TapNow 账户授权。授权在浏览器中完成，用你的 TapNow 账户登录并同意。

安装后，在对话中直接描述创作需求即可。

## 确认可以用了

在对话中发一句：

检查 TapNow 是否已连接，列一下我最近的 TapNow 画布。

复制

返回画布列表就说明可以用了。

## 开始使用

用 TapNow 给这份季度汇报做一套章节配图，一共五个章节，风格统一，图内不要出现文字。做完把画布链接发我。

复制

成品会进入你的 TapNow 画布，回复里带画布链接，点开可以回 TapNow 继续精修或导出。

## 常见问题

****市场里搜不到 TapNow。**** 上架条目会按账户、工作空间和版本开放，以你当前账户可见的市场为准。

****安装了但对话里用不了。**** 先确认授权是否完成。部分平台会在首次调用时才弹出授权提示，完成授权后重新发送一次任务即可。

****生成一直没有结果。**** 图片通常十几秒到半分钟，视频需要更久。可以让 Agent 再查一次结果，或者打开画布链接直接在 TapNow 里看进度。

****提示额度不足。**** 生成使用的是你 TapNow 账户的 Tapies，在 TapNow 的[管理 Tapies 与套餐](../account/tapies-and-plans.md)中查看余额。

****想换一个 TapNow 团队。**** 在 TapNow 中切换到目标团队后，回到平台重新授权一次。成品会落在重新授权时选择的团队里。
