# 添加自定义连接器

在支持自定义 MCP 连接器的 Agent 中填入 TapNow 的连接地址并完成一次授权，之后可以直接在对话里生成图片和视频。

如果你用的 Agent 支持自己填写 MCP 连接器，按下面的步骤添加一次 TapNow。完成授权后，你就能在对话中直接让它调用 TapNow 生成内容。整个过程只需要做一次。

## 你的 MCP 连接器地址

下面是你当前所用 TapNow 对应的连接地址，复制它。

| 你使用的 TapNow | MCP 连接器地址 |
| --- | --- |
| `app.tapnow.ai` | `https://mcp.tapnow.ai/api/agent-gateway/mcp/general/mcp` |
| `app.tapnow.media` | `https://mcp.tapnow.media/api/agent-gateway/mcp/general/mcp` |

## Claude

1. 打开 Claude 的设置（****Settings****），进入连接器（****Connectors****）。
2. 选择添加自定义连接器（****Add custom connector****）。
3. 名称填 `TapNow`，地址填上面的连接地址。
4. 保存后点击这个连接器的连接（****Connect****），浏览器会打开 TapNow 的授权页面。
5. 用你的 TapNow 账户登录并同意授权。页面提示成功后回到 Claude。

或可以直接复制提示词到 Claude 对话中粘贴使用。

复制提示词

## ChatGPT

1. 打开 ChatGPT 的设置（****Settings****），进入连接器（****Connectors****）。
2. 选择添加连接器，填入名称 `TapNow` 和上面的连接地址。
3. 保存后完成一次浏览器授权，用你的 TapNow 账户登录并同意。

或可以直接复制提示词到 ChatGPT 对话中粘贴使用。

复制提示词

Claude 和 ChatGPT 的菜单位置会随版本和界面语言变化，以你看到的界面为准。找不到入口时，在设置里搜索 Connectors。

## 你使用的 Agent

1. 打开 Agent 的设置（****Settings****），进入连接器（****Connectors****）。
2. 选择添加自定义连接器（****Add custom connector****）。
3. 名称填 `TapNow`，地址填上面的连接地址。
4. 保存后点击这个连接器的连接（****Connect****），浏览器会打开 TapNow 的授权页面。
5. 用你的 TapNow 账户登录并同意授权。页面提示成功后回到 Agent。

或可以直接复制提示词到 Agent 对话中粘贴使用。

复制提示词

Agent 的菜单位置会随版本和界面语言变化，以你看到的界面为准。找不到入口时，在设置里搜索 Connectors。

## 确认连上了

回到对话，发一句：

检查一下 TapNow 连接器是否可用，列一下我最近的 TapNow 画布。

复制

如果返回了你的画布列表，说明已经连上。如果提示找不到 TapNow 工具，回到设置确认连接器状态是「已连接」。

## 开始使用

连上之后，用平时说话的方式提要求就行。写清楚三件事效果最好：要什么、给什么参考、用在哪里。

用 TapNow 生成一张产品主图：白色陶瓷马克杯放在浅木色桌面上，右侧有自然光，背景干净。比例 1:1，用于电商主图。生成完把画布链接给我。

复制

要做成套内容时，先把产品图拖进对话，再把用途说清楚，Agent 会选择合适的生成方式：

用我刚发的产品图，用 TapNow 做一套电商组图，包含白底图、场景图和细节图，平台是小红书。做完告诉我每张的用途。

## 授权与账户

授权只针对你登录的那个 TapNow 账户和团队。生成消耗的是这个账户的 Tapies，产出也进入这个账户的画布。

如果你在多个团队之间切换，授权时选择的团队决定了成品落在哪里。需要换团队时，在 TapNow 中切换后重新授权一次。

不要把连接地址当作密钥分享

连接地址本身不包含你的身份信息，但授权后的连接器可以用你的账户生成内容并消耗 Tapies。不要在共享设备上保留已授权的连接器。

## 常见问题

****授权页面打不开。**** 检查浏览器是否拦截了弹出窗口。部分客户端会在新标签页打开授权页，被拦截时没有任何提示。

****提示找不到 TapNow 的工具。**** 先确认连接器状态是「已连接」；再确认地址填的是上面那条连接地址，而不是 TapNow 的网站地址。

****生成一直没有结果。**** 图片通常十几秒到半分钟，视频需要更久。可以让 Agent 再查一次结果，或者打开画布链接直接在 TapNow 里看进度。

****提示额度不足。**** 生成使用的是你 TapNow 账户的 Tapies，在 TapNow 的[管理 Tapies 与套餐](https://docs.tapnow.ai/zh/docs/account/manage-tapies-and-plans)中查看余额。
