# 创作文本与 3D

在画布上创建和整理文本，并进入 3D 世界工作空间。

文本节点适合保存脚本、说明和提示词。3D 世界节点可以打开独立工作空间，用来摆放内容并调整相机位置。

## 文本节点

文本节点适合放脚本、镜头说明、提示词和其他需要反复查看的文字。

### 开始创建文本

1. 点击画布左侧工具栏的 `+`；
2. 选择文本节点；
3. 单击节点并输入内容；
4. 选中文字，使用 Toolbar 设置标题、正文、粗体、斜体或列表；
5. 单击画布空白处，退出文字编辑。

也可以双击画布空白处，再选择文本节点。

### 文本 Toolbar 核心能力

| Toolbar 能力 | 适合什么时候使用 | 操作后会发生什么 |
| --- | --- | --- |
| ****标题 1、标题 2、标题 3**** | 整理脚本或长文本的层级 | 将当前段落改为对应级别的标题 |
| ****正文**** | 把标题恢复为普通段落 | 将当前段落改为正文 |
| ****粗体、斜体**** | 标出重点内容 | 改变选中文字的样式 |
| ****项目符号、编号列表**** | 整理步骤、要求或镜头清单 | 将当前段落变成列表 |
| ****分割线**** | 分开两部分内容 | 在当前文字位置插入分割线 |
| ****背景颜色**** | 在画布上区分不同文本节点 | 修改当前文本节点的背景颜色 |
| ****复制全部**** | 需要把整段文字粘贴到其他位置 | 复制节点内的全部文字 |
| ****保存到素材库**** | 这份文本之后还会重复使用 | 打开保存面板 |
| ****全屏**** | 需要集中阅读或编辑长文本 | 打开文本全屏编辑 |

这里介绍的是文本 Toolbar 中最常用的能力。实际显示的按钮会根据节点状态和产品版本变化。

## 先预览 3D 内容

画布上有 3D 资产、全景图或 3D 场景时，可以先查看内容，再决定是否进入片场：

1. 选中对应节点，在 Toolbar 中点击 ****预览****；
2. 查看全景图时拖动鼠标环视；查看 3D 物品时拖动旋转；查看 3D 场景时拖动环视，或使用 `W`、`A`、`S`、`D` 移动；
3. 需要保留当前取景时，点击 ****打开取景器****，再点击 ****拍摄****。照片会直接成为画布上的图片节点；
4. 需要继续布景时，点击 ****在 3D 片场中使用****。TapNow 会创建独立片场并打开它，再继续添加角色、3D 物品、摄像机，或调整环境和光照。

只读画布可以查看预览，但不能拍摄，也不能从预览创建 3D 片场。预览、拍摄当前画面和进入片场本身不会调用生成模型；在片场中使用生成能力时，才会按页面显示的模型和参数消耗 Tapies。

## 3D 世界

3D 世界用于搭建空间、摆放内容和调整相机位置。你可以先在 3D 工作空间中确定构图和机位，再把结果带回画布继续制作。

### 开始创建一个 3D 世界

1. 点击画布左侧工具栏的 `+`；
2. 选择 ****3D****；
3. 画布上出现 3D 世界节点后，单击节点；
4. 点击 Toolbar 中的 ****进入片场****；
5. 在工作空间中添加或调整当前页面支持的环境、内容和相机；
6. 完成后退出工作空间，回到画布。

如果已经有 `.glb` 文件，可以在空白 3D 世界节点的 Toolbar 中选择 ****上传****，把 3D 资产导入工作空间。

3D 世界入口可能根据账户权限显示为锁定状态，以页面中的开放提示为准。进入空白工作空间不会自动开始模型生成；在工作空间中调用生成能力时，会按照页面显示的模型和参数正常消耗 Tapies。

### 3D 世界节点核心能力

| Toolbar 能力 | 适合什么时候使用 | 操作后会发生什么 |
| --- | --- | --- |
| ****进入片场**** | 需要调整空间、内容或相机 | 打开当前节点对应的 3D 工作空间 |
| ****上传**** | 已经有 `.glb` 资产，需要放进 3D 世界 | 从电脑选择文件并导入当前节点 |

这里只介绍 3D 世界节点在画布上的核心入口。进入 3D 工作空间后，可使用的控制项会根据当前内容、账户权限和产品版本变化。
