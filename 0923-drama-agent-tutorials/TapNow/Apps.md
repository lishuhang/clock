# Apps

选择适合当前场景的 App，让 Agent 完成创作任务或读取团队工作资料。

Apps 为 Agent 增加具体能力。有些 Apps 用来生成、修图或剪辑视频；有些 Apps 连接 Lark（飞书）、Notion、Slack 等工作平台。

Agent 负责理解目标和上下文，App 负责执行一类明确工作。这样，同一张画布可以连接新的创作方法和团队工具，不需要反复搬运资料或重新解释背景。

## Agent 和 App 是怎样配合的？

以一支产品广告为例：

1. Agent 读取你加入的目标和画布节点；
2. Lark App 读取指定会议纪要和客户反馈；
3. Agent 整理最新要求，并让你确认冲突信息；
4. AI 生成 App 产出静态候选；
5. 专业修图 App 修正产品和画面细节；
6. 视频剪辑 App 整理镜头与输出；
7. 工作 App 把预览或项目链接同步回团队。

App 每次使用的都是当前项目明确提供的上下文。同一张产品图、脚本和品牌要求可以沿着不同 Apps 继续工作，不需要反复下载、上传和解释。

## 常见的 Apps 有哪两类？

| 类型 | 适合做什么 | 示例 |
| --- | --- | --- |
| ****创作 Apps**** | 在画布中生成或编辑内容 | AI 生成、专业修图、视频剪辑 |
| ****工作 Apps**** | 读取或同步真实项目资料 | Lark（飞书）、Notion、Slack |

实际可用的 Apps 取决于当前账户、工作空间和版本，以产品内显示的列表为准。

## 从应用市场开始

1. 打开侧边栏中的****应用市场****。
2. 在****应用****和****官方技能****之间切换，或搜索应用和用例。
3. 打开一个条目的****查看详情****，先看它能帮你完成什么、需要提供哪些资料，以及适用范围与限制。
4. 选择****在对话中试用****，把用例提示词带入 Agent；也可以选择****添加到对话****，先把这个应用加入当前任务。
5. 补充具体的参考素材、账号范围和交付要求，再发送任务。检查 Agent 返回的结果，必要时继续提出定向修改。

部分应用首次使用时需要连接外部工具。应用市场入口和其中的条目会根据账户、工作空间和版本开放；如果侧边栏没有显示****应用市场****，请以当前账户可见的入口为准。

## 怎样使用一个 App？

1. 打开 Apps 入口；
2. 选择当前任务需要的 App；
3. 如果 App 需要访问外部服务，点击 Agent 对话中显示的授权入口并完成账户授权；
4. 回到 Agent，说明要使用哪个 App 和哪些资料；
5. 先检查 Agent 读取的来源和准备执行的动作，再确认运行。

授权完成后回到同一段 Agent 对话，原任务会保留。继续发送任务，或按对话中的提示恢复执行即可。

例如：

使用 Lark App 读取这次客户会议纪要和最新 Brief。先整理明确需求、开放问题和冲突信息，不要立即生成。

复制

如果你只说“帮我读取会议”，Agent 仍然需要知道具体账户、会议或时间范围，以及读取后要整理什么。App 提供访问与执行能力，任务边界仍由你决定。

## 从 App 示例开始

不确定 App 能做什么时，先打开 App 详情。部分 App 会展示图片或视频案例，并提供可以直接使用的示例指令。点击示例后，指令会进入 Agent 输入框；先按自己的任务修改对象、参考资料和交付要求，再发送。

从输入框的 `+` 添加 App 时，也可能看到该 App 推荐的示例。示例只负责帮你起步，不会立即运行，也不会替你选择要读取的资料。

## 怎样用工作 Apps 读取资料？

会议纪要、Brief、品牌规范、团队讨论和已有剧本都可以成为任务输入。授权后，仍要明确这次需要读取的具体文档、频道、项目或时间范围。

授权不等于读取全部资料

App 只能在你允许的范围内访问内容。每次任务仍应说明资料来源、用途和优先级，避免 Agent 使用错误版本。

工作 App 常见的任务包括：

- 从指定会议纪要整理客户确认项；
- 从 Notion 页面读取品牌规范和已有脚本；
- 从 Slack 频道汇总某段时间内的反馈；
- 把确认后的预览、项目链接或文件同步回团队。

读取完成后先看来源和时间。重要日期、价格、合同要求和发布决定，应回到原文核对。

## 怎样使用创作 Apps？

创作 Apps 会直接使用当前项目的上下文。你可以选中画布上的产品图、角色、脚本或上一版结果，再让 Agent 调用对应 App。

例如：

使用专业修图 App。保持 @产品正面图 的包装结构，只替换背景和光线，不要修改 Logo 和瓶身比例。

复制

执行前检查输入、输出规格、模型、数量、时长和预计 Tapies 消耗。

创作 Apps 只处理当前任务明确提供的输入。需要保持产品、角色或风格时，把唯一标准放到画布并在任务中引用，不要期待 App 自动从所有历史内容中找出正确版本。

## 怎样让多个 Apps 连续工作？

多个 Apps 可以沿着同一个项目连续工作，但不要一次把所有动作交给 Agent。按可验收的阶段推进：

1. 先读取并整理资料；
2. 确认要求和创意方向；
3. 生成少量静态候选；
4. 修正主体和画面细节；
5. 制作或剪辑视频；
6. 检查交付文件；
7. 确认后再同步到外部平台。

每一步都留下可检查的画布节点或文件。某一步结果不对时，可以从这里调整，不需要重跑整条链路。

## 授权 App 前检查什么？

1. 连接的是哪个账户或工作空间；
2. App 申请读取或执行哪些能力；
3. 数据是否适合交给当前项目使用；
4. 发送、发布、删除等重要动作是否需要人工确认；
5. 任务完成后是否仍需保留连接。

授权决定 App 能接触哪些内容，任务决定这次实际使用哪些内容。授权范围较大时，更要在任务中指定具体文档、频道、页面或时间段。

## Agent 没有调用 App 时怎么办？

- 在指令中直接写明 App 名称；
- 检查 App 是否已启用并完成授权；
- 确认当前账户和空间是否支持该 App；
- 检查画布上是否已经放入 App 需要的输入；
- 让 Agent 先说明准备调用哪个 App 和原因。

如果多个 Apps 都能完成类似任务，可以先让 Agent 比较它们当前支持的输入、输出和预计消耗，再选择。

## App 无法读取内容时怎么办？

- 确认当前连接的账户拥有原始内容权限；
- 检查资料是否位于另一个工作空间；
- 把范围缩小到具体文档、频道或页面；
- 确认引用的是最新版本；
- 如果产品内没有该 App，不要把未来能力当作当前可用功能。

## 怎样确认 App 用对了？

- Agent 列出的来源与任务指定范围一致；
- 读取的是当前版本、正确账户和正确时间段；
- 创作 App 使用了指定的画布节点；
- 输出规格、数量和消耗与确认卡片一致；
- 外部同步只发生在你确认的目标位置；
- 结果可以在画布、侧边栏面板或外部平台中被找到。

## 怎样安全地使用 Apps？

- 不要在对话中粘贴密码、密钥或支付信息；
- 对发送、发布、删除等重要动作保留人工确认；
- 外部资料加入画布后，分享项目前再次检查权限；
- App 显示待审批、未连接或无权限时，先完成授权，不要反复运行同一任务。

发送、发布、删除和覆盖属于重要动作。即使 App 已经获得相应权限，也建议保留人工确认，并在执行后检查真实目标位置。
