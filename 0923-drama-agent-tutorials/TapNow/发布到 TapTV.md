# 发布到 TapTV

在全球首个开源 AI 视频创作社区发布作品，并通过公开画布分享可查阅、可克隆的创作方法。

TapTV 是全球首个开源 AI 视频创作社区。

创作者可以发布完成的视频，也可以选择公开对应画布。其他用户能从作品页进入公开画布，查看这支作品使用了哪些参考、节点怎样连接、创作过程如何推进；点击克隆后，画布会复制到自己的空间，可以沿着原有思路学习、替换素材或继续创作。

提交后，作品会进入处理和审核流程。审核通过后，其他用户就能在 TapTV 中看到并播放它。

## 解读创作思路

在电脑端打开 TapTV 作品的只读项目预览后，页面顶部会显示两个独立操作：

- ****解读创作思路****：登录后，TapNow 会先把项目克隆到你的空间，再打开可编辑画布和 Agent。Agent 会自动开始解读画布中的创作思路。该过程预计消耗 40–150 Tapies，原公开项目保持不变。
- ****克隆项目****：创建一份可编辑副本并进入画布，不会自动打开 Agent。

这两个入口目前仅在电脑端提供，手机端交互保持不变。

## 在 TapTV 学习公开画布

看到感兴趣的作品时，可以按下面的方式学习：

1. 从作品页打开创作者公开的画布；
2. 查看参考素材、节点关系和不同制作阶段；
3. 顺着连接理解输入如何变成图片、视频和最终成片；
4. 点击 ****克隆画布****，把一份副本保存到自己的空间；
5. 在副本中替换素材、调整节点或尝试新的方向；
6. 对比修改前后的结果，总结可以复用的创作方法。

查阅画布适合了解创作者的判断过程，克隆则适合亲手拆解和练习。你可以从优秀作品中学习构图、镜头设计、参考使用和画布组织经验，再把这些方法用到自己的项目里。

克隆画布与素材权利

克隆画布会创建一份可继续编辑的副本，但不代表其中所有素材都可以直接商用或再次发布。使用参考图、音乐、人物或品牌素材前，请确认相应权利和授权范围。

## 发布前需要准备什么？

| 内容 | 要求 |
| --- | --- |
| 作品视频 | 必填，支持 MP4 和 MOV，文件不超过 300 MB |
| 封面 | 必填，选择一张能清楚代表作品的图片 |
| 作品名称 | 必填，最多 80 个字符 |
| 作品描述 | 选填，最多 500 个字符 |
| 公开画布 | 选填，决定观众能否从作品继续查看创作画布 |

上传前先播放一次最终视频，确认画面、声音和结尾都是准备公开的版本。

## 怎样发布？

1. 在画布中打开分享入口，点击 ****发布作品到 TapTV****；
2. 上传作品视频和封面；
3. 填写作品名称和描述；
4. 选择是否公开当前画布；
5. 点击 ****发布并投稿****。

上传期间不要关闭页面。提交成功后，页面会提示作品已经进入审核。

## 是否公开画布？

公开画布是 TapTV 开源创作体验的核心。打开 ****公开画布**** 后，观众可以从作品继续查阅你的制作过程，并在页面允许时克隆一份到自己的空间学习和二次创作。

当你愿意分享参考使用方式、节点关系、镜头结构和创作经验时，可以打开这个选项。整理清楚的画布更容易被其他创作者理解：保留关键输入与结果，给重要节点命名，并把停用版本和最终版本区分开。

如果画布里有客户 Brief、内部评论、未发布素材或个人信息，请先整理画布，或关闭 ****公开画布****，只发布最终视频。

## 发布后在哪里查看？

打开 TapTV 或你的创作者主页查看作品。作品仍在处理或审核时，以页面显示的状态为准，不需要重复上传。

如果审核没有通过，先查看页面给出的原因。修改对应的视频、封面或作品信息后，再重新提交。

## TapTV 和 Arena 有什么区别？

| 入口 | 用途 |
| --- | --- |
| TapTV | 发布作品，查阅或克隆公开画布，学习其他创作者的创作方法 |
| Arena | 参加有主题、时间和投稿规则的社区活动 |

作品发布到 TapTV 后，不会自动参加所有 Arena 活动。要参加活动，还需要进入对应的 Arena 页面，按该活动的章程完成报名或投稿。
