# 使用播放列表

把多个视频片段放进一条时间线，调整顺序和长度，再下载合并视频或导出回画布。

播放列表用于把多个视频片段接成一条完整视频。你可以在同一条时间线上调整镜头顺序、裁掉不需要的开头和结尾、切割片段并预览整体效果。

原始视频节点会继续保留在画布上。修改播放列表不会覆盖原始视频。

## 1. 创建播放列表

已经有两个或更多视频节点时，可以直接创建：

1. 按住 `Shift`，依次单击要使用的视频节点；也可以从空白处拖出选框；
2. 在选区上方的工具栏中点击创建播放列表；
3. 新的播放列表节点会出现在画布上；
4. 刚才选择的视频会按照当前顺序进入时间线。

也可以点击画布左侧的 `+`，进入工具并选择播放列表。这样会先创建一个空播放列表，再由你添加视频。

## 2. 添加更多视频

播放列表创建后，可以继续加入片段：

1. 点击播放列表中的 `+`；
2. 画布进入视频选择状态；
3. 单击需要加入的视频节点；
4. 添加完成后按 `Esc` 退出选择状态。

也可以直接把一个视频节点拖到播放列表上。看到合并到时间线的提示后松开，视频就会成为新的片段。

图片和音频节点不能作为视频片段直接加入播放列表。

## 3. 调整镜头顺序

在时间线上按住一个视频片段，向左或向右拖动，再放到新的位置。

调整后从头播放一次，重点检查：

- 镜头顺序是否能看懂；
- 相邻镜头是否重复；
- 人物或产品位置是否突然跳动；
- 前后镜头的运动方向是否冲突；
- 整体时长是否接近需要的长度。

第一遍先把顺序排对，再处理每段视频的具体长度。

## 4. 裁切和切割片段

### 裁掉片段开头或结尾

选中时间线中的片段，拖动片段左侧或右侧边缘：

- 拖动左侧边缘，调整片段从哪里开始；
- 拖动右侧边缘，调整片段在哪里结束。

裁切只改变播放列表使用的范围，不会删除画布上的原始视频。

### 从播放头位置切开

1. 把播放头移动到需要切开的画面；
2. 点击切割，或按键盘上的 `C`；
3. 当前片段会从播放头位置分成两段。

切开后可以分别移动、裁切或删除两段内容。切点距离片段边缘太近时无法切割，每段至少需要保留 1 秒。

预览时还可以使用：

| 操作 | 快捷键 |
| --- | --- |
| 在播放头位置切割 | `C` |
| 裁掉当前片段播放头左侧的内容 | `Q` |
| 裁掉当前片段播放头右侧的内容 | `E` |

## 5. 删除片段或找到原视频

右键点击时间线中的片段，可以：

- 定位到画布上的源视频节点；
- 从播放列表中移除当前片段。

从播放列表移除片段不会删除源视频节点。需要重新修改或生成某个镜头时，可以先定位到源节点，完成修改后再把新视频加入播放列表。

## 6. 预览完整视频

点击播放，从头观看整条时间线。导出前至少完整检查一次：

- 是否有黑帧或多余静止画面；
- 每个镜头的开头和结尾是否干净；
- 相邻镜头是否衔接自然；
- 视频声音是否突然中断或重复；
- 总时长是否符合使用要求。

单独播放每个片段不够，很多问题只会出现在两个镜头的连接位置。

## 7. 导出播放列表

打开播放列表的导出菜单，可以选择：

| 你需要什么 | 选择哪个入口 |
| --- | --- |
| 保存时间线中使用的原始视频片段 | 下载原始片段（MP4） |
| 把整条时间线合成一个视频文件 | 下载合并视频（MP4） |
| 把合并结果继续放在当前画布上使用 | 导出到画布 |

下载原始片段时，会按照时间线顺序下载；相同源文件只会下载一次。

合并视频或导出到画布需要等待处理完成。处理期间不要重复点击导出，也不要关闭正在显示进度的页面。

## 跟着做一次

下面把四个生成镜头组合成一条短片：

1. 按住 `Shift`，选中四个视频节点；
2. 点击选区上方的创建播放列表；
3. 把开场镜头拖到最左侧，把产品特写放到最后；
4. 拖动每个片段两端，裁掉开头和结尾不稳定的画面；
5. 在需要缩短的片段中移动播放头，按 `C` 切开并删除多余部分；
6. 从头播放一次，检查镜头顺序、黑帧、声音和总时长；
7. 选择下载合并视频（MP4）。

下载完成后，在电脑上重新播放文件，确认它与时间线中的预览一致。
