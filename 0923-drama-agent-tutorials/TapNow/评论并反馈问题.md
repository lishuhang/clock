# 评论并反馈问题

用评论讨论画布内容；遇到产品问题时，连同相关节点和画布信息一起提交反馈。

需要让团队修改某个画面时，使用画布评论。遇到按钮失效、生成异常或页面报错时，使用 ****反馈问题****。

这两个入口用途不同：

| 你遇到的情况 | 使用 |
| --- | --- |
| “这张图里的产品需要再大一点” | 评论 |
| “点击生成后一直没有结果” | 反馈问题 |

## 1. 在画布上添加评论

1. 点击画布左侧工具栏中的 ****评论模式****；
2. 点击需要讨论的位置；
3. 输入评论内容；
4. 按 `Enter` 发送；
5. 再次点击评论模式按钮可以退出。

评论会作为一个节点留在画布上。把评论放在对应图片、视频或文字旁边，团队成员打开画布后就能看到它针对什么内容。

单条评论最多 200 个字符。需要换行时可以使用 `Shift Enter`。

## 2. 回复、编辑或删除评论

点击评论节点可以打开完整讨论。

- 在底部输入框中回复；
- 点击自己评论旁的 `···` 可以编辑或删除；
- 其他成员的评论可以回复，但不能替对方修改。

评论目前没有“已解决”状态。修改完成后，可以直接回复结果，或在不再需要保留讨论时由评论作者删除。

## 3. 一条容易执行的评论

评论中写清修改对象和想要的结果即可，例如：

> 第二个镜头的产品太小。保留现在的构图，把产品放大到画面宽度的三分之一。

如果评论只写“这里不对”或“再高级一点”，其他成员通常还需要重新确认具体要改什么。

## 4. 向 TapNow 反馈产品问题

如果问题与某些节点有关，可以先选中这些节点，再点击浮动工具栏中的 ****反馈问题****。相关节点会自动出现在反馈窗口中。

提交时可以填写：

- 当时进行了什么操作；
- 期望看到什么；
- 实际发生了什么；
- 可选的问题截图；
- 是否附上当前画布链接；
- 是否附上最近操作回放。

反馈窗口还会自动附带应用版本、浏览器和系统、发生时间、画布 ID、节点数量、网络状态等信息，帮助 TapNow 更快复现问题。

## 5. 怎样写清产品问题

例如：

> 我选中两个视频节点后创建播放列表，点击确认后持续显示加载。等待 5 分钟仍然没有创建，刷新页面后可以再次复现。两个原视频都能正常播放。

提交前检查截图、相关节点和画布链接，避免附带与问题无关的客户资料或个人信息。

如果反馈窗口暂时无法发送，请保留错误截图和发生时间，再通过[故障排查](https://docs.tapnow.ai/zh/docs/account/troubleshoot-issues)中的方式联系我们。
