**第一章 👏Seko 3.0 画布 Agent 来啦**

Seko 是商汤科技旗下的“创编一体” AI 视频创作 Agent。

我们致力于让您在**轻松高效**的环境中，完美搞定从创意、剧本、角色、场景、分镜，到视频生成与编辑输出的**全链路创作**。

Seko 3.0 全新升级，更好用的**「画布agent」**和**「顶流创作者的能力封装」**来了！

**💡 一句话搞定视频全链路！画布 Agent 震撼发布**

只需输入一个创意或一段故事，**<u>超多专业级特色Skills</u>**为你自动生成：

**策划全套件**：剧情大纲、角色设定、场景列表、道具规划

**导演级辅助**：分镜方案及提示词、镜头运动设计、情绪节奏规划、配乐建议

**全程支持自然语言交互，动动嘴，AI 替你做成片！**

短视频、网文短剧、漫剧、电影级画面、产品广告、数字人视频，通通不在话下！

**（7）多剧集**

单集内容创作完成后，无需从零搭建下一集内容，画布支持两种续作启动方式，结合全链路资产复用能力，实现剧集内容的高效、连贯创作。

**上传完整剧本**：直接导入下一集的完整剧本文件，画布会自动对齐前作的角色设定、场景素材、视觉风格等核心资产，一键生成对应分镜结构与内容框架，全程保持剧集整体调性统一。

**输入创作灵感**：只需输入核心创意、剧情走向或关键情节关键词，画布将基于前作的内容基底与资产库自动续写完整内容，快速将零散创意落地为成熟的单集内容。
