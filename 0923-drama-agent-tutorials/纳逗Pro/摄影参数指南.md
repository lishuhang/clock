# 纳逗Pro 摄影参数使用指南 [​](#纳逗pro-摄影参数使用指南)

TIP

摄影参数用于在生图时直接控制镜头视角、景深关系、色彩基础和镜头光学质感。焦距和景深决定镜头语言，色彩科学决定画面底色，镜头组用于选择不同电影镜头系列的成像气质。

| 参数 | 控制内容 | 对画面的主要影响 |
| --- | --- | --- |
| 焦距 | 镜头视角和透视 | 决定画面看得多宽、空间是否被拉伸或压缩 |
| 景深 | 前后景清晰关系 | 决定主体和环境是同时清晰，还是主体从背景中剥离 |
| 色彩科学 | 胶片或摄影机的色彩基础 | 决定肤色、高光、阴影、颗粒、对比和整体色彩倾向 |
| 镜头组 | 一套电影镜头系列的光学质感 | 决定锐度、柔焦、焦外形态、眩光、畸变和复古感 |

## 焦距 [​](#焦距)

焦距决定镜头视角、透视变形和空间压缩感。这里的毫米数可以按常见全画幅镜头视角理解。

| 选项 | 画面效果 | 推荐场景 |
| --- | --- | --- |
| 10mm 圆周鱼眼 | 视角极宽，画面内会出现明显圆周边缘，透视变形强烈 | 梦境、迷幻、主观视角、实验影像、极端空间压迫感 |
| 18mm 超广角 | 视角很宽，有强烈透视拉伸，但直线边缘不会像鱼眼那样弯曲 | 大场景、建筑、狭小空间、动作调度、强调人物与环境关系 |
| 25mm 广角 | 视角宽，环境信息丰富，透视感明显但相对可控 | 场景交代、街景、人物在环境中的运动、空间叙事 |
| 35mm 小广角 | 兼顾人物与环境，视角自然，有轻微空间张力 | 通用叙事镜头、双人戏、生活化场景、导演视角预演 |
| 50mm 标准 | 接近自然观看感，透视关系稳定，不夸张 | 中近景、常规对白、客观叙事、需要稳妥还原的画面 |
| 85mm 中焦 | 视角收窄，有轻微压缩感，人物更突出 | 人像、特写、情绪镜头、弱化杂乱背景 |
| 135mm 长焦 | 视角窄，空间压缩强，前后景距离感被压近 | 远距离观察、强烈人物孤立感、密集街景、压缩空间层次 |

## 景深 [​](#景深)

景深控制前景、主体、背景之间的清晰程度。这里沿用影视摄影中常见的 T 值表达，数值越小，背景虚化通常越明显。

| 选项 | 画面效果 | 推荐场景 |
| --- | --- | --- |
| T1.5 | 前后景明显虚化，注意力集中在主体上 | 肖像、情绪特写、浪漫氛围、需要弱化复杂背景的画面 |
| T4.0 | 前后景略微模糊，环境仍可辨认，主体更突出 | 通用人物镜头、对白、半身、兼顾主体和环境的画面 |
| T8.0 | 前后景基本清晰，保留全局细节 | 群戏、动作调度、大场景、需要看清空间信息的镜头 |

## 色彩科学 [​](#色彩科学)

色彩科学决定画面的色彩倾向、颗粒感、对比、高光过渡和阴影气质。它不是简单滤镜，而是让画面靠近某种经典胶片或数字电影摄影机的成像方式。

如果不想指定胶片或摄影机色彩，选择“不设置”；如果想要明确的数字电影机倾向，选择对应摄影机。

## 镜头组 [​](#镜头组)

镜头组指一套实际镜头系列，而不是单支镜头，也不是焦距选项。焦距仍然由“焦距”参数控制；镜头组负责同一镜头系列在不同焦距下共同呈现的光学倾向。

## 使用原则 [​](#使用原则)

先用焦距和景深确定镜头语言，再用色彩科学确定底色，最后用镜头组增加光学味道。

如果画面已经有很强的题材风格，不一定要把所有参数都设满。色彩科学和镜头组都可以选择“不设置”，让提示词、主体和构图先发挥作用。

变形宽银幕镜头组更容易在夜景、高光点、逆光和宽幅构图中被感知；如果画面里没有明显光源或背景层次，椭圆焦外、水平眩光和边缘拉伸可能不会特别明显。

已经在摄影参数中选择的焦距、景深、色彩科学和镜头组，不需要在提示词里重复描述。提示词中如果再次写入同类要求，例如特定胶片、摄影机、镜头型号或虚化效果，可能和面板设置互相影响，导致控制效果变弱或不稳定。
