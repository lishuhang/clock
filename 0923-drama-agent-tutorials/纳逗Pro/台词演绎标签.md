# 纳逗 Pro 台词演绎标签使用指南 [​](#纳逗-pro-台词演绎标签使用指南)

TIP

台词演绎标签是奇声 Omni 的特色功能，针对影视配音场景经过专门优化。它能够结合台词语义与上下文，控制角色的情绪、语气、节奏和表演方式，实现影视级配音表现力，摆脱旁白人机感，让声音更像角色在剧情中的真实表达与表演。

## 什么是台词演绎标签 [​](#什么是台词演绎标签)

台词演绎标签是一种配音控制指令。将标签添加到台词中，可以引导角色以指定的情绪、语气、语速或表演方式进行演绎，让生成的声音更贴合剧情。

例如：

Plain

```
[生气]你为什么现在才告诉我？
[耳语]小声一点，别让他们听见。
我没事[停顿]真的没事。
```

标签只用于控制演绎效果，不会作为台词内容被朗读。

### 自然语言标签 [​](#自然语言标签)

除原生标签外，纳逗 Pro 也支持使用任意自然语言描述演绎方式，例如：

Plain

```
[疲惫但强装镇定]我没事，你先走吧。
[压低声音，语气紧张]他们好像追上来了。
[表面平静，内心愤怒]这就是你的解释？
```

自然语言标签适合描述更细腻、复合的表演状态，但效果可能不如原生标签稳定。建议优先选择含义接近的原生标签；原生标签无法满足需要时，再使用自然语言标签作为补充。

## 如何使用演绎优化 [​](#如何使用演绎优化)

演绎优化可以分析对白中的情绪、语气和节奏，自动添加合适的演绎标签。目前支持在分镜表和生成工具中使用。

### 在分镜表中使用 [​](#在分镜表中使用)

在分镜表的对白文本中，选择一段连续对话后使用演绎优化。

系统会结合前后文判断角色在每句对白中的情绪与表演方式，为台词添加合适的演绎标签。连续对话的上下文越完整，越有利于识别情绪变化和剧情转折。

适用于：

- 多个角色之间的连续对话
- 情绪逐步变化的剧情
- 包含冲突、转折或情绪递进的片段
- 需要结合前后文判断演绎方式的对白

建议选择语义连续、情节完整的一段对话进行优化。

### 在生成工具中使用 [​](#在生成工具中使用)

在生成工具的提示词框中填写一段纯台词，然后使用演绎优化。系统会结合整段台词的上下文，分析合适的情绪、语气和表达节奏。

例如，输入：

Plain

```
你终于来了，我还以为你不会再出现了。这三年我给你打过那么多电话，也问过所有认识你的人，可没有一个人知道你去了哪里。现在你突然回来，却只对我说一句好久不见。你知不知道，我等这句话等了多久？
```

演绎优化后：

Plain

```
[苦涩]你终于来了，我还以为你不会再出现了。这三年我给你打过那么多电话，也问过所有认识你的人，可没有一个人知道你去了哪里。[停顿]现在你突然回来，却只对我说一句好久不见。[叹气]你知不知道，我等这句话等了多久？
```

使用时无需额外填写角色设定、剧情背景或演绎要求，直接输入纯台词即可。优化结果可能因台词内容而有所不同，生成前可以根据实际剧情进行调整。

## 标签使用规则 [​](#标签使用规则)

- 情绪、表演方式、语速和表现力标签放在台词开头，每段只能使用一个，不可叠加。
- 动作与声音标签可以插入台词中的对应位置。
- 停顿标签应放在需要停顿的两个短语之间。
- 标签不宜过多，优先标记对剧情和表演有明显影响的关键内容。
- 需要极慢语速时，可以使用 `[长停顿]` 分隔短语，通常比单独使用 `[很慢]` 更自然。
