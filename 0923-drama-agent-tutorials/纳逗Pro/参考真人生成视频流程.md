# 如何在纳逗Pro参考真人生成视频 [​](#如何在纳逗pro参考真人生成视频)

> 在纳逗 Pro 参考真人生成视频有两种路径：
>
> 1. 若需要使用**艺人形象**，需先由制作团队提供艺人授权文件至纳逗Pro官方工作人员，纳逗Pro进行核验后即可在有限范围内参考该艺人生成视频；
> 2. 若需要使用**素人形象**，则在画布右键选择「Seedance 2.0 真人录入」，由**本人**手机扫码完成活体人脸认证，再为该素人单独建文件夹并上传其图片素材，完成后即可参考图片生成视频。

## 路径1：参考「艺人**形象**」生成视频 [​](#路径1-参考「艺人形象」生成视频)

**使用流程：**

![艺人形象使用流程：提供艺人授权文件 → 纳逗Pro配置使用范围 → 可使用艺人形象生成视频](image_1.png)

1. 制作团队提供艺人的授权文件
2. 纳逗Pro核验后配置艺人形象使用范围（可配置团队或单个画布的使用范围）
3. 配置完成后即可参考该艺人生成视频

**如果已经获得艺人授权，希望使用纳逗Pro完成创作，可发送相关信息至纳逗 Pro 官方邮箱** [**nadoupro@qiyi.com**](mailto:nadoupro@qiyi.com)**，将有专人对接。**

## 方式2：参考「素人**形象**」生成视频 [​](#方式2-参考「素人形象」生成视频)

**使用流程：**

![素人形象使用流程：真人录入 → 活体人脸认证 → 上传图片到素人文件夹 → 参考该素人生成视频](image_2.png)

1. 在画布右键选择「Seedance 2.0 真人录入」
2. 手机扫码进行活体人脸认证
3. 上传素人图片到素人文件夹
4. 完成后即可参考素人库中的图片生成视频

**操作流程示意：**

**① 真人录入入口：**画布右键唤起「Seedance 2.0 真人录入」，进入录入页点击「录制新的真人」。

![这张截图是纳逗Pro平台的操作界面，对应使用Seedance方式2参考素人生成视频流程的第一步操作。截图中在平台画布区域点击右键后，弹出的右键菜单里，「Seedance 2.0真人录入」选项被红色框线突出标注，该选项即为流程里所说的真人录入入口，点击此选项即可进入录入页，后续可进行录制新的真人等操作，该截图清晰展示了操作步骤的关键入口位置。](image_3.png)

![这张图片是Seedance 2.0真人录入的操作界面，对应文档中“参考「素人」生成视频”流程的第一步操作入口。界面整体为黑色背景，左上角标注有“Seedance 2.0 真人录入”的标题，左侧有红色方框特别高亮标注了“录制新的真人”按钮，该按钮带有加号标识，是进入真人录入流程的核心操作点。界面右上角设有“权限说明”选项，中间区域显示提示文字“没有更多文件夹了”，用户可点击红框标注的“录制新的真人”按钮，推进素人素材的录入流程。](image_4.png)

**② 授权与人脸认证：**扫码授权人像资产，手机端允许摄像头并完成活体检测，认证成功后返回。

![图片展示的是纳逗Pro中“Seedance 2.0真人录入”流程中的扫码授权人像资产界面。画面中央是一个二维码，下方提示“请使用手机扫码进行人脸检测”。右下角有“重新生成二维码”按钮。该图片与上下文紧密相关，是“使用流程”中“手机扫码进行活体人脸认证”步骤的直观呈现，帮助用户了解扫码授权的具体操作界面。](image_5.png)

![图片展示的是手机端进行活体人脸认证时的授权界面。画面显示“身份认证服务”及网址“h5-v2.kych5.com”，上方有“加载中，请稍等...”提示。中间有一个黑色半球形图案，下方弹出提示框，内容为“允许“h5-v2.kych5.com”使用你的摄像头？”，框内有“不允许”和“允许”两个蓝色按钮。该图片与文档中“使用流程”里“授权与人脸认证”步骤相关，是扫码授权人像资产、手机端允许摄像头并完成活体检测后返回的界面示例。](image_6.png)

**③ 命名与素材上传：**为素人人像资产命名，上传素人图片到素人文件夹，从文件夹中选择图片可在画布使用。

![这张图片对应的是纳逗Pro生成视频流程里，参考素人生成视频时的「命名与素材上传」环节。画面弹出的操作窗口显示，系统提示“创建成功，请为你的人像资产命名”，窗口内有输入框，已输入的名称仅显示少量字符，输入框旁标注字符限制为2/70，窗口右下角设有“保存”按钮，用户可在该输入框完成素人人像资产的命名操作，契合了该环节为素人人像资产命名的要求。](image_7.png)

每位素人需要单独有一个文件夹，不可将多个素人的图像放到同一个文件夹中混合使用。

![这张图片是Seedance 2.0真人录入工具的操作界面，对应素人生成视频流程里的素材上传环节。界面左侧设有带“本地上传”字样的上传按钮，用于添加素人图片，当前显示“已选择0张”，中间标注“没有更多素材了”，说明暂未上传素人图片，右下角有“使用”功能按钮，该界面是生成素人视频时上传对应素材的操作入口，符合流程中需单独设置素人文件夹并上传素材的要求。](image_8.png)

**注意：**扫码二维码存在时效，失效时点击「重新生成二维码」即可。

## 两种路径对比 [​](#两种路径对比)

|  | 路径1：参考艺人 | 路径2：参考素人 |
| --- | --- | --- |
| **适用对象** | 艺人 | 任意素人（需本人授权） |
| **前置条件** | 艺人授权文件 | 真人录入 + 活体人脸认证 |
| **关键路径** | 艺人形象使用方提供授权 → 纳逗Pro进行核对并控制使用范围 | 本人录入 → 本人认证 → 本人上传素材 |

## 特别提示： [​](#特别提示)

1. 您上传的人脸信息将受到保护，仅用于您所使用功能的必要处理，不会单独提取、进行人脸识别或身份比对，也不会对外提供或用于其他目的。
2. 如您上传的内容包含他人人脸信息，须事先取得当事人明确、合法的授权，并在授权范围内使用，避免侵犯其个人信息及肖像等相关权益。
