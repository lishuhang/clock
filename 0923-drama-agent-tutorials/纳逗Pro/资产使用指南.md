# 什么是资产？ [​](#什么是资产)

## 1 什么是资产 [​](#_1-什么是资产)

纳逗Pro「资产」板块整合IP库、数字资产库和音色库三大资源库，为创作者提供从版权故事到角色素材、配音音色的全链路资源支持。

## 2 怎么使用 IP 库 [​](#_2-怎么使用-ip-库)

IP库汇聚海量故事版权内容，涵盖小说、剧本、漫画等体裁，创作者提交合作意向、审核签约后即可开展AI创作。当前收录6000+ 个 IP，来源覆盖爱奇艺、七猫及创作者原创。

每个IP卡片展示名称、作者、体裁、题材、简介，部分IP展示内容导读，方便创作者快速了解和获取，也可点击IP卡片查看详情或申请合作。

## 3 怎么使用数字资产库 [​](#_3-怎么使用数字资产库)

数字资产库收录角色、道具、场景等创作素材，选中即可直接应用于创作项目。当前包含364个角色图、168个模型图、309条视频和14个3D模型。

支持按资产类型（角色图/模型图/视频/3D模型）、授权状态、题材、性别、年龄段、身高、体格等多维度筛选，帮助创作者精准定位所需素材。

## 4 怎么使用音色库 [​](#_4-怎么使用音色库)

音色库提供专业影视配音资源，覆盖角色对白、剧情旁白、预告解说等场景，让角色更鲜活、故事更生动。当前收录150个音色资产。

每个音色卡片展示名称、性别年龄标签、音色特点和试听条，创作者可直接试听后选用。

## 5 常见问题 [​](#_5-常见问题)

**Q：IP 授权后可以商用吗？**  
 授权状态取决于 IP 方和平台协议。已授权的 IP 可在授权范围内用于 AI 创作，具体商用范围以授权协议为准。

**Q：数字资产可以二次编辑吗？**  
 可以。选中数字资产库中的素材后可直接应用于创作项目，在画布或工作台中可对素材进行进一步编辑和调整。

**Q：音色库的音色如何使用？**  
 在音色库中试听音色后，可在音频节点的台词配音或音色转换功能中直接选用。也可在【资产】-【音色库】中管理已授权的音色。

**Q：IP 库的 IP 来源有哪些？**  
 当前 IP 来源覆盖爱奇艺、七猫及创作者原创，涵盖小说、剧本、漫画等体裁。

**Q：数字资产库包含哪些类型的素材？**  
 当前包含角色图、模型图、视频和 3D 模型四类，支持按资产类型、授权状态、题材、性别、年龄段、身高、体格等多维度筛选。
