# 自由画布怎么用？ [​](#自由画布怎么用)

## 1 什么是自由画布 [​](#_1-什么是自由画布)

自由画布是纳逗Pro 面向创意探索场景提供的开放式 AI 创作空间。用户可以通过添加不同功能节点，将文本、图片、视频、音频等多种素材进行组合，实现从灵感构思到内容生成的完整创作流程。

自由画布支持：

- 多模态素材自由组合
- AI 内容生成
- 节点之间自由连接
- 创作过程实时调整
- 素材资产统一管理

**适合场景：**

- 快速探索创意
- 生成角色、场景、分镜素材
- 制作短视频、漫剧、影视片段
- 搭建个性化 AI 创作流程

## 2 怎么创建画布 [​](#_2-怎么创建画布)

点击导航栏或制作空间右上角【+】，选择创作模式，点击【新建画布】，创建完成后即可进入自由创作区域。

![该图片是软件的“选择创作模式”界面，界面中明确划分了制作空间、脚本空间、智能体三个功能区块。制作空间下突出显示“新建画布”选项，右侧标注“试一试”按钮，下方有对应说明，提及可创建自由画布来满足各类创作需求。此外，界面还设有“新建工作台”“新建稿件”选项，智能体区块内提供图片、视频、音频三类素材的快速创作入口，支持用户选择适配的创作模式进行相关创作操作。](_files_自由画布使用指南/image_1.png)

## 3 怎么添加创作内容 [​](#_3-怎么添加创作内容)

在自由画布中，用户可以通过以下三种方式添加创作内容：

**方法一：新增节点**

双击画布空白区域，选择需要使用的节点类型，添加至画布。

![该图片展示的是纳逗Pro平台的自由画布创作界面，界面左侧有用于操作的功能栏，包含添加节点等相关选项；画布中间区域有“点击画布即可自由生成”的提示，还配有“参考参考图”“角色三视”“新鲜生成视频”三类功能选项，用于辅助创作者添加创作内容，该界面对应文档中“3怎么添加创作内容”里的方法一，是介绍双击画布空白区域添加节点操作的相关图示。](_files_自由画布使用指南/image_1.gif)

**方法二：上传素材**

支持图片、视频、音频、文本文件直接拖拽上传至画布。

![图片展示了纳画Pro软件中自由画布的添加创作内容界面。画面左侧有“+”号图标，点击可新增节点。右侧弹出文件选择窗口，显示“我的”文件夹内容，有多个文件选项，如“示例视频.mp4”“示例视频.jpg”等。该图片与文档中“怎么添加创作内容”部分的“方法二：上传素材”内容对应，直观呈现了上传素材至画布的操作界面及文件选择情况。](_files_自由画布使用指南/image_2.gif)

**方法三：调用已有资产**

可从【资产】中调用已有素材，包括个人空间中已保存的角色、场景、道具、音频等。

![这是“纳逗Pro”自由画布的操作界面截图，界面整体为深色背景。左侧栏有一个带加号的绿色圆形按钮，为新增节点操作按钮，旁边还有另外两个功能按钮。界面中间区域有多个功能按钮，上方带“灵感”字样的按钮旁标注“用AI自动生成”，下方分布着“多多素材库”“角色三视图”“新生成代码”三个功能选项，该界面对应自由画布新增创作内容的操作场景，可通过这些选项开展相关创作内容添加操作。](_files_自由画布使用指南/image_3.gif)

也可从【数字资产】中调用角色图、模型图、视频或3D模型。

#### 4.1.2 图片节点 [​](#_4-1-2-图片节点)

图片节点用于生成和处理视觉素材，可用于分镜图、人物设计图、海报等。

**支持的生成方式：**

1. **文生图**：输入文字描述，生成对应画面。适合创意探索、快速生成视觉方案。
2. **融图模式**：上传参考图片，让 AI 根据参考内容进行创作。适合保持人物一致性、场景风格统一、融合多个视觉元素。
3. **720° 全景生成**：根据参考图生成完整空间环境。适合场景设计、影视空间搭建、多镜头统一场景。

#### 4.1.3 视频节点 [​](#_4-1-3-视频节点)

视频节点用于生成动态视频内容，可将图片、文字等素材转化为视频。适用于影视素材生成、短视频制作、TVC 制作等。

**支持的生成方式：**

1. **文生视频**：输入文字描述，直接生成视频
2. **首尾帧生成视频**：设置视频开始和结束画面，生成自然过渡效果
3. **多参考视频**：上传多张相关图片作为参考，生成连续动态效果
4. **视频编辑**：上传视频并输入修改提示词，编辑视频内容
5. **动作控制**：上传参考视频或人物图，生成更精准的动作视频效果

## 5 怎么使用Agent 辅助创作 [​](#_5-怎么使用agent-辅助创作)

在自由画布中，除了手动添加和连接节点，还可以通过画布右上角的【Agent】入口与 AI Agent 进行对话式创作。用自然语言描述创作需求，Agent 会自动在画布中生成和连接节点，适合希望快速产出或不熟悉节点操作流程的用户。

![图片展示了纳图Pro自由画布界面。画面右上角有“Agent”按钮，其右侧有“陶乐家分”标识。界面中部有一个灰色矩形区域，内有“暂无图片”字样。左侧有“+”号图标，下方还有“+”号和“-”号图标。该图片与文档中介绍Agent辅助创作的内容相关，直观呈现了在自由画布中点击右上角“Agent”按钮打开对话面板的操作场景。](_files_自由画布使用指南/image_21.png)

### 5.1 对话式创作 [​](#_5-1-对话式创作)

点击右上角【Agent】打开对话面板，输入创作需求即可开始。对话过程中支持以下操作：

- **引用画布节点**：在对话中引用当前画布已有的节点作为上下文，Agent 会基于已有内容继续创作
- **从空间导入素材**：在对话中直接引用工作空间中已上传的素材，无需切换到资产面板操作
- **本地上传素材**：在对话中直接上传本地文件作为参考素材

### 5.2 Agent 设置 [​](#_5-2-agent-设置)

在 Agent 对话面板中可以自主配置以下选项，控制 Agent 的创作行为：

- **问询频率**：设置 Agent 在创作过程中向用户确认方案的频率。频率越高，Agent 会在更多关键节点征求你的意见；调低则让 Agent 更自主地完成全流程
- **素材自动生成**：开启后，Agent 会根据对话内容自动判断需要哪些素材并生成，无需逐个手动操作
- **图片模型选择**：为 Agent 的图片生成任务选择合适的模型，可选 Seedream 5.0 Pro、奇智-IGI 2、奇智-INB 2 等
- **视频模型选择**：为 Agent 的视频生成任务选择合适的模型，可选 Seedance 2.5、Seedance 2.0、可灵 3.0 Omni 4K 等
- **Skill 选择**：为 Agent 选择使用合适的 Skill 技能包，如电影级运镜生成、风格重绘、智能调色等，具体可用 Skill 详见第五章

## 8 常见创作流程示例 [​](#_8-常见创作流程示例)

**流程**：上传人物参考图 → 图片节点（融图模式）→ 生成角色设计图 → 用于后续视频制作

#### 制作完整影视片段 [​](#制作完整影视片段)

**适合**：短剧、漫剧、宣传片制作。

**流程**：故事梗概 → 剧本生成 → 角色设计 → 场景设计 → 分镜生成 → 视频制作

## 10 自由画布创作技巧 [​](#_10-自由画布创作技巧)

#### 先规划，再生成 [​](#先规划-再生成)

推荐流程：明确创作目标 → 创建文本节点梳理需求 → 生成角色和场景资产 → 再进入视频制作。避免直接生成视频导致修改成本增加。

#### 善用参考资产 [​](#善用参考资产)

如果希望保持人物一致、场景统一、风格稳定，建议提前上传参考图，并通过图片节点的融图模式进行创作。

#### 模块化管理资产 [​](#模块化管理资产)

建议将角色、场景、道具、视频片段分别保存管理，方便后续复用。详见→第六章「资产管理指南」。

## 11 常见问题 [​](#_11-常见问题)

**Q：自由画布和影视创作工作台有什么区别？**  
 自由画布适合自由探索、灵活搭建工作流；工作台适合有剧本、按结构化流程推进的创作。两者可以互补使用。

**Q：节点之间可以交叉连接吗？**  
 可以。一个节点的输出可以同时连接到多个节点的输入，实现素材的复用和分支工作流。

**Q：画布中的内容可以分享给其他人吗？**  
 可以。纳逗Pro 支持将画布中的内容分享给其他用户，方便团队协作。
