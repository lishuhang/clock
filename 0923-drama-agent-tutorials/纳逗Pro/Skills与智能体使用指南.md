# Skills 与智能体怎么用？ [​](#skills-与智能体怎么用)

## 1 什么是 Skills 与智能体 [​](#_1-什么是-skills-与智能体)

纳逗Pro「能力」板块包含三个子板块：Skills市场、智能体和我的Skills。【Skills】汇聚官方和社区创作者开发的创作技能包，覆盖影视创作、视觉风格、音频处理等多个领域；【智能体】覆盖编剧、导演、美术、摄录、剪辑、宣发等影视制作全链路；【我的Skills】则是用户管理、收藏和创建个人技能包的专属空间。三者结合，构成了纳逗Pro区别于通用AI视频工具的核心能力体系。

## 2 怎么使用Skills市场 [​](#_2-怎么使用skills市场)

Skills是纳逗Pro的创作技能包体系，由官方和社区创作者开发，用户可在能力板块中直接调用，也可以在画布中调用【Agent】来使用Skill。

Skills市场汇聚了多种类型的创作工具，覆盖影视创作、视觉风格、动漫番剧、短剧漫剧、游戏、音乐音频、品牌营销、通用工具等多个领域。

每个Skill以卡片形式展示，包含类型（视频/图片/音频）、名称、作者、使用次数和功能说明，用户可快速浏览和选择。

### 怎么使用 Skill [​](#怎么使用-skill)

在纳逗Pro左侧导航栏点击「能力」，选择顶部「Skills」标签页。可通过分类标签筛选，或使用右上角搜索框按关键词查找。找到需要的Skill后，点击卡片即可在画布中使用。

用户还可点击右上角「我的Skills」查看已收藏和已创建的Skill。

## 3 怎么创建我的 Skills [​](#_3-怎么创建我的-skills)

「我的Skills」是用户的个人技能管理空间。在能力板块中点击「我的Skills」标签页即可进入，在这里可以查看已收藏和已创建的Skill，也可以创建属于自己的Skill。

目前有三种创建方式：手动上传创建、把画布当前创作对话总结成 Skill、通过 Agent 从零创建 Skill

### 方式一：手动上传**创建自定义Skill** [​](#方式一-手动上传创建自定义skill)

1. **进入创建入口：** 在左侧导航选择【能力】，顶部选择【Skills】标签，点击右上角【创建】。

   ![该图片展示了「纳逗Pro」平台的Skills页面，对应“创建自定义Skill”流程的创建入口相关操作指引。图片左侧有被标记为「1」的九宫格图标按钮，左侧导航栏在Skills标签页下，顶部对应“Skills”选项被标记为「2」，页面右上角被标记为「3」的“创建”按钮是创建Skill的核心入口。页面中间区域展示了各类已有的Skill相关内容卡片，涵盖文本、图片生成、音视频处理等不同类型的功能内容，整体呈现了Skills页面的界面布局。](image_2.png)
2. **填写基本信息：**填写**Skill名称、Skill简介、Skill内容、使用场景、预期输入、输出内容。**

![图片展示了“创建Skill”界面。界面上方有“保存”和“取消”按钮。下方有多个输入框，包括“Skill名称”“Skill简介”“Skill内容”“使用场景”“预期输入”“输出内容”等，每个输入框下方都有字数限制提示。其中“Skill内容”区域有“复制”“Markdown”“上传”选项。该图片与上文“创建自定义Skill”流程中“填写基本信息”步骤对应，直观呈现了填写Skill相关信息的操作界面。](image_3.png)

3. **选择类型、上传封面：**选择Skill类型，目前支持**文本、图片、音频、视频**，这里选的类型会作为"输出类型"展示在Skill详情页。封面选填，上传一张有代表性的图，Skill卡片会更醒目。

![图片展示的是创建自定义Skill时的“选择类型”和“上传封面（选填）”界面。上方“选择类型”下拉框中显示“视频”选项。下方“上传封面（选填）”区域有一个灰色矩形按钮，按钮上有白色图标和文字“点击上传”。该图片与文档中“创建自定义Skill”步骤相关，对应“选择类型、上传封面”这一步骤，直观呈现了选择Skill类型和上传封面的操作界面。](image_4.png)

4. **保存：** 点击【保存】，Skill就会存进【我的Skills】。此时状态还是"未发布"，不会出现在Skill商店，你可以先自己测试和修改。
5. **测试效果：** 在【能力】-【我的Skills】中找到刚创建的Skill，点击【去使用】，系统会新建一块画布并自动加载这个Skill。

![图片展示的是在【能力】-【我的Skills】页面中，找到刚创建的Skill“一句话生成故事”的界面。页面上方有“我的Skills”标签，下方显示该Skill为“未发布”，并有“去使用”按钮。该图片与上文“测试效果”步骤相关，说明在【能力】-【我的Skills】中找到刚创建的Skill后，点击“去使用”，系统会新建一块画布并自动加载这个Skill，以便在画布里进行测试，验证Skill的执行效果。](image_5.png)

6. **在画布里跑一遍：** 在画布右侧Agent对话框里输入你的创作灵感（比如一句话的故事），Agent会按Skill内容里写好的流程执行，信息不足时先向你追问，执行过程中能看到它逐步调用图片、视频等生成能力。在输入框输入"/"还可以查看当前可用的所有Skill。 **此画布可用于后续提交审核材料。**

![图片展示的是纳图Pro个人空间中“一句生成AI短片”界面。左侧有“多参考生成”“多参考三视图”“骨骼主视角”选项，下方是视频播放区域。右侧是Agent对话框，提示“Hi，你有什么创作想法？”下方有“寻找一些创意短片”“不找创意短片”两个选项。画面右下角红框内显示“一句生成 - 一个10岁孩子坐上自己的机械装置穿越城市”等内容，旁边有“+”“-”“/”等操作按钮。此图对应文档中创建自定义Skill后在画布里跑一遍的操作说明，展示输入创作灵感后的界面情况。](image_6.png)

![图片展示的是纳图Pro平台中生成的AI短片画面。画面中有四张短片缩略图，每张缩略图下方都有播放按钮。画面背景为城市夜景，有高楼大厦、行驶的车辆和骑摩托车的人物。右下角有“+”“-”按钮，以及“+”“-”“=”“/”“×”等数学运算符号按钮。右侧有“模型”“任务”“参数”“提示”等选项卡，当前“模型”选项卡被选中，显示了多个模型名称及版本号。该图片与文档中介绍在画布里跑一遍生成AI短片的内容相关，展示了生成的AI短片画面。](image_7.png)

7. **编辑、发布等操作：** 点击【去使用】旁边的"…"，共有四个操作： **编辑、发布、移动到团队、删除** 。如果效果不理想，回到【我的Skills】，点【去使用】旁边的"…"选择【编辑】，调整Skill内容后再测。

![这张图片展示了“我的Skills”页面的操作界面，页面上方有“我的Skills”的高亮标识，用户可在此管理自行创建的Skills，当前显示“我创建的2”项。图中突出显示了未发布的Skill卡片，卡片右侧有三点状的更多操作按钮，点击该按钮后弹出包含编辑、发布、移动到团队、删除选项的下拉菜单，该功能对应文档中介绍的编辑、发布等操作内容，用户可通过此菜单对自行创建的Skill进行相关调整或管理。](image_8.png)

8. **发布：** 点击【发布】，确认Skill信息后，需填写：

   1. **发布审核材料（均为必填）**：填写能完整运行该 Skill 的画布链接、选择场景分类、填写版本说明（200 字以内），并上传展示 Skill 运行效果的图片或视频。
   2. **设置定价**：按单次使用收费，档位为 0 / 5 / 20 / 40 / 60 / 80 / 100 积分，0 积分为免费，积分分成全部给到 Skill 发布者。
   3. **勾选协议**：勾选《纳逗Pro数字与技术资产合作协议》后点击【发布】。

![这是发布Skill的操作界面，界面包含三个核心区域，均被红色框标注。左侧“Skill信息”区域展示了Skill名称、发布人、发布到的位置、当前版本等内容；下方“发布审核材料”区域包含填写完整运行Skill的画布链接、选择场景分类、填写200字以内版本说明的输入项，还有上传展示Skill运行效果的图片或视频的按钮；右侧“Skill定价”区域明确了单次使用的收费积分档位，分别为0、5、20、40、60、80、100积分，还标注了0积分即免费、其余为单次使用收费且积分分成全部给到Skill发布者的规则。界面底部还有勾选相关合作协议的选项及取消、发布的按钮。](image_9.png)

审核通过后，Skill 会上架 Skill 商店，其他用户就能搜索并使用了。

## 4 智能体有哪些 [​](#_4-智能体有哪些)

纳逗Pro 的智能体按影视制作职能分类大概有以下类型：

| 职能类别 | 代表智能体 | 核心能力 |
| --- | --- | --- |
| 编剧 | 编剧助手 | 小说一键转剧本、剧本评估与分析 |
| 导演 | 导演智能体 | 精细光线调整、运镜定义、精准导演意图表达 |
| 美术 | 美术智能体 | 主体库管理、角色/场景一致性和稳定性 |
| 专业戏份 | 专业戏增强智能体 | 融入专业表演指导，生成文戏/武戏/感情戏 |
| 长镜头 | 一镜到底智能体 | 生成长达数十秒的连续长镜头 |

**剧本内容:**

- 支持多种上传形式——

  - 一集对应一个文档，或一个文档中包括多集内容
  - 需要满足`上传总集数为：5 ~ 100集`。
- 每一集剧本中——

  - 基本字数要求：不少于1000汉字。
  - 需要有明确的`场号`标识，并且单集内`场次数：大于3场`。

  一场完整的戏，包含时间、地点、事件三要素。**场次**是"一段完整叙事单元"，从角色进入某个空间开始，到离开或转场结束。**场号**是每个场景的"身份证号"，在这一集剧本里的唯一编号。**场头**是场次的"身份证照片"，包含场次信息，固定格式写在每场戏最前面，让全剧组一眼看懂：这场在哪拍、什么时候拍、什么气氛。

## 6 常见问题 [​](#_6-常见问题)

**Q：智能体需要额外付费吗？**  
 智能体功能包含在积分消耗中，不同智能体的积分消耗标准不同，具体以平台页面展示为准。

**Q：剧本评估支持的剧本格式**

支持解析的基本**文件格式要求**及大小：

- 非加密的word、pdf、txt格式文件
- 文件最大数量 100
- 单个文件最大20MB

*推荐文件名使用统一的格式，例如：《剧名》-第x集*

**Q：剧本解析失败了，怎么办？**

| 问题现象 (你可能会看到) | 可能原因 | 具体表现 | 解决方法 (你可以这样操作) |
| --- | --- | --- | --- |
| “不支持该文件类型” | 上传了暂不支持或加密的文件。 | 上传了如 `.pages`、加密PDF、或带密码的Word文档。 | 请上传 **非加密的** Word (.docx)、PDF 或纯文本 (.txt) 格式文件。 |
| “单个文件最多支持500W字” | 剧本内容太长，超过系统单次处理上限。 | 你的剧本内容可能太长了（真是位高产创作者！） | 建议按 “集”拆分成几个文件，再分别上传。 |
| “未提取到内容” | 文件为加密文件、纯图片或空白文档。 | 1. 文件有打开密码。  2. 文件内文字是图片形式（如扫描版）。  3. 文件确实是空白的。 | 请检查并确保上传的是 可编辑、包含纯文字内容 的版本。 |
| “源文件字符异常无法读取” | 文件中包含乱码或非常规字符。 | 文件编码异常，或包含系统无法识别的特殊符号。（文本乱码啦！） | 建议用文本编辑器（如记事本）将文件另存为 UTF-8 编码的 .txt 格式，清理异常字符后重新上传。 |
| “未识别到集号” | 文档中缺少明确的集数标识。 | 文档中没有类似 `第一集` 这样的集号标题。 | 请在文档中为每一集加上明确标题，如 `## 第一集`，然后重新上传。 |
| “请上传<5-100>集以内的剧本附件” | 文档集数少于可解析的数量，或超出单次处理的上限。 | 集数小于4集，或大于101集。 | 集数过少可将一集拆成多集，集数过多可将多集内容合并成一集。 |
| “单集字数不得低于1000个汉字” | 某一集或多集内容过少。 | 单集字数少于1000汉字。 | 对该集剧本进行拓写，或将该集合并到其他剧集中。 |
| “未识别到场号" | 文档中缺少场头或场号。 | 文档中没有类似 `第一场` 这样的场号标题。 | 请在文档中为每一场加上明确场次信息，建议使用“第1场”等描述 |
| “存在超长场次” | 某一场次或多个场次内容过长。 | 文档中没有做“场次”区分，或单个场次的内容超出一定长度。 | 建议将超长的场次内容拆分成几个场次，记得分别标清表头~ |
| “单集内的场次数不得低于3场” | 单集场次过少，或没有区分场次。 | 文档中某一集或多集内容仅有一个或两个场次，或没有场次信息。 | 将一场拆成多个场次，并在每一场开头标注场次信息。 |
