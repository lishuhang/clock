# 智能预演体验指南

预演整组镜头、统一规划分镜，并自动把关键帧插入对应片段，帮助多镜头剧情保持人物动作、运镜关系和空间逻辑一致。

## 为什么要用智能预演

****常见痛点****

1. 首尾帧只能解决两个镜头的一致性，多镜头仍需反复抽卡。
2. 运镜和空间逻辑容易跳变，正反打镜头难以保持一致。
3. 手动补救成本高，链路长且繁琐。

****推荐用法：****先把剧本和每幕分镜调整到位，一键生成智能预演；确认分镜图无误后，再生成视频。

## 功能简介

在片段轴中打开智能预演

****智能预演****基于镜头提示词，预演并统一规划关键分镜图，自动插入片段作为视频参考。

它相当于导演助理，先为整组镜头做好规划，从而降低抽卡率。

## 功能详述

### 如何使用？

[![这张图片呈现的是小云雀短剧Agent智能预演功能里的片段选择界面，界面顶部设有“多选”“智能分镜图”选项，鼠标光标正指向“智能分镜图”选项。界面内展示了5个时长不一的片段缩略图，从左至右依次为时长11s的片段01、9s的片段02、13s的片段03、9s的片段04、13s的片段05，其中时长11s的片段01被黑色边框选中，对应使用步骤里选中预演片段的操作，结合操作指南，该界面是选择智能预演对应片段的操作入口区域。](_files_小云雀短剧 Agent 智能预演体验指南/image_2.png)](https://p11-seeyou-cn.byteimg.com/tos-cn-i-e844mpvzdi/f55bedc4fc654a19ba2b86385df8efdf~tplv-e844mpvzdi-compress:q90.image)

选择一组需要预演的片段

[![这张图展示的是小云雀短剧Agent智能预演操作相关的分镜参考设置界面，界面上方标注当前为“片段10”，还提示了镜头调整、积分消耗相关信息。画面左侧有两个红色箭头，分别指向“分镜1的参考图”和“分镜2的参考图”的输入区域，明确了两段分镜的参考图来源，分别对应片段S8的分镜1、分镜2参考图。界面中还清晰标注了本片段的场景设定为梅菲尔纪念医院急诊区走廊白天全景，同时详细说明了两段分镜的时长、构图、人物角色及对应的动作、台词等内容。](_files_小云雀短剧 Agent 智能预演体验指南/image_3.png)](_files_小云雀短剧 Agent 智能预演体验指南/image_3.png)

查看自动插入的分镜参考图

1. 在分集编辑器底部点击「智能预演」，选择一组已经确认提示词的片段，再点击「生成智能预演」。
2. 生成后，分镜图会自动插入对应片段，并用绿点提示查看。
3. 确认分镜图无误后，直接生成视频。

****温馨提示****

1. 预演片段需要多于 2 个。
2. 所选片段引用的素材不能超过 9 个。

查看智能预演分镜结果

重新抽卡规划片段分镜

****整体不满意：****选中片段再次抽卡，重新规划分镜内容。

****单个分镜图不满意：****

1. 打开分镜图右上角的编辑入口，进入画布。
2. 从分镜图拉出节点，输入修改想法并生成图片。
3. 把新图片添加到素材。
4. 在资产库中将新分镜图拖入编辑器。
