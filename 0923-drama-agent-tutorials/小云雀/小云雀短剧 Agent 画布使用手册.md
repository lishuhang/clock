# 小云雀短剧 Agent 画布使用手册

## 一、什么是资产创作画布

**和市面上画布产品的差异点：**

- **聚焦资产库创作**：提供光影控制、镜头控制、全景图、三视图等短剧场景工具
- **剧本故事驱动**：结合剧本解析的角色和场景，在画布中特设了角色节点和场景节点以及其预设参考图关系，整理画布时也会按照角色和场景聚合分类整理
- **全链路资产同步**：支持资产库内容的全局联动修改，一处更新全链路自动生效；在画布创作的节点可添加进资产库，在故事板分镜页调用

## 二、画布能做什么

在资产创作画布中，你可以完成以下工作：

1. **编辑核心资产：**对剧本解析出的角色、场景进行图片补充，也可编辑新建，辅助后续创作和管理
2. **添加创作素材：**补充文本、图片、音视频等素材，作为参考输入或灵感来源
3. **并行推进创作：**不同角色、不同场景、不同方案可以在同一画布中同时展开，减少来回切换
4. **沉淀创作过程：**不仅保留最终结果，也保留中间过程和参考依据，便于后续修改、复用和协作

## 三、核心概念说明

1. **资产库**：包含最终创作结果、可持续沉淀和复用的内容，即角色、场景、道具、素材
2. **节点**：画布上的每一个内容单元都为一个节点，不同节点类型承载不同内容；**基础节点**（文本、图片、视频、音频）可进行对应模态的生成/上传行为、**角色/场景节点**则富含更多字段信息，在分镜故事板页可自动调用
3. **连线**：节点之间的连线关系，即为引用上下文关系；引用角色/场景节点，则将其节点图作为参考图

剧本资产拆解后进入资产库页面，可点击右上角「在画布中编辑」进入画布，也可直接点击角色/场景卡片，定位至画布对应位置

点击角色节点的「更多」图标，将打开信息配置弹窗。剧本解析出的角色节点将自动附带文本音色，同时支持上传参考音频文件，自定义角色的音频音色参考

### 怎么替换角色/场景图

1. 在图片节点可以右键选择「应用到角色」「应用到场景」对已有进行角色/场景节点进行主图替换
2. 在想要替换的图片节点点击“复制图片”，选中对应节点ctrl+v复制

### 左下角菜单栏

[![左下角菜单栏](image_28.png)](image_28.png)

左下角菜单栏

从左至右依次为：

1. 重置：回到全局视角
2. 整理画布：将按照节点类型进行整理排布
3. 展示角色和场景：将隐藏基础节点及其相关连线，只清晰展示资产库结果
4. 画布小地图：便于宏观把控视角
5. 网格吸附：开启后节点排列将吸附网格
6. 调整画布缩放比例
