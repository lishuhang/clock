# 小云雀营销 Agent 产品使用手册

> **Web入口🏆：****[https://xyq.jianying.com/marketing-agent](/marketing-agent)**

## 一、你可以用它做什么

营销 Agent 从「商品信息 + 核心卖点」出发，帮助商家找到创意方向，并补全为可执行的视频生成方案。你可以直接描述已有想法，也可以从 Showcase、创意库、Hook 库和风格库中获取灵感；生成结果可同步到小云雀已有的画布，继续整理和加工。

| **核心能力** | **解决什么问题** | **用户可以怎么做** |
| --- | --- | --- |
| **首页 Showcase** | 没有创意方向，不知道从哪里开始 | 预览案例，点击「使用」或「复刻」作为创作起点 |
| **创意库** | 不知道广告讲什么、用什么形式展开 | 按营销场景浏览、搜索和预览创意 |
| **Hook 库** | 开场不够抓眼，用户前 3 秒就划走 | 从视觉、结构、口播、声音等方向选择开场方式 |
| **风格库** | 画面不统一，品牌记忆点不清晰 | 选择贯穿全片的视觉语言 |
| **画布** | 素材和生成结果分散，难以反复修改与组合 | 集中管理、引用和编辑图片与视频，并继续生成、预览和导出 |

## 二、快速上手

[![营销创作流程：添加素材和商品卖点后，按是否已有创意方向选择浏览创意库或直接描述想法，再设置风格、模型和画布并生成](image_1.png)](image_1.png)

营销创作流程图

1. **进入营销 Agent。**打开小云雀首页，在 Agent 类型中选择「营销 Agent」。
2. **添加商品与参考。**点击「+」上传商品图、素材或参考内容；也可用 @ 引用已有资产。
3. **先写商品与卖点。**在输入框中说明商品、核心卖点、目标人群、投放平台和视频时长；不知道创意方向也没关系。
4. **按需寻找灵感与控制方向。**没有想法时，可先浏览首页 Showcase 或创意库；已有想法时可直接描述。创意、Hook、风格均为可选项，可任选其一、任选多个，也可以全部不选交给 Agent 自动补全。
5. **生成并进入画布。**提交后查看生成结果；需要继续加工时，可在画布中引用、编辑、组合并导出。

> 示例：便携榨汁杯；卖点为 6 叶刀头、便携防漏、30 秒打果汁；面向通勤和健身人群；投放抖音；15 秒；希望节奏轻快、真实种草。

## 五、Hook 库：抓住前 3 秒

[![Hook 库：选择能抓住前 3 秒的开场](image_1.jpg)](image_1.jpg)

Hook 库：选择能抓住前 3 秒的开场

Hook 库专门解决广告开场问题：前 3 秒先让用户停下来，再把注意力交给卖点和剧情。

| 分类 | 适合解决的问题 |
| --- | --- |
| 视觉 | 用巨物、微缩、极端场景或特效制造第一眼冲击 |
| 结构 | 用反差、悬念、先结果后过程等叙事方式留住用户 |
| 文案口播 | 用痛点、利益点、提问或冲突句快速建立关注 |
| 声音 | 用音效、节奏、ASMR 或突发声音打断滑动 |
| 风格 | 用鲜明的审美或类型片质感形成开场辨识度 |

当前库中示例包括「巨物产品飞入」「巨物产品互动」「高空机翼奇观」「火车车顶视角」「火山岩浆奇观」「高楼边缘场景」「沙漠车顶自拍」「产品飞溅特效」等；每张卡片可预览视频，也可查看对应 Prompt。

## 六、风格库：统一整条广告的视觉记忆

[![风格库：统一整条广告的视觉语言](image_2.jpg)](image_2.jpg)

风格库：统一整条广告的视觉语言

风格库为整条广告提供统一的视觉语言，让画面从色彩、光线、场景到人物气质保持一致，形成品牌记忆。

| 分类 | 典型感受 | 更适合的产品 |
| --- | --- | --- |
| 自然生活 | 真实、松弛、亲近 | 家居、食品、户外、日用 |
| 东方美学 | 留白、温润、文化感 | 茶饮、香氛、美妆、文创 |
| 高级质感 | 克制、精致、品牌感 | 美妆、珠宝、数码、高端消费 |
| 年轻潮流 | 活力、时尚、社交感 | 服饰、潮玩、零食、社媒新品 |
| 科技未来 | 冷峻、前沿、效率感 | 数码、智能硬件、汽车、软件服务 |
