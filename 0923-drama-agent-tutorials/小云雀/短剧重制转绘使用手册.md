# 短剧「重制转绘」使用手册

上传原始短剧，系统自动识别角色与场景，再按新画风和目标地区重新生成成片。无需剪辑或 AI 经验，按流程操作即可。

## 什么是「重制转绘」？

重制转绘是一条“原片复刻”流水线：理解原片中的角色、场景和道具，尽量保留剧情节奏与镜头结构，再按指定风格和地区重新生成。

****适合谁用：****想把已有短剧换画风、换地区版本重新发行的创作者、运营和出海团队。

****重制转绘效果展示****

### 它能帮你做什么

| 能力 | 说明 |
| --- | --- |
| ****镜头语言 1:1 复刻**** | 用原视频白模作为运动参考，继承机位、运镜与切镜 |
| ****Seedance 2.5 加持**** | 提升复刻画质与还原度 |
| ****更长单集时长**** | 单集最长 5 分钟，总时长可达 100 分钟 |
| ****17 种目标地区**** | 自适应当地人种、语言与环境特征 |
| ****一次解析多种风格**** | 切换画面风格与画幅比例 |
| ****两类复刻模式**** | 白模复刻强调精准，普通复刻兼顾性价比 |

## 分环节使用指南

****整体流程：****上传原片 → 设置风格、比例和地区 → 解析 → 资产本土化 → 生成资产 → 生成分集脚本 → 分镜精修 → 合成导出。

### 环节一 · 进入功能入口

进入短剧 Agent 顶部的「重制转绘」，点击或拖拽上传视频。支持 mp4、mov，单个视频 5–300 秒且不超过 500MB；最多 20 个视频，单项目总时长 100 分钟。

> ****请确认对上传视频拥有合法版权或已经获得授权。****

进入重制转绘并上传剧集

### 环节二 · 上传原片并设置参数

上传中或完成后，可以添加原片、调整集数顺序、重新上传或删除某一集。随后设置风格、画幅比例和目标地区。

1. ****风格：****选择成片画风。
2. ****比例：****按投放平台选择横屏或竖屏。
3. ****目标地区：****选择中国、日本、韩国、美国、印尼、巴西、南非、墨西哥等地区。

视频必须全部上传完成，并选好风格与目标地区，才能点击「确认顺序并解析」。

[![这张图是短剧「重制转绘」使用手册的配套操作界面，对应文档里提到的设定成片相关参数的环节。界面右上角展示了“目标地区”的下拉选项，其中“中国”选项已被选中，这部分正是文档里说明的需先设置的三项内容之一，该部分选定后，成片画面会自适应当地的人种、语言与环境特征。界面左侧为“上传原片”区域，呈现了7个视频集的上传状态，每个集次均提供取消上传或删除的操作选项，可支持调整集数顺序、重新上传等操作，与手册中对应上传环节的说明相呼应。](_files_短剧重制转绘使用手册/image_2.png)](_files_短剧重制转绘使用手册/image_2.png)

批量上传并设置目标地区

### 环节三 · 确认解析

点击「确认顺序并解析」后会显示预计积分消耗。确认后不能再调整集数顺序、增删原片或切换目标地区，请提交前再次核对。

[![图片展示的是短剧「重制转绘」使用手册中环节三“确认解析”时的界面。界面上方有“上传图片”“资产库”“分集搭建”等选项。下方是上传的7集视频缩略图，每集视频下方有“重新上传”“删除”选项，部分视频还显示“已上传”。底部有“确认顺序并解析资产”按钮。该图片与上下文紧密相关，直观呈现了上传的视频集数及当前操作步骤。](_files_短剧重制转绘使用手册/image_3.png)](_files_短剧重制转绘使用手册/image_3.png)

确认视频顺序并解析资产

### 环节四 · 等待解析完成

每集会依次显示未解析、解析中和解析完成。单集解析失败不影响其他集，点击「重新解析」即可一次重试全部失败剧集。

[![图片展示的是短剧「重制转绘」使用手册中环节三“确认解析”步骤的上传原片界面。界面上方有“上传图片”“资产库”“分集搭建”选项。下方列出7集视频文件，每集视频下方有“重新上传”“重新解析”“重置解析”按钮，其中第4集视频被红色框线突出显示。底部提示“视频解析完成后，将进行资产本土化”，并有“+100资产本土化”按钮。该图片与上下文对应，直观呈现了上传原片及视频解析相关操作的界面情况。](_files_短剧重制转绘使用手册/image_4.png)](_files_短剧重制转绘使用手册/image_4.png)

查看解析状态并重试失败剧集

### 环节五 · 资产本土化

解析完成后执行资产本土化。系统会依据目标地区和语言调整角色、场景等资产；该步骤按视频总时长预估积分。

[![这张图片是短剧「重制转绘」使用手册的环节三·确认解析对应的操作界面，页面顶部显示流程步骤为“1. 上传原片、2. 资产库、3. 分集视频”，当前处于“上传原片”环节，界面展示了已上传的7个视频文件，每个文件对应标注了集数，还配有相关古风人物的参考缩略图，每个集数旁设有操作按钮，页面底部提示内容显示资产已完成本土化，可前往资产库查看编辑解析结果，还有“下一步”操作按钮。](_files_短剧重制转绘使用手册/image_5.png)](_files_短剧重制转绘使用手册/image_5.png)

完成资产本土化后进入下一步

### 环节六 · 资产库

在资产库检查角色、场景、道具和素材。逐项核对描述和原片参考图，不满意的内容可重新生成或微调，也可用「批量」生成全部资产图片。

[![图片展示的是短剧「重制转绘」中资产库界面。画面中呈现了多个角色卡，如林风、西风、锦绣卫01等，每张卡下方有角色名称及编号。右上角有“只显示角色”和“显示全部形象”选项。右下角有“数量”和“筛选”按钮。该图片与上下文紧密相关，上下文介绍在资产库确认角色、场景等资产是否还原准确，可对不满意的重新生成或微调，也可用右上角“批量”一键生成所有资产图片，这一步相当于“定妆”，资产越准，后续复刻整片越稳。](_files_短剧重制转绘使用手册/image_6.png)](_files_短剧重制转绘使用手册/image_6.png)

在资产库核对本土化角色与场景

### 环节七 · 生成分集脚本

切到分集视频，为每一集生成分镜脚本；右上角「批量」可处理多集。积分按原视频时长和实际生成结果计算。

[![图片展示的是短剧「重制转绘」中“分镜工作台：逐片段精修”环节的界面。界面顶部显示“青木之战_video”标题，有“1. 上传原片”“2. 资产库”“3. 分镜视图”等选项，当前选中“3. 分镜视图”。下方以网格形式呈现共24集的分镜内容，每集有集数、标题及“生成脚本”按钮，如“第1集：魔界霸主 魔王降临”“第2集：猛手握龙爪”等，右上角有“数量”“16/9”“日本”“100%”“开启滤镜”等设置选项。](_files_短剧重制转绘使用手册/image_7.png)](_files_短剧重制转绘使用手册/image_7.png)

批量生成分集脚本

### 环节八 · 分镜工作台

分镜工作台左侧是角色与场景资产，中间是片段脚本分镜，右侧可在转绘、原片、白模和对比视图间切换。确认满意后点击「合成全集」。

[![图片展示的是短剧「重制转绘」生成分集脚本环节中“白模参考”效果示例。画面左侧为角色、场景、道具等素材列表，右侧是片段01的分镜脚本，包含4个分镜，每个分镜配有台词及镜头描述。右侧还呈现了片段01的分镜画面，为一位身着华丽服饰的女性角色。该图片与上下文紧密相关，直观呈现了“白模参考”功能的效果，即基于原片进行粗粒度白模生成，用户可勾选片段生成白模，作为复刻素材实现镜头语言1:1复刻。](_files_短剧重制转绘使用手册/image_8.png)](_files_短剧重制转绘使用手册/image_8.png)

逐片段检查分镜脚本和预览
