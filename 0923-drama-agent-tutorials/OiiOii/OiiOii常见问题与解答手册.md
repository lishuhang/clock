# 功能类问题​

### 1.内容生成失败：​

目前，同一时段内出现多次生成失败有可能是因为当前模型服务有波动，请耐心等待服务恢复后重试。对您造成的不便，我们深表歉意​

### 2.修改分镜，角色等未生效：​

这种情况可能是由于资源未能及时更新所导致的，请先尝试刷新，若刷新后依旧未能显示最新生成的视频，请复制分享链接，进行反馈​

### 3.画布空白：​

请首先尝试刷新浏览器，若无法解决问题，可以尝试更换最新版Chrome浏览器，优化体验​

### 4.视频预览卡顿：​

请尝试清除浏览器缓存后再次进行预览​
