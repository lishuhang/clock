欢迎使用 **LibTV**！

LibTV 是 LiblibAI 推出的**首款专业 AI 视频创作产品**，也是目前**唯一一个同时为人类创作者和 Agent 设计的视频创作系统**。

作为一款诞生在 2026 年的产品，LibTV 理所当然地拥有两个同样重要的入口：

**对创作者来说**，它是一套专业的视频创作工具，足以容纳整个 AI 视频创作流程，你可以在无限画布上搭建剧本、分镜、镜头和剪辑流程，像排练电影一样组织整个创作项目。

**对于 Agent 来说**，它是很多打包好的、可以直接调用的专业创作能力，通过 Skill 接口理解任务、调用模型、编排工作流并自动完成创作。

是的，**你和你的 Agent 现在都可以 solo filming 了！**

1.2.6 **脚本节点 🎬**

**脚本功能（新版）**

**功能概述：从“基础脚本工具”升级到“分镜故事板脚本工具”。**

新版脚本不只是把剧本拆成表格，而是把剧本拆解、剧本资产管理、分镜头调整、提示词合成、批量生图、批量生视频串成一条完整流程。

适合流水漫、AI 短剧、动画短片、故事分镜等内容创作场景，可以更快完成：剧本拆解 → 角色/场景/道具资产提取 → 分镜脚本调整 → 批量生成分镜图 → 批量生成视频片段。

对比脚本旧版 解决的问题

针对收集的用户问题，新版脚本方案围绕四个关键词展开：**<u>资产化、可编辑、可批量、灵活修改</u>**

**资产化**：将脚本从“纯文本表格”升级为“内容 + 资产”结构，风格、角色、场景、道具等资产与脚本绑定并可被提示词引用；

**可编辑**：脚本的每一行、每一个字段、每一个资产都可以被用户修改，修改后能同步更新对应的提示词；脚本中的分镜支持新增、删除、调整顺序。

**可批量**：用户可批量执行分镜图和分镜视频的生成。可自由选择生成范围（单个/部分/全部）、生成类型（批量生图、批量生视频）、以及批量执行的模型类型。

**灵活修改：**新版脚本可以在批量生成前直接补充和调整，用户可在真正批量生图、生视频前，把角色、场景、提示词、参考图都修改补充到比较稳的状态，再进入生产。

三、使用方式功能介绍

**第 1 步：添加脚本节点**

**可通过两种方式**添加脚本节点：

第一种，<u>双击画布，或者打开底部的 “+”，选择「脚本 new」</u>。

第二种，先把剧本文本输入到一个文本节点里，再从文本节点<u>拉出一条线，选择「脚本 new」</u>。

脚本节点的**前置输入**可以是一段**剧本文本**，也可以同时接入一些**参考图**，比如角色图、场景图、风格图等。

如果只是想快速拆分镜，输入剧本文本就可以开始。

如果希望后续生成的角色、画风、场景更稳定，建议在一开始就把关键参考图接进去，这样脚本节点在拆解时也可以更好地理解整体风格和角色设定。

**第 2 步：开始生成**

将文本、图片节点<u>与脚本节点连接后</u>**，**或者直接在脚本节点的<u>生成器输入框内输入剧本内容</u>，选择合适的脚本拆解模型，**<u>点击生成。</u>**

**模型的选择**：推荐优先选择<u>CVLM5.5 或 GVLM 3.1</u>

生成后，脚本节点会自动完成几件事：

把剧本文本拆成结构化 shot；

提取关键角色、场景、道具；

整理每个 shot 对应的画面信息；

为后续生图、生视频准备基础提示词。

这一步相当于先把一段完整剧本拆成一份可编辑的分镜故事板。

<img src="_files_LibTV使用指南/image14.png" style="width:5.75in;height:3.09375in" />

**第 3 步：编辑脚本节点**

**这一步是后续生成是否准确的关键。**

脚本节点生成出来后，**不建议直接批量生图/视频**。更好的方式是先检查 shot 信息，管理好角色、场景、道具等资产，再进入后面的批量生成。

因为后续所有分镜图和视频片段，都会基于这里的信息继续生成。如果这里的角色描述不准、场景不清楚、镜头动作太弱，后面批量生成就会把这些问题放大。

第 5 步：批量生分镜图

等上一步镜头资产和最终提示词信息确认完毕之后，就可以选择批量生成分镜或者是批量生成视频了。

选择对应的镜头和对应的模型后，点击【确认并创建生成器组】，会在画布上创建一组生成器组。

注意：这里面不是空的生成器，这是一个将资产连线、脚本中的提示词、对应选择的生成器参数（模型、尺寸、分辨率等）都带过来的生成器。**<u>点击选中对应的生成器即可查看。</u>**

在这一步，用户可以自主补充更多的参考图信息，调整单独分镜的生成器参数，微调提示词信息等。

若**解组不会让生成器中的信息消失，**这是一个普通的组。

信息的流动是从脚本到分镜组的，如果在生成器内修改了信息，是**不会向上传递**给上游的脚本传递的。

对于短剧、漫剧、动画短片来说，这条链路可以减少很多重复操作：不用每个镜头都手动复制提示词，也不用在多个节点之间来回找角色和场景信息。

四、核心亮点

亮点 1：自动生成 角色、场景、道具，一致性调用

过去 AI 生成的脚本是"一锤子买卖"——不满意只能重新生成。现在不一样：

脚本里的**角色、场景、道具**都被拆成独立“资产”，可以单独修改、替换、复用

改一处，自动同步到所有相关画面

**角色、风格、场景、道具**等在每个分镜里**保持一致，**不会“换个镜头换张脸”

整部片子锁定**统一视觉风格**(真人 / 二次元 / 3D / 水彩等)

角色、场景、道具全部继承同一套风格基调

画面之间衔接自然，不会一个镜头一个画风

亮点 3：先精细调整再批量，结果更可控

新版脚本不是直接让用户“一键到底”，而是在批量生成前留了一个检查和修正环节。

用户可以先看脚本拆得是否正确，角色提取得是否准确，场景有没有漏，提示词是否完整。

发现问题可以直接在脚本节点里修：

缺角色/场景/道具图，可随时补充和添加；

镜头不顺，直接调整顺序；

分镜少了，新增 shot；

分镜多了，删除 shot；

风格不对，可在生成时加风格图或风格词进行修改。

修完之后再批量生成，会比直接一键生成更可控。

整体逻辑更符合创作者实际工作方式：先出草稿，再人工调整，最后批量生产。

亮点 4：一个故事，从文字到成片，全程不用跳出平台

一键**批量生成**所有分镜图、所有视频片段

将生成的视频片段合成为完整视频

亮点 5：更适合短剧、漫剧、AI 影视的批量生产

新版脚本不是只服务单张图或视频片段，而是更适合一整段故事的生产。

尤其是短剧和漫剧，经常会有这些需求：

一集里有大量重复角色；

同一个场景会反复出现；

需要快速拆分镜；

需要批量生成素材；

需要先测试几条，再批量跑全量；

需要在成本和质量之间做控制。

新版脚本可以把这些重复性的内容资产化，把每个镜头的生产变成可管理、可批量的流程。

它不是完全替代创作者判断，而是把创作者从大量重复整理提示词、复制角色信息、逐条生成的工作里解放出来。

AI 影视 / 动画短片

适合做灵感泛化、剧本拆解、资产整理和分镜生成。

对早期创意验证来说，这个流程会比较高效。

短剧 / 漫剧单集素材生产

短剧和漫剧更依赖批量生产，一集里面经常有几十个镜头，而且角色和场景会反复出现。

新版脚本在这种场景下比较有优势：

可以快速拆单集分镜；

可以统一管理角色和场景；

可以批量生成分镜图；

可以继续批量生成视频；

可以先局部测试，再批量跑全量。

对于流水线生产来说，它能减少很多重复操作。

**当前还存在的边界**

新版脚本目前还不是“精品短片一键直出”。

导演思维、镜头节奏、时长判断、镜头与镜头之间的衔接，还是需要人工介入。

尤其是精品 TVC 这类对产品一致性、镜头设计、品牌质感要求特别高的场景，当前生成稳定性还会有一些不确定性。

但整体来看，相比旧版，V2 的生产逻辑更完整，生成链路也更顺。对于需要快速拆剧本、搭故事板、批量出素材的创作者来说，新版脚本会比旧版更实用。

**「创建运动」---操作演示（适合想让角色在 3D 场景中按指定路线移动）**

点击播放后，角色沿路径运动

角色从门口走到房间中间。

短剧人物走位、漫剧角色调度、电商广告人物展示

操作路径：

用户在左侧对象树选中摄像机。

右侧出现「创建运镜」入口。

点击后，系统展示运镜模板。

用户选择推近、拉远、横移、环绕、升镜、俯冲等模板。

适合场景：

镜头慢慢推近角色，突出人物登场

镜头拉远展示完整场景

镜头横移展示空间层次

镜头环绕商品或角色，做广告展示

**运镜控制使用小技巧：**

**Kling 3.0** 对「镜头左右移」提示的相应响应不准，对左右上下摇动偶尔不准确（已反馈给可灵官方，等待反馈）。**这种情况可以通过切换其他模型或者方式处理**

不同的视角有不同的应用场景**，如果分镜应用不当，会导致失效的情况。**

|                                                                |
|----------------------------------------------------------------|

5.4 **音频模型**

5.4.1 **音色克隆**

**功能简述**

> 录制对应的声音样本，就能创建专属音色。后续输入文本，即可用这个音色持续生成新的配音内容。

**使用方法**

> 1️⃣ 新建「音频」节点，模型选择 Minimax Speech。进入高级设置，选择切换音色。
>
> 2️⃣ 进入音色库，选择「我的音色」，然后点击顶部「克隆新音色」

|                                                                                                                                                                        |                                                                                                                                                                      |
|------------------------------------------------------------------------------------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <img src="_files_LibTV使用指南/image202.png" style="width:2.53125in;height:2.51042in" /> | <img src="_files_LibTV使用指南/image203.png" style="width:2.875in;height:2.59375in" /> |

**克隆流程**

> **1️⃣ 朗读音频**
>
> 建议在相对安静的环境下,进行清晰、语速适中的朗读,尽量读115s以上,这样克隆出的音色结果才更准确。如果希
>
> 望有某些对应的情绪,可以在朗读的时候加上,这样使用该音色的的时候,也会带上对应的情绪。
>
> **2️⃣ 生成并试听音色**
>
> 音色生成成功后,先用一段短文本试听。试听时重点检查:

相似度：是否接近原声音色

清晰度：是否有杂音、糊音、爆音

稳定性：是否忽高忽低、忽快忽慢

自然度：是否像真人说话

情绪表达：是否符合文本内容

> 3️⃣ **填写音色相关的信息,进行音色信息登录**
>
> 登录相关音色信息,完成后即可完成克隆音色的创建。
>
> 4️⃣ 使用克隆音色生成语音
>
> 音色克隆成功后,**在语音生成页面选择该音色,再输入文本生成语音。**
>
> 注意:如果创建音色后,7天内未使用,会被minimax官方api清除(受内存限制,有实效性),所以建议创建完立刻
>
> 使用一次,这样就会一直保存在自己的音色库中。
