# Flova AI 快速视频教程

跟着下面五段视频，快速上手 Flova 的核心用法。

## 概览

Flova 是一个 AI 原生的视频创作 Agent 平台：你可以用自然语言描述创作诉求，也可以上传文本、图片、视频或音频作为参考，Agent 会在多步规划与执行中把项目从构思推进到成片。

[VIDEO](_files_Flova AI 快速视频教程/video_1.mp4)

## 如何开始一段创作

Flova 不强制你按某种固定方式开始。你可以从一句简单的 Prompt 起步，也可以上传一张图片作为美学和风格的灵感参考、上传你已经设定好的角色图直接进入创作，或者上传一段音乐作为 MV 的起点。在项目的任何阶段，任何形式的素材都能成为创作的入口。

[VIDEO](_files_Flova AI 快速视频教程/video_2.mp4)

## 多线并行创作

右侧对话区的 Agent 适合处理全局性和较复杂的改动；左侧通过手动编辑、手动生成与评论生成，则适合对单点素材精修或重新生成。两条线可以同时推进，互不阻塞。

[VIDEO](_files_Flova AI 快速视频教程/video_3.mp4)

## 灵活组织素材与故事板

媒体文件区里的素材组可以随意拖入故事板或剪辑时间线，绑定到对应的元素、分镜或音频；故事板本身也支持卡片之间的拖拽与重新编排，让你随时调整故事结构。

[VIDEO](_files_Flova AI 快速视频教程/video_4.mp4)

## 使用 Skill

Skill 是给 Agent 的一套可复用的创作流程：把你的工作习惯、审美与制作规则写成 Skill 后，Agent 会按同一套标准执行，长期协作更稳定。
