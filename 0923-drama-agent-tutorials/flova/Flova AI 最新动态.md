# Flova AI 最新动态

## 2026-08-31

- ****团队版最多支持 100 个席位：**** 团队总席位上限由 20 个提高到 100 个。
- ****积分优先抵扣临期余额：**** 生成内容时，会优先使用 7 天内即将到期的积分，再使用当前模型的专属积分，减少积分因过期而浪费。
- ****生成受限原因展示更清晰：**** 当生成因积分不足、模型或分辨率权限受限而暂停时，会在对应步骤显示具体原因。
- ****Wan 3.0 支持更多音频格式：**** 使用音频作为参考素材时，除 WAV 和 MP3 外，现在也支持 M4A、AAC 和 FLAC。

## 2026-08-24

- ****Wan 3.0 上线：**** 原生生成 30 秒视频，支持使用文档与网页直接创作。
- ****社区 Skill 支持按分类搜索：**** 可以在当前分类中直接搜索公开 Skill，更快找到适合的创作流程。

## 2026-08-17

- ****Seedance 2.5 能力升级：**** 新增字幕擦除、视频续作、原样重新生成和 1080p 输出；续作与重新生成会保留原始参考素材和生成设置。
- ****画布评论支持多轮对话：**** 可以针对镜头、角色、音频和未归类素材分别打开对话，持续追问、上传参考素材并查看历史记录；支持与主 Agent 对话并行执行。
- ****Skill 支持携带引用素材：**** 编辑 Skill 时可以引用品牌图片、文档、视频和音频。发布后的 Skill 会固定引用版本，并把可用素材副本带入使用者的项目。
- ****Flova MCP 与外部工具接入：**** Codex 等外部 AI 工具可以通过 MCP 授权连接 Flova，查询或创建项目、上传素材、运行创作任务、恢复项目并导出结果。
- ****TXT 文件上传上限提高到 50MB：**** 可以直接上传更长的剧本、品牌资料、研究报告和制作说明，不必提前拆分成多个文件。

## 2026-08-10

- ****Seedance 2.5 正式上线：**** 单次最长可生成 30 秒视频，最多可添加 50 个图片、视频和音频等多模态参考素材，为长叙事和复杂场景提供更充分的控制能力。
- ****支持涂鸦生成：**** Seedream 5 Pro 和 GPT Image 2 生成的图片，可以直接在参考图片上涂鸦和标注，引导模型按照指定位置和结构重新生成。
- ****项目可以设置 Agent 执行偏好：**** 可以选择由 Agent 自动决定、在生成媒体前确认 Prompt，或者直接生成；关键步骤是否需要确认也可以按账号和项目分别保存。
- ****社区 Skill 展示优化：**** 支持按精选、使用最多和最新排序。

## 2026-08-03

- ****Agent 支持消息排队：**** 支持在任务执行过程中继续发送、编辑和删除消息，也可以选择立即发送；发送失败的内容会保留，方便重新处理。
- ****文档与 Skill 支持修改对比：**** Agent 修改文档或 Skill 后，可以通过差异对比确认具体变化后再保存。
- ****反馈中心支持持续沟通：**** 可以在原反馈中继续补充信息、查看官方回复和未读状态，不必为同一个问题反复创建新反馈。
- ****MiniMax H3 2K 上线：**** 新增 MiniMax H3 2K 多模态视频生成，支持使用文本、图片、视频和音频作为参考内容生成视频。

## 2026-07-28

- ****个人项目支持复制到团队空间：**** 个人版项目现在可以复制到团队版，方便把个人创作中已经整理好的项目交给团队继续协作、审核或复用。
- ****项目文档与资产库文档上传补齐：**** 项目文档区和资产库都支持上传文档。项目中的参考资料、剧本文件、品牌资料等可以进入文档区成为 Agent 可引用的长期上下文，也可以沉淀到资产库中供后续项目复用。

## 2026-07-23

- ****时间线音频与画布编辑升级：**** 时间线音频编辑和媒体空间画布能力进一步增强，支持缩放、旋转、翻转和吸附等操作，让素材摆放、画面调整和音视频剪辑更容易精确控制。

## 2026-07-22

- ****素材裁剪上线：**** 图片、视频和音频素材现在都可以裁剪，并将裁剪结果生成新的资产，方便从已有素材里截取需要的画面、片段或声音继续创作。
- ****对话支持语音输入：**** 对话区新增语音输入，可以直接说出创作需求、修改意见或审核反馈，让和 Agent 沟通项目更自然。

## 2026-07-16

- ****画布快捷键扩展：**** Storyboard 画布新增 Cmd/Ctrl+0 适配画布、+/- 缩放、Esc 退出或清空选择，并补齐快捷键说明与生效范围控制。整理复杂故事板和大量素材时，画布操作更顺手。

## 2026-07-14

- ****Skill 口令可直接给 CLI 使用：**** Skill 分享弹窗新增六位口令。你可以把口令交给 Flova CLI，让 Codex、Claude Code 等外部 Agent 直接引用对应 Skill，不必反复复制完整 Skill 内容。
- ****时间线剪辑新增淡入编辑：**** 视频和音频剪辑新增淡入时长控制，可以更细地调整片段进入时的画面和声音过渡。

## 2026-07-11

- ****文档上传上限提高到 100,000 字符：**** 项目文档和参考资料可以承载更长文本，适合上传更完整的剧本、品牌手册、客户 brief 或制作资料。
- ****HappyHorse 升级到 1.1：**** Agent 创作流程底层能力更新到 HappyHorse 1.1，项目推进与复杂任务处理能力继续优化。

## 2026-07-09

- ****团队管理与团队套餐上线：**** 账号页现在可以切换个人版和团队版。团队管理页支持成员查询绑定、席位续费、积分分配与回收，并配套展示团队套餐，方便团队统一管理成员和用量。
- ****媒体空间上线，故事板和媒体区合并：**** 原有故事板和媒体区合并为新的媒体空间。媒体空间新增画布模式，原有展示方式改名为列表模式，两种模式可自由切换。画布支持素材拖拽、预览、缩放、多选和布局保存等核心操作，更适合在复杂项目里同时管理故事结构和媒体素材。
- ****Gemini Omni Flash 视频模型接入：**** 生成工具新增 Gemini Omni Flash 视频模型，为视频生成提供更多模型选择。
- ****Seed Audio 1.0 接入：**** 音频生成能力接入 Seed Audio 1.0，为声音创作提供新的模型选项。

## 2026-07-01

- ****Seedance 2.0 Mini 上线：**** 轻量版视频模型 Seedance 2.0 Mini 已接入前后端，支持文本转视频、图片转视频和多素材转视频，最多可使用 9 张参考图，支持 4–15 秒视频生成。

## 2026-06-28

- ****订单发票功能上线：**** 账户页现在可以对订单开发票、查看发票状态和重开发票。退款订单会禁用开票入口，开票结果会通过轮询提示，让发票处理状态更清楚。

## 2026-06-26

- ****Agent 接入与 CLI 授权上线：**** 现在可以把 Flova 交给 Codex、Claude Code 等 AI Agent 来操作。通过 Agent 接入页复制启动提示词、完成浏览器授权或 API Key 授权后，Agent 可以帮你创建项目、推进创作、读取项目状态并导出视频，让 Flova 更容易接入到自己的自动化创作工作流里。

## 2026-06-24

- ****资产库上线，跨项目复用素材与创作资产：**** 你可以把项目里沉淀出的可复用内容存入资产库，在后续项目中继续调用。无论是故事板里的角色元素、镜头设计、背景音乐、单个素材，还是项目文档，都可以作为跨项目资产保存下来，减少重复整理和重复上传，让常用风格、角色和制作资料逐步沉淀成自己的创作资产库。

## 2026-06-18

- ****故事板支持并行局部修改：**** 故事板生成后，不必每次都回到主对话里让 Agent 从头理解整份项目。你可以直接针对多个镜头、角色元素或音频层分别提出评论和修改需求，让 Agent 并行处理这些局部调整；这样在打磨分镜、角色设定和音画节奏时，可以更快推进多个修改点，整体迭代效率更高。

## 2026-06-17

- ****视频素材支持一键提取音频：**** 在视频素材预览区可以直接提取音轨，并生成新的音频素材。提取后的音频可以继续用于配音、参考音频或剪辑，让已有视频里的声音素材更容易被二次利用。

## 2026-06-12

- ****Skill 社区上线：**** Skill 现在可以从社区中发现和复用。你可以浏览精选 Skill，查看适合的创作流程，并添加到「我的 Skill」后在项目里直接调用。这样常用的创作方法、风格规则和制作流程不必每次重新配置，也更容易从成熟模板开始创作。

## 2026-06-11

- ****Agent 支持主动搜索资料：**** 当创作任务需要补充背景信息、事实资料或参考内容时，Agent 可以在执行计划中发起搜索，并把搜索结果整理成项目内的文档资源。后续创作步骤可以继续使用这些搜索结果，让脚本、设定和视觉方案有更完整的资料依据。

## 2026-06-09

- ****Prompt Draft 支持生成前确认和持续编辑：**** 生成图片或视频前，Agent 可以先产出可编辑的 prompt 草稿，并在素材区保留为独立草稿卡片。你可以打开草稿检查提示词、引用素材和生成设置，调整后再保存并生成；草稿也支持删除、移动、撤销/重做和版本冲突处理，方便在正式消耗 credits 前把 prompt 打磨清楚。

## 2026-06-08

- ****项目文档支持你和 Agent 一起创建：**** 项目文档现在可以直接新建、编辑、重命名和删除自由文档，Agent 也可以在创作过程中把阶段性内容写成项目文档。比如你可以先让 Agent 生成一版剧本、角色设定或拍摄说明，再在文档区里继续修改；上传文档也支持在文档区中预览，并可以直接引用给 Agent 作为上下文。

## 2026-05-23

- ****邀请奖励模块重新上线：**** 推广码与邀请历史重新开放。弹窗里能看到当前的奖励档位明细和完整的历史邀请记录（含被邀请人邮箱），列表滚到底部会自动加载下一页。如果账号暂不符合邀请资格（注册未满 7 天、还没成功导出过任何项目），复制邀请链接的按钮会置灰，悬浮时会告诉你具体原因。通过邀请获得的积分会在提示里明确写出"30 天有效期"，避免错过使用时机。

## 2026-05-21

- ****MiniMax 配音上线，音色库大幅扩充：**** 配音功能接入 MiniMax 模型，新增上千个音色和更丰富的情感参数。打开配音弹窗就能在音色选择里直接挑选这些新选项；旁白的默认模型也已切换为 MiniMax。
- ****配音支持语速调节：**** 配音生成新增「语速」参数，可以根据节奏需要调慢或调快。该参数覆盖所有配音模型（Doubao、ElevenLabs、MiniMax），调好的语速会保留在素材记录里，下次复用同段配音时不必重新调。

## 2026-05-20

- ****AI 超清上线（图片 + 视频）：**** 在素材预览区现在可以直接对图片和视频做 AI 超分。图片支持升到 4K 或 8K，可选不同放大倍率；视频支持升到 1080p / 2K / 4K，可选 24 / 30 / 60 fps。点击「AI 超清」入口后，参数面板里会显示当前任务的费用明细，确认后再触发。功能面向付费会员开放，未订阅用户在入口处会看到不可用提示。生成失败可以一键重试。
- ****生成工具支持直接超分：**** 生成工具页面也新增了「AI 超清」入口，刚生成的图片或视频可以直接发起超分，不必再回素材预览区找一遍。生成出的超分版本可以从历史里直接定位，并提供「查看原素材」入口，方便对比原图与超分结果。
- ****全局反馈入口：**** 右上角头像下拉菜单新增「反馈」入口，点击后弹出反馈表单，你可以填写问题描述和联系方式直接告诉我们。表单带校验与防重复提交，发送后会有确认提示。
- ****剪辑时间线分割优化：**** 时间线上音视频片段的分割体验整体打磨：新增专用分割图标、分割后保持原选中状态、悬浮分割位置时给出提示，方便精准下刀；分割后的音频保留连续的淡出效果，淡出参数也可以独立调整；分割操作支持撤销与重做，分割与裁剪交叠时的边界也处理得更稳。

## 2026-05-19

- ****多选与拖拽上传：**** 媒体文件区和故事板的素材区现在支持多选——可以圈选或勾选多个素材，一次性收藏、删除或通过右键菜单做批量操作。你也可以直接把电脑里的文件拖进媒体文件区或素材区上传，不必再走"点上传按钮 → 选择文件"那一步。

## 2026-05-15

- ****先草拟 prompt，再触发生成：**** 创作图片或视频时，现在可以先让 AI 草拟出生成 prompt，你预览、修改、确认后再触发实际生成。这样能在花费 credits 之前先确认 prompt 是否符合预期，反复打磨 prompt 也不会重复消耗算力。复制项目时，已经草拟好的 prompt 会一同迁移到新项目里，方便复用。

## 2026-05-14

- ****Flova TV 全新改版：**** 首页视频墙按内容分类划分频道，你可以按类型快速浏览灵感。每个视频卡片都关联了对应的 Skill：全屏预览时可以直接查看 Skill 详情，并一键添加到「我的 Skill」或从其中移除。视频没有上传封面时会自动取第一帧作为预览图，列表更整齐。
- ****对话提问改成卡片式：**** 创作过程中 Agent 向你确认需求时，不再是一段长问句，而是一张张可点击的选项卡片，支持单选与多选，每个选项下方还附带一段说明文字，让你在做决定前更清楚每个选择的含义。
- ****生成中禁用恢复历史版本：**** 故事板正在生成时，恢复到历史版本的按钮会自动置灰，避免在新结果回流前回退到旧版本而导致内容混乱。

## 2026-05-13

- ****Skill 分享上线：**** 你创建的 Skill 现在可以通过一条链接公开分享出去。其他人打开链接就能直接预览这条 Skill 的完整规则，不必先登录；只有在决定收藏使用、点击保存时，才会提示登录。社区里别人公开分享的 Skill，也可以一键收藏到「我的 Skill」，下一次创作就能直接调用。想停止分享时，撤销前会先弹出二次确认，避免一键误操作。
- ****Kling 3.0 全能参考：**** Kling 视频模型升级到 3.0，新增「全能参考」模式，生成视频时可以同时上传多张参考图片和一段参考视频，作为画风、镜头与动作的综合参考。切换模型时，参考图片数量、视频时长与上传规则会自动按当前模型重新校准与过滤，避免把上一模型的参数错带过来。

## 2026-04 · Flova 1.0

Flova 自上线以来最大的一次版本升级：项目内工作台彻底重构，Skill 系统首次登场，老项目也能一键迁移到新格式。

- ****全新四面板工作台：**** 项目内工作台彻底改版，故事板、媒体文件、剪辑时间线和文档区切换为四个独立面板，每个面板都可以单独打开操作，整体节奏更顺手。
- ****全面开放手动操作：**** 大量原本只能交给 Agent 的操作开始支持手动——素材拖拽、与故事板及分镜的关联、文档和文字内容编辑、单项删除等都可以直接由你完成。
- ****Skill 系统首次上线：**** Flova 全新引入 Skill——一套给 Agent 的可复用创作流程。你可以把工作习惯、审美与制作规则沉淀成 Skill，让 Agent 按同一套标准执行。
- ****老项目一键迁移到新版：**** 1.0 之前创建的项目可以一键同步为新版本格式，迁移后直接在四面板工作台里继续创作，不必从头重做。
