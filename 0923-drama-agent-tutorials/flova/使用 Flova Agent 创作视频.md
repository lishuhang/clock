# 使用 Flova Agent 创作视频

Flova Agent 是创作项目里的操作者。你可以在项目右边的对话框里用自然语言告诉它想做什么，它会根据当前项目状态，决定下一步执行。

它不只是一个聊天助手，而是会调度不同创作模块来帮你执行创作任务的一个系统。

## Agent 能做什么

- 与你沟通项目制作过程中的任何问题
- 设计剧本、分镜表或参考素材，创建故事板
- 分析你指定的图片、视频、音频或文档
- 生成图片、视频、音乐、旁白不同的媒体素材。
- 管理素材和故事板的关系，绑定素材到故事板里的元素、分镜或音频层
- 根据故事板和已有素材组装剪辑时间线

## Agent 如何工作

Agent 会根据任务类型自动调度不同模块。你通常不需要指定这些模块，只需要说明目标和约束。

- ****规划****：理解你的目标，判断任务复杂度，决定是否需要建立 Final Video Spec、加载 Skill，并安排后续步骤。
- ****素材理解与处理****：分析你上传的视频、图片、音乐或文档。必要时，也可以提取视频片段、关键帧或音频，作为后续故事板和生成的参考。
- ****故事板设计****：创建或修改关键元素、分镜和音频层，形成后续素材生成与剪辑的结构基础。
- ****媒体生成****：生成或重生成图片、视频、音乐和旁白，并管理素材组、版本和故事板绑定关系。
- ****剪辑组装****：根据故事板和已选素材，生成或修改剪辑时间线，处理片段顺序、节奏、音量和音画同步。

## 如何向 Agent 提需求

描述越清楚，Agent 越容易做出符合预期的结果。你可以从以下几个方面补充信息。

****说清楚你想做什么****

```
把《灰姑娘》的故事做成约 3 分钟的 AI 短片，横屏 16:9，对白英文，3D 动画风。
```

****补充关键规格****

```
做一支 30 秒竖屏耳机广告，突出降噪和轻巧，无对白，快节奏 BGM。
```

****说明素材用途****

```
参考我上传的产品图和 BGM，先帮我设计几版广告创意，不要直接生成。
```

****说明限制条件****

```
请不要改写我上传的剧本，直接按原文整理故事板。
```

****说明你想讨论，还是执行****

```
这个项目先不要生成素材，先告诉我你准备按什么步骤推进。
```

## Agent 与 Skill、Final Video Spec 的关系

Agent 会读取项目里的上下文，并据此决定怎么推进。

- ****Final Video Spec****：记录当前这支视频的全局规格，如画幅比例、语言、时长、风格等
- ****Skill****：规定这类视频应该按什么流程制作，例如先设计故事板、如何使用参考素材、使用哪些模型和提示词规则
- ****Agent****：读取这些上下文，调度后续故事板、素材生成和剪辑任务

如果只是生成一张图、一段视频或一个单素材任务，Agent 通常不需要建立完整 Final Video Spec 或加载 Skill。若你明确要做一支完整视频，Agent 通常会先建立或加载这些上下文，让后续步骤保持一致。

## 执行过程是否可见

Agent 工作时，你可以在对话中看到它正在推进什么步骤，例如：

- 正在分析素材
- 正在创建故事板
- 正在生成关键元素
- 正在生成镜头视频
- 正在组装剪辑时间线

同时，执行结果会出现在对应面板中：

- 故事板结果会进入故事板区域
- 图片、视频、音频结果会进入媒体文件区和故事板的媒体存放区
- 成片的剪辑结果会进入剪辑时间线
- 文档更新可在文档区查看

这样你可以一边看 Agent 的执行过程，一边在左侧面板检查结果。

## 停止、回退与分支

- 如果执行过程中发现方向不对，可以停止当前任务，补充更多信息后再继续。
- 每条 AI 消息底部都可以选择「回到此刻」，将项目回退到该消息对应的状态。你也可以选择「从此开始新项目」，从某个时刻另起一条创作方向，用来对比不同版本。
- 这适合在故事方向、镜头风格或素材选择出现分歧时使用。

## 与手动编辑配合

Agent 和手动编辑可以一起使用。

- Agent 适合多步骤、跨模块、需要规划的任务。
- 手动编辑适合你明确知道怎么改的小调整，或者一些媒体素材管理的工作。
- 你可以让 Agent 继续生成下一批内容，同时在左侧整理已有素材、修改故事板或进行评论生成。
- 如果并行修改影响到同一处内容，系统会打开冲突面板，让你选择保留哪个版本。

## 使用建议

- 复杂项目先让 Agent 规划，再进入批量生成。
- 进入媒体生成之前要检查final video spec以及skill是否符合要求。这两个是复杂视频任务的基础。
- 上传素材时最好说明清楚用途，例如角色参考、场景参考、产品图或音乐节奏参考。
- 不希望改动的内容要直接说明，例如「不要改写剧本」或「不要重新设计角色」。
- 关键节点及时检查，如故事板、元素图。
- 小修小改可以手动完成，不必都交给 Agent。
