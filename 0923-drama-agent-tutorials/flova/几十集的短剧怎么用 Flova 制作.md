# 几十集的短剧怎么用 Flova 制作

一部几十集、总时长超过一小时的短剧，往往包含复杂的人物关系和前后伏笔，制作过程中还会不断加入新造型、新场景和新镜头。前面的基础一旦出错，越往后返工范围越大，也会重复消耗积分。

下面这套方法来自一个使用完整长剧本逐集推进的创作项目。先让 Agent 理解全剧，再从第一集开始，逐步完成故事板、角色、场景、Prompt 卡和素材。

****执行可以局部，项目认知必须完整。****

## 1. 完整剧本一次上传，制作按集推进

创建项目后，先上传完整剧本，再说明这一轮要处理到哪里。完整剧本为 Agent 提供全剧背景，当前指令只限定本轮的执行范围。

```
请完整阅读我上传的这部多集短剧剧本，梳理全剧的时代背景、主要人物、人物关系和分集结构。本轮只制作第一集。请先把第一集整理成故事板，暂时不要生成图片或视频。后续剧集等我确认后再继续。
```

这一步适合搭配 Flova 官方的[****「剧本生视频（需上传剧本）」****](https://flova.tv/zh-CN/skill/?id=4eb6170f4c6645e9ae48e1ad09399227) Skill。加载这个 Skill 后，Agent 会先读取整份剧本，梳理剧情、人物与分集结构，再按照指定的集数或章节推进故事板和后续制作。

第一集故事板设计完成后，要求 Agent 重新与原剧本对照核查。重点确认场次有没有遗漏、人物关系是否还原、动作和台词有没有被改写，以及结尾是否越过本集边界。

```
请基于原剧本校对第一集故事板。发现遗漏或改写时，先修正故事板。核对完成后告诉我改了哪些内容，暂时不要生成素材。
```

这样，Agent 可以掌握完整的剧情发展，创作者仍然保留逐集审核和放行的权利。

## 2. 先讨论剧情，再确认故事板和基准设定

剧本进入故事板以后，先别急着生成所有镜头。多集项目里的很多内容相互依赖：角色还没有定型，包含这个角色的 Shot 就缺少可靠参考；场景基调仍在变化，越早批量生成，后面需要重做的内容越多。

1. 讨论剧情、时代背景和现实逻辑；
2. 根据讨论结果调整故事板和分镜节奏；
3. 确认角色、场景等基准设定；
4. 编写 Prompt 卡；
5. 审核后再生成图片和视频。

```
请先不要修改故事板或生成素材。请基于完整剧本，检查第一集的剧情、人物行为和场景设定是否符合故事的时代背景与现实逻辑。列出需要进一步确认或调整的问题，并说明理由。等我确认后，再修改故事板。
```

把创作过程明确分为“讨论 → 写 Prompt → 正式生成”。每个会影响后续结果的位置都可以先确认，不必等一批素材全部生成后再回头找问题。

## 3. 根据任务搭配主对话与评论生成

制作多集短剧时，项目级任务建议放在主对话中处理，例如讨论剧情、整理整集故事板、批量编写 Prompt 卡或修改全局规则。

当任务只针对当前角色、场景或 Shot 时，建议进入对应对象，通过评论生成提出修改。这样不必重复解释要修改的是哪个对象，也能避免局部细节干扰主对话中的项目级任务。

例如，整集 Prompt 卡可以在主对话中这样安排：

```
请根据已经确认的第一集故事板、角色和场景设定，为第一集各个 Shot 编写图片和视频 Prompt。只更新 Prompt 卡，不要开始生成。完成后等我确认。
```

如果只需要调整当前角色的服装造型，可以在这个角色的评论生成中输入：

```
请保持当前角色已经确认的脸型、体型、发型和身份特征不变。根据这个角色所处的时代背景和当前场景，调整服装造型。服装需要符合人物身份和当时的生活条件，不要修改其他造型。
```

前一个任务涉及整集的多个 Shot，适合在主对话中统一处理；后一个任务只修改当前角色，适合通过评论生成完成。

## 4. 角色设计采用“选角”思路

短剧里的角色会跨越多集，在不同阶段和场景中反复出现，一张效果不错的角色图还不够。更稳妥的做法是先研究故事所处的时代背景和现实依据，再逐步比较脸型、体型、发型与服装。

同一个角色在不同剧情阶段可以有多套造型，这些造型不需要在项目开始时一次性全部生成。先确认稳定的角色身份和基础形象；随着剧集推进，再根据当前剧情增加日常、工作、婚礼或其他特殊情节需要的造型。

声音也可以用类似的方式确定。角色图确认后，挑一段能体现人物性格的台词生成试镜视频，再从视频中提取音频，把它放回对应角色，作为后续可复用的声音参考。角色定型同时包含外形和声音，后面的剧集就不需要重新寻找基准。

## 5. 把稳定规则写进 Skill 和 Final Video Spec

做完几集以后，一些临时要求会逐渐变成固定做法。每次重新提醒既费时间，也容易遗漏。Skill 适合记录可复用的工作方法和执行规则，Final Video Spec 适合记录当前项目需要长期遵守的成片要求。

- 图像和视频 Prompt 统一使用中文；
- 图片统一使用已经确认的模型；
- 对白从普通话改为四川话；
- 每完成一集故事板，都必须与原剧本核对。

确认后的规则不应只停留在对话里。把它们写回 Skill 或 Final Video Spec 后，后续剧集可以自动复用，不需要反复提醒。角色描述、参考图、Prompt 和最终素材也要同步更新并绑定到对应对象，才算真正完成这一阶段。

## 总结

对于几十集短剧或长电影项目，可以直接复用下面的原则。

- ****完整上下文一次给全，实际任务逐步拆小。****
- ****主对话管理全局，评论生成处理局部。****
- ****每一阶段由人审核，确认后的规则写回 Skill。****

这套方法不追求一次生成整部长剧，而是让 Agent 在理解全剧的基础上，稳定完成当前一集、一个场次或一个对象。已经确认的角色、场景、素材和制作规则，可以继续服务后面的剧集。
