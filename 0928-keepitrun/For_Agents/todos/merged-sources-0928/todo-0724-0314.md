## 三、踩坑记录

### 1. 微信反爬"环境异常"

微信对服务器 IP 越来越严格，直接 `requests.get()` 返回验证页而非文章。z-ai `page_reader`（基于云端浏览器）也未能绕过本次反爬。

**规避方法**: 
- 对于已发布文章，可从镜像站（36kr、新浪等）获取内容
- 对于新文章，需要用户手动保存 HTML 后用本地文件处理

### 2. img repo Pages 构建失败 (errored)

上传图片后，img repo 的 GitHub Pages 构建一度显示 "errored"。原因是 compress-images workflow 并发运行，频繁 push 导致 Pages 构建被取消。

**解决**: 等待 compress workflow 完成后，Pages 自动重新构建成功。无需手动干预。

### 3. Google Free Translate 速率限制

Google 免费端点没有明确的速率限制文档，但连续快速请求可能被临时封禁。脚本中每条间隔 0.3s，实测 224 条无问题。

**如遇速率限制**: 增大 `time.sleep(0.3)` 到 `0.5` 或 `1.0`。

### 4. Ruby `json` 模块作用域

在 `translate_batch_google_free` 函数内使用 `json.loads()` 时，因函数内 `import json as _json` 而外部 `json` 未导入导致 `NameError`。

**解决**: 函数内显式 `import json as _json` 并使用 `_json.loads()`。
