> **当前状态：研究结论已更新，未发布新的免费代理版本。**
>
> **最后核验：2026-08-19（GMT+8）**
>
> **生产域名现状：`https://gpt2.lishuhang.com` 当前显示为历史 PM Worker v1.2；它不是本轮验证后的新通道。**

本目录保存 GPT-Image-2 Worker 项目的历史实现、调查材料和交接记录。项目曾先后试验马良、Keydraw/97api、Squido 和 Pixmind（PM）等上游。历史文件可供 UI、任务轮询、错误处理及水印能力参考，但不等同于当前可用的生产依赖。

## 项目目标与边界

目标是提供清晰、稳定的图像生成体验，并在存在上游明确授权时保留历史版本中已经验证过的提示词、比例、任务状态、图片代理和加水印等用户体验能力。去水印功能不应重新引入。

本项目不把第三方公开体验页面、访客 Key、注册赠额、免费试用或人机验证当作可分发的服务凭据。具体而言，项目不会自动创建或隐藏管理第三方账户，不会规避 CAPTCHA、登录、会话期限、额度或风控规则，也不会把仅面向站点自身页面展示的共享 Key 包装成对外通用 API。这一边界既避免用户数据和服务稳定性风险，也避免因上游限流或授权变化而导致生产站点突然失效。

## 当前结论

截至 2026-08-19，未找到一个同时满足下列条件、并且可被安全地部署为本项目后端的 GPT-Image-2 免费上游：**游客无需登录、无需后续人工激活或人机验证、允许第三方 Worker 代理、具有明确稳定的免费额度与使用授权。**

| 候选 | 2026-08-19 实测状态 | 是否适合部署为本项目匿名代理 | 原因 |
|---|---|---:|---|
| Keydraw / 97api 公开页面 | 匿名页面可访问；最小测试任务成功完成并展示图片。 | 否 | 页面仅向其自身用户展示访客 Key，并提示不要滥用；没有提供第三方代理、再分发或长期配额授权。历史上同一 Key 也曾失效。 |
| Flaq 免费生成页 | 游客可输入提示词，但提交后出现“Verify you are human”验证。 | 否 | 无需注册不等于没有安全验证；自动点击或规避该验证不属于可持续、合规的后端集成。 |
| gptimage2.com | 可匿名浏览，生成按钮明确要求登录，免费资格是注册赠分。 | 否 | 需要账户。 |

## 已知历史问题

历史代码中有若干经验仍然适用于任何未来合法上游的 Worker 实现。第一，嵌入 HTML 的模板字符串需要审查转义、作用域和同名常量；第二，前端删除控件时必须清理所有事件和 DOM 引用；第三，任务调度必须为上游失败、无可用凭据、长期轮询等情况设置终态和超时，不能无限显示“排队中”；第四，发布后应使用带 cache-busting 参数的请求和真实浏览器交互复核，而不是只以 HTTP 200 判断可用。

任何未来的发布还必须避免把用户授权信息放进 localStorage 之外的非必要位置，避免将 secrets、Cookie、测试账户文件或临时部署配置提交 Git，并始终在发布前确认 Worker 名称、自定义域名与 workers.dev 地址的实际映射。

## 合规发布的可行路径

如果未来需要让 `gpt2.lishuhang.com` 恢复为可稳定的图像站，应优先选择具有明确授权和稳定额度的集成方式，而不是依赖其他产品的匿名体验层。

| 路径 | 用户体验 | 前置条件 | 适合程度 |
|---|---|---|---|
| 用户自有、合法的付费 API Key | 最稳定；可以提供简洁的设置与用量提示。 | 用户自行取得允许服务端调用的 Key，并确认服务条款和成本。 | 推荐。 |
| 上游公开合作/API 计划 | 可实现真正免登录的本站体验。 | 获得上游关于第三方代理、配额、并发和再分发的明确授权。 | 推荐，但需商务/技术确认。 |
| 外部匿名体验站的跳转页 | 用户可直接使用对方站点。 | 不代理、不复制 Key、不隐藏来源；对方站点仍在线。 | 可作为信息入口，不等同于本站生图通道。 |
| 注册赠额、访客 Key 或 CAPTCHA 站点的自动化中转 | 表面上无登录，但稳定性和合规性差。 | 不应作为方案。 | 不采用。 |
