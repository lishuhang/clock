**仍未解决**。这是整个自动化注册的核心阻塞问题。mailtm-validator 的「已注册」按钮会尝试后端登录，如果仍然 500，用户会看到错误提示。

**可能原因**:

**workaround**: 用户手动在浏览器注册后，可以在 pixmind 网站登录，从浏览器 DevTools 提取 Bearer token，手动编辑 JSON 添加 token 字段
