# TV App v1.4 — 语法错误修复

## 任务目的
修复 tv.lishuhang.workers.dev 的 JS 语法错误，不升级版本号。

## 用户输入的 Prompt
> 1.4 tvapp 出错了，f12：
> (索引):1 Uncaught SyntaxError: Unexpected token 'else'
> 本次修复问题不升级版本号

## 问题定位
浏览器报错 `Uncaught SyntaxError: Unexpected token 'else' at line 1401 of the rendered page.

通过浏览器 eval 获取页面源码，定位到 HTML 行 1396-1401 处的 handleFailover 函数存在花括号错误：
- `if (next === 0)` 块内，`if (st.cycleCount >= 3)` 的右花括号在 1399 行正确关闭
- 但 1400 行多了一个 `}`，导致 `if (next === 0)` 在 1400 行就被关闭
- 1401-1402 行的 `rotateToNextChannel(id); return;` 变成孤立代码
- 1405 行的 `} else {` 报错，因为 `else` 不跟在任何 `if` 配对

## 具体修复
Worker 文件 `/home/z/my-project/tv-worker-bundle.js`（从 CF API 下载的原始 worker）行 1400：
```
                        return;
                    }
                }
                    rotateToNextChannel(id);
                    return;
                }
                showStatus(id, ...);
            } else {
```

修复后（删除 1400 行的多余 `}`）：
```
                        return;
                    }
                }
                showStatus(id, ...);
                rotateToNextChannel(id);
                return;
            } else {
```

## 验证

- toggleSettings、标签切换、页面功能正常

## 踸见问题
- worker bundle 含大量转义字符（如 `\n`），Python 字符串处理会失败，需用 Node 或 sed 处理
- `node -e 'try{new Function(code)}catch(e){}'` 方式受 Node v24 的 TypeScript 类型检查影响
- 最终用 `python3 replace` 一次替换成功
- **切勿在 worker 代码中使用模板字符串内嵌 `\n`**，否则会导致同类语法错误
