# 345 Live Stream Proxy Worker v2.10.1

## 目的与边界

该 Worker 仅作为多个已存在上游的 **HLS 代理与适配层**。本版本未创建新 Worker、新域名、新定时任务或新云资源。生产 blind 版本部署于 `https://345.lishuhang.com/`；用户面向的播放清单必须使用该自定义域，而**不得**使用 `workers.dev` 域名。

> 本项目的传输层测试确认的是 HLS 清单和媒体资源能否取回。它不等于对 DRM、私有加扰、地区限制、浏览器解码结果或长期稳定性的保证。

| 路由类别 | 示例 | 作用 |
|---|---|---|
| 345 动态目录 | `/gt5.m3u8` | 从 `m.345iptv.com` 解析当前播放会话并代理清单、分片。 |
| 央视频动态目录 | `/yspc16.m3u8`、`/yspw01.m3u8` | 使用自动刷新构建时注入的短期动态 URL；部分频道可能因上游令牌过期返回 502。 |
| 学习强国动态目录 | `/xuexi_<key>.m3u8` | 使用自动刷新构建时注入的短期授权路径并代理分片。 |
| 卫视官网备用源 | `/wso-hainan.m3u8` 等 | 按官网 API / 固定公开播放入口动态取得清单；仅作备用。 |
| 健康检查 | `/health/<tid><id>` | 针对 345 动态目录做快速可用性检查。 |
| 状态页 | `/` | blind 版本输出文字状态和诊断信息，不提供完整频道目录 UI。 |

## v2.10.1 的关键兼容修复

上游 345 播放页已从“长加密 blob”变为直接以内联 JavaScript 变量表达式提供解码材料。旧解析器只识别前一形式，造成绝大多数 345 路由返回 `Failed to resolve session URL: long encrypted blob not found`。本版本保留旧 blob 路径，并在其不存在或解析失败时以**数据解析**方式读取当前页面变量；不执行上游页面脚本。

此外，学习强国键名以十六进制字符结尾，会被通用 `/<tid><id>.m3u8` 正则提前匹配。自动构建脚本现将 xuexi 路由插入该通用匹配器之前，从而进入专用处理器。

## 自动刷新链路

现有 GitHub Actions 工作流位于 `lishuhang/345` 仓库。它会使用 Playwright 抓取动态 URL，构建 blind Worker 并上传 Cloudflare。该链路确实可以完成发布，但其抓取步骤存在容错，且动态上游令牌会自然过期。因此，必须把“工作流成功”“状态页成功”和“最终 HLS 传输成功”分开判断。详细审计证据见 `automation-audit-0815.md`。

## 本轮验证摘要

| 对象 | 验证结果 |
|---|---|
| `gt5.m3u8` | 已从解析错误修复为返回 HLS 清单；上游分片仍可能不稳定。 |
| `xuexi_416c4a41.m3u8` | 返回 HLS 清单，连续两个媒体资源均测试成功。 |
| YSP | 自动刷新后仍为部分可用；至少一个旧频道 URL 返回 403，故应保留多线路并定期检测。 |
| WSO | 个别源在两次探测间出现超时，说明适合作为备选而非唯一来源。 |
