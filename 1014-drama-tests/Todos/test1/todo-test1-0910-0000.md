   - **实测** = 真人真跑流程
   - **数据测** = **价格口径 + 功能点口径** ← 这就是你现在要做的
   - **静态测** = 一键成片这类非实战型功能

> 使用"支持 / 部分支持 / 不支持 / 需企业版 / 待核验"五种状态，不做跨范式总冠军。

**所以你要做的事，精确表述是：\**先建一套\**统一的功能点口径**（不是数个数，是用同一框架扫每一家），再扫 10 家，**同类的并到一行比，独有的单列出来**。你说的"同时抽多张卡 / 管理资产 / 协作"分别对应这套框架里的「视频模型-批量并发」「角色场景道具」「协作」三格。
