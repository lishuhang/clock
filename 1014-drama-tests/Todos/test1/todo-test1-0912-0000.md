## 3. 按时间线展开

### 3.1 08-27 早会（袁颖指导）：视角与测试策略

1. **视角定位（关键新增）**：评测服务对象是"个人用户 / OGC / 一人公司"——读者从小红书上看到漫剧火了想自己做的普通人，不是九州、点众这类公司内部由专人解决付款/培训的抽卡师。由此引出稿件核心切入点：**"个人用户入门困难"**（第一步花钱就被卡住、教程不清晰、客服难触达）。
2. **客服体验成为评测内容**：以巨日禄为例——官网给出最便宜的方案是 600 元/月，几十元档没有入口；官网商务微信加不上、企业微信审核久，≈没有客服。但袁颖补充背景：巨日禄获客逻辑是**私域为主**（销售群、专人对接，中小客户也有人对接），所以这一点要写，但要写成"两种获客路径的体验差"，不是单纯负面。
3. **付费策略**：先买 30 天或更长会员深度测试（360 最低套餐仅 7 天有效期，容易被"卡住"）；贵的平台"列厚一点"；先跑通一个平台完整流程，测试中发现的问题随时调方案。
4. **报销要求**：所有付费都要给公司报销 → 工作文档里已建统一账号表（手机 13264571716 / 邮箱 yulezibenlun@163.com / 密码 Yulezibenlun25），并要求盘点发票/退款政策。
5. **新增样片类型**：袁颖建议在评测里加做一条"新闻媒体型 / 知识解读型"AI 样片（参考实习生此前做的邹市明一类视频），顺便为视频组探路；lishuhang 回应以"测试为主"，合适才用。

### 3.2 09-09：定形式、定嘉宾、扩模型

1. **形式与输出物**：最多 4 小时连线（约半小时讲各家付费方式及费率 → 全部 prompt 发出等生成 → 有余力进各家付费页边看边聊）；输出 = 直播（片头贴片露出，嘉宾不提供素材就口播自报家门）+ 文稿 + 视频号短视频总结（可加原声）。
2. **整体流程与时间表**：评估嘉宾人选 → 高蕊问意向 → lishuhang 与嘉宾对齐评测标准与流程 → **下周末至下下周中执行 4 小时录制** → 拆成**三篇（价格-效果-功能）分期发布**。意向确认后：t+1 对测试流程、t+3 执行录制（张禹成建议直播放 t+4 给剪辑留时间，并先定"片头贴片"），录制不超过 3 小时；若提前确认意向则整体提前。
3. **嘉宾候选**：优先《黑鸟》导演 + 其 AI 项目负责人/实际使用者（距离近、宣传意愿强、专业性和配合度好）；张禹成同步找 4A 广告公司 ECD 或前 ECD 作备选。
4. **模型范围扩大**：不只测 Seedance 2.5，加测 **Seedance 2.0**（大量漫剧创作者仍在用 2.0）。
5. **超创的分工定位**：超创基本只帮测 1~2 个（尤其新功能），主要贡献是**提示词和模板化功能**，其余平台由我们自己测；也观察嘉宾自己的测试方法。
6. **访谈问题清单**：① 付费时遇到的奇葩点；② 所有智能体功能中他最看重什么（注意：他自己有独立的资产管理工具，并非完全依赖平台）；③ 实际上手测几个；④ 观察其测试方法。
7. **写作风格**（当晚）：需要"针对性地喂大量文档让输出风格接近对标"，对标对象初步为《娱乐硬糖》——但李书航判断蒸馏只擅长情感水文，正经内容效果一般且吃 token，方向未定。

### 3.3 09-10：不依赖嘉宾、平台名单变化、邀请函

1. **底线明确**：理想明确"**我没有同意你的进度依赖嘉宾的情况**"，要求先出内容——"你先把价格和功能点做统计，但不要列表格排名，排名标准还是得咨询使用的人"；lishuhang 表态不会无限期等：**嘉宾不来，下周中就只发布价格和功能点的稿子**（原目标 09-11 下班前完成统计）。
2. **备选方案**：完全不依赖嘉宾时，内部自拟提示词，让佳玉目测结果充当"超创"角色；或参考此前测"欢乐码"时对超创构思过程的揣摩方式。
3. **平台名单变化**：理想拍板"**不测 360 了，360 已经放弃这一条产品线**"。经确认，**最终名单为 11 家**（即邀请函导出版口径）：小云雀、爱奇艺纳逗 Pro、新片场 ShotLab、万兴剧厂、LibTV、TapNow、OiiOii、巨日禄、**flova、AniShort、商汤 seko**；原 10 家中的天工短剧工作台、360 纳米不在最终名单内（lishuhang 当日发现的"写 9 个但列了 10 个"是版本间数字不一致，以 11 家为准）。
4. **邀请函修改**：太长要精简；把"能给对方的好处"（贴片露出、观点输出、品牌展示、联名发布）放到前面；参考骨朵 AI 给嘉宾的权益写法。改后由张禹成发出（先发高蕊）。
5. **嘉宾沟通三口径**（lishuhang 给张禹成）：① 向嘉宾强调评测目标人群是**没有基础知识但想做一人剧组的入门者**，介绍"从哪个 agent 开始最适合他"；② 嘉宾做东西可能涉及我们不知道的工作流、资产等**画布特有用法**，请老师讲解并据此修改自行评测步骤；③ 评测需求和访谈直播需求可以合并的部分，现场问嘉宾。
6. **张禹成方案**：若嘉宾熟就直接电话沟通，不熟就发精简版；他自己"管他熟不熟都发文档"。

### 3.4 09-11：方向升级——"小白视角"评测教学一体（当前主线）

1. **重大调整（无理想/张禹成合意）**：不再让嘉宾承担横评主体，改为——**超创提供"成片片段 + 当时用的提示词 + 工作流 + skill + 简单教程/使用说明"，由"没怎么用过视频 Agent 的人"照着操作生成**，定位是"小白操作者想整点不一样的东西出来"，借此看 Agent 的能力、易用性和效果。
2. **产出形态**：评测 + 教学一体，做多期——小白遇到问题先自己搜，搜不到打包问超创（或第一期让超创录简单教学）；"采访用真人，其他内容可以用蒸馏的"。
3. **邀请函必须大改**：现有版本"又复杂又过于依赖嘉宾"；要拆成**两个版本/两套话术**——直接认识的超创 vs 通过平台介绍的超创（后者平台有自己的宣传诉求，但没关系：通过超创使用平台建立认知后，内部即可横向评测）。
4. **新嘉宾**：lishuhang 09-11 下午采访的创作者（做 TVC 的）可参与横评提供输出，**下周一（09-14）拉群**；张禹成评价"他家是做 TVC 的，也不是不行"。
5. **态度**：无理想对"依赖超创"的可行性再次存疑（"李书航说要依赖超创根本不现实"），张禹成回应"我俩下午也聊了"，即转向小白视角方案。
