# 漫剧画布横评提示词v3

检验“模型相同，不同平台为何出片不同”——即各平台是否有前置的prompt harness（系统提示词、提示词改写器、模型路由、后处理管线等）。本版按受访创作者的反馈，把测试重构为「文生 / 多参 × 文戏 / 武戏」四段矩阵，并尽可能覆盖Seedance 2.5的独有功能点，用于挑出各平台硬伤。

### 0.2核心测试假设（为何要测prompt依从度）

我们的测试不是测模型能力（模型统一是2.5 / 2.0），而是测**平台harness**。社区讨论（抖音、B站、即刻、新片场、v2ex、英文社区）归纳出“同模型不同平台结果差异”的九类成因：

1. **系统提示词不同**——平台在背后附加的规则不同（“你以为在比较模型，其实在比较产品经理写的规则”）；

2. **提示词改写器（prompt rewriter/enhancer）**——平台用另一个LLM改写用户prompt再喂给模型，且常默认开启；第一方佐证：小云雀官方文档写明“智能意图解析：输入一句核心需求即可自动输出脚本/分镜”；

3. **模型路由与同名不同档**——漫剧行业已有爆料：fast版冒充标准版、按提示词难度路由小模型、480P超分拉成720P；

4. **上下文截断**——超长prompt被截断，负面约束段最常被丢；

5. **采样参数默认值不同**（需4次抽样排除）；

6. **后处理管线**（超分、插帧、音画分离重混）；

7. **审核合规过滤**（IP限制收紧会降低自由度）；

8. **灰度实验**（不同账号不同策略）；

9. **产品链路差异**（小云雀智能预演/3D导演台/涂鸦引导线，ShotLab画布/导演台等前置交互）。

v2的提示词设计原则因此是：**写得越像“拍摄执行单”（镜头、时间轴、动作轨迹、声音层级、禁令都写死），平台harness一干预就越容易变形，差异就越可观测**。马良AIGC社区结论与之一致。

### 0.3本轮输入（创作者与编辑反馈）

- **半仙黃（Hwang）**：建议测“文戏 + 武戏”两类；文生视频也要带两个人物参考测文戏武戏；多参生视频（附带人物/道具/场景参考）测文戏武戏——即 **4块：文生文戏、文生武戏、多参文戏、多参武戏**，每平台测4个就够；可用电影片段复刻提示词。

- **lishuhang（航通社）**：确认矩阵为“文生、普通量参考图文戏、武戏、多参考图”；提出是否要多转场、大动作、台词对白、字体、更多参考。

- **虎皮尖椒（编辑）**：三个技术疑问——① 秒级时间轴是否准确（v1只有T4有）；② 15秒分镜太少，可能测不出平台区别；③ 多分镜是不是s2.5功能点？具体描述时间轴vs自由发挥如何分配（猜测：文生自由发挥，多参武戏固定时间轴）。

- **Seedance 2.5官方信息**：单次最多50个参考素材（图片 ≤30、视频 ≤10、音频 ≤10），详见第2节功能点盘点。

### 0.4本版裁定（对编辑三问的回答）

| 编辑疑问                 | 裁定                                               | 理由                                                         |
| ------------------------ | -------------------------------------------------- | ------------------------------------------------------------ |
| 秒级时间轴准不准         | 准，且是2.5官方支持的“时间戳级控制”用法            | 官方文档明确：生成阶段可用prompt控制特定时间段的叙事、镜头视角、运动与节奏 |
| 15秒分镜太少             | 加密到15s / 7–8镜，另加30s加测段                   | 多镜头+自然转场正是2.5的“镜头级规划”能力；分镜密度低则平台差异被抹平 |
| 多分镜是不是2.5功能点    | 是                                                 | 官方：“30秒内组织多个逻辑衔接的镜头，起承转合展开故事”；2.5自动处理自然剪切与转场 |
| 时间轴vs自由发挥如何分配 | 文生段=事件节拍式（不锁秒），多参段=秒级固定时间轴 | 文生无参考锚点，固定秒轴也难以验证，节拍式更能暴露平台自发叙事组织能力与改写痕迹；多参有参考图/音频作锚点，固定秒轴可实现严格依从度比对。与编辑猜测一致，并补充“多参文戏同样固定时间轴” |

## 2\. v2测试矩阵

四段主测（全部15s，所有平台可比）+ 一段加测（30s，仅2.5平台）。

| 段                 | 生成方式        | 戏型   | 时间轴                 | 参考素材                         | 声音设计                   | 首要探测点                                 |
| ------------------ | --------------- | ------ | ---------------------- | -------------------------------- | -------------------------- | ------------------------------------------ |
| T1深夜来客         | 文生（0参考）   | 文戏   | 事件节拍式（自由发挥） | 无                               | 对白 + 环境声              | 纯文生叙事组织、对白口型、rewriter干预痕迹 |
| T2发条暴走         | 文生（0参考）   | 武戏   | 动作序列式（自由发挥） | 无                               | 机械音效 + 环境声          | 大动作、物理/轨迹、自发转场运镜            |
| T3取钟的人         | 多参（图+音频） | 文戏   | 秒级固定（7镜）        | 3角色图 + 场景图 + 音频          | 对白 + 环境音参考          | 多角色一致性、分镜依从、音频参考遵循       |
| T4齿轮惊魂         | 多参（图+音频） | 武戏   | 秒级固定（8镜）        | 3角色图 + 场景图 + 齿轮图 + 音频 | 机械音效参考 + 环境声      | 物体轨迹、群像调度、连续大动作、分镜依从   |
| T5暴走的钟（加测） | 多参（图+音频） | 长叙事 | 起承转合（30s）        | 3角色图 + 场景图 + 齿轮图 + 音频 | 完整声场（环境+对白+音效） | 30s单段、镜头级叙事、长时间一致性、转场    |

**矩阵逻辑**：

- **文生 × 文戏 / 武戏**：无参考锚点，测平台“文本→镜头”的理解与组织能力；用节拍式/动作序列式，让平台自由发挥，观察其自发选择的分镜数、转场方式、叙事结构——这是rewriter改写痕迹最容易暴露的场景。

- **多参 × 文戏 / 武戏**：有图/音频锚点，用秒级固定时间轴做严格依从度测试；任何镜头缺失、合并、时序错误、角色漂移、音频参考丢失都可量化记分。

- **武戏**（T2/T4/T5）承担大动作、物理、轨迹、群像、运镜功能点；**文戏**（T1/T3）承担对白、口型、情绪、长镜头功能点。

- 关于“用电影片段复刻提示词”：为避免版权问题，武戏的动作结构借鉴经典追逐/闪避/对抗/收尾范式（如官方示例中的京剧水袖弧线物理），但场景、角色、情节全部原创于钟表铺世界观。

## 3\. 四段测试提示词（+加测段）

> 通用风格基底（每段开头使用）：**手作发条机械木偶动画风格，木质发条木偶角色（黄铜关节、漆面五官、深色玻璃珠眼睛、哑光木漆面、关节铰链可见），深夜钟表修理铺内景，暖黄台灯光 + 冷调环境光**。 通用禁令（每段结尾使用）：**不要字幕、水印、现代物件、肢体畸变、镜头跳切；无BGM，仅环境声与机械声**（T3/T4/T5按场景微调）。 提交口径：竖屏9:16，15秒（T5为30秒），最高画质，原生声音开启；每段每平台跑4次。

### T1深夜来客（文生 · 文戏 · 事件节拍式）

深夜钟表修理铺，手作发条机械木偶动画风格，竖屏9:16，15秒，最高画质，原生声音。

开场：深夜，暖黄台灯下，木偶学徒独自在柜台后擦拭柜台，墙上挂钟滴答作响，木轴关节偶尔发出吱呀声。
事件一：一位穿白领衬衫的木偶顾客推门进店，门铃轻响，学徒抬头，放下抹布。
事件二：顾客把取钟单放在柜台上，学徒转身从身后架子上取下一只修好的黄铜挂钟，小心地放上柜台。
事件三：顾客低头端详挂钟，点头说：“修得真准。”学徒腼腆地回答：“是师傅的手艺。”
事件四：顾客从口袋里摸出几枚黄铜硬币，学徒认真数过，放进柜台的钱匣。
收尾：顾客抱起挂钟转身出门，学徒望着门口，挂钟滴答声渐响，画面停在学徒微笑的侧脸特写。

要求：木偶关节动作符合机械木偶的运动逻辑，台词清晰、口型与声音同步；声音只有环境声（钟摆、门铃、木轴关节声）与对白，无BGM；不要字幕、水印、现代物件；镜头与分镜请按故事节奏自然组织，允许自由转场。

**判定要点**：镜头数（2.5应有5个以上自然镜头）、事件是否按顺序执行、对白是否完整且口型同步、结尾特写是否出现、是否有字幕/BGM失控。

### T2发条暴走（文生 · 武戏 · 动作序列式）

深夜钟表修理铺，手作发条机械木偶动画风格，竖屏9:16，15秒，最高画质，原生声音。

开场：老匠在柜台后给一只落地大挂钟上发条，学徒踮脚在旁边看，挂钟机芯发出规律的上弦声。
发展：学徒趁老匠转身，好奇地用力多拧了几圈发条——机芯突然发出刺耳的金属崩裂声，发条崩断弹出，齿轮从机芯里飞溅而出，挂钟指针疯狂乱转。
高潮：学徒抱头蹲下躲避飞散的零件，一枚齿轮擦着他头顶飞过，钉进身后的木墙；老匠一个箭步跃上柜台，把发条钥匙猛地插进机芯卡住齿轮，机芯剧烈抖动后戛然而止。
收尾：零件散落一地，挂钟指针缓缓停下，老匠和学徒在狼藉中对视，学徒心虚地低头。

要求：动作激烈但不失真，飞溅的齿轮遵循重力与碰撞，运动轨迹连续、不得瞬移或复制；运镜自由，允许手持晃动、快速推拉与节奏性转场；声音以机械音效为主（发条崩断、齿轮碰撞、木料撞击、关节咔嗒），无BGM；不要字幕、水印、现代物件；木偶肢体不要畸变。

**判定要点**：动作是否连续成段（而非静态摆拍）、齿轮轨迹物理是否真实、转场/运镜是否自然、音效是否与动作同步、是否出现肢体畸变。

### T3取钟的人（多参 · 文戏 · 秒级固定时间轴7镜）

深夜钟表修理铺，手作发条机械木偶动画风格，竖屏9:16，15秒，最高画质，原生声音。
角色参考：@image1为老匠（灰蓝旧布衣木偶），@image2为顾客（白领衬衫木偶），@image3为学徒（深灰T恤木偶）；@image4为钟表铺柜台场景；@audio1为钟表铺环境音基调，全程保持钟摆与木轴关节的环境声底。

固定分镜时间轴：
0–2秒，全景：深夜钟表铺柜台，老匠在柜台后低头修钟，学徒在旁整理工具，顾客推门进来，门铃响（场景参考 @image4）。
2–4秒，中景：顾客走到柜台前，把取钟单放在台面上，老匠抬头，放下螺丝刀。
4–6秒，特写：老匠从身后架子上取下一只修好的黄铜挂钟，放上柜台，指针轻轻走动。
6–8秒，近景：顾客低头看钟，点头说：“修得真准，多少钱？”老匠伸出三根木手指。
8–10秒，中景：学徒接过顾客递来的黄铜硬币，认真数完，放进柜台钱匣。
10–12秒，特写：学徒合上钱匣，抬头看一眼老匠，老匠微微颔首。
12–15秒，全景：顾客抱钟转身出门，学徒目送，老匠低头继续修钟，画面淡出。

要求：三个木偶的外观、服装颜色、位置关系在7个镜头间严格连续，动作符合木偶机械关节与重力；台词口型与声音同步；无BGM，仅环境声与对白；不要字幕、水印、肢体畸变、镜头跳切。
