## 同事测试得到的剧本产物（统一参考剧本）

> 来源：`重生短剧：.docx`。原文约 85—90 秒。为保证后续视频横比公平，四条镜头提示词均以这份固定产物为依据，而不是使用各平台各自生成的剧本。

### 场景一：沈府·受封宴｜前世｜0—18 秒

锣鼓喧天。沈云卿一身华服，刚接过“诰命夫人”的圣旨，宾客齐声道贺：“恭喜慕容夫人！”人群外，衣衫破旧、满脸憔悴的沈云乔死死盯着她。沈云卿刚转身，一把匕首猛地刺进她腹部，众人惊叫。

沈云卿：“云乔……你疯了？”

沈云乔：“凭什么？三年前抛绣球，你嫁的是慕容安，我却砸中了一个乞丐！”

快速闪回：沈云乔掀开破旧喜轿，看到衣衫褴褛的男人，转身逃走；大雨中，她被赶出客栈，跪在街边。画面切回。

沈云乔：“我逃了三年，吃尽苦头！可你呢？如今都做诰命夫人了！”

沈云卿：“你真以为……我过得很好？”

沈云卿倒地，画面骤黑。

### 场景二：沈府绣楼｜重生｜18—31 秒

“大小姐！大小姐！”沈云卿猛然睁眼，低头发现手里抱着红绣球。楼下人声鼎沸。

司仪：“沈家二位小姐今日抛绣球择婿！”

沈云卿看向身旁，沈云乔同样脸色惨白、急促喘息。姐妹四目相对，短暂死寂。沈云乔突然抱紧绣球，低声说：“三年前……”两人同时看向楼下，意识到都重生了。

### 场景三：绣楼下｜31—50 秒

年轻俊朗的慕容安站在人群最显眼的位置；另一边角落，一个衣衫破旧的年轻乞丐安静坐着。沈云乔看到慕容安，眼睛瞬间亮了。前世华服、高门大宅、众人跪拜沈云卿的画面快速闪过。

沈云乔心声：“这一世，慕容夫人的位置是我的！”

司仪：“二小姐，请——”

沈云乔抢先冲到栏杆前，把绣球精准抛进慕容安怀里。满场哗然，慕容安抬头，沈云乔笑得志在必得。

### 场景四：沈云卿抛绣球｜50—70 秒

沈云卿抱着绣球走到栏杆前，看着慕容安。前世记忆闪回：慕容安冷着脸把密信扔在桌上：“把这个送进宫。”沈云卿跪在慕容府祠堂，慕容安从她身边走过：“你是沈家的女儿。娶你，本就是为了沈家。”

沈云卿心声：“诰命也好，富贵也罢……这一世，我都不要了。”

她正准备抛球，沈云乔从身后“不小心”撞了她一下：“姐姐小心！”绣球脱手，飞过人群，落进角落乞丐怀里，全场安静。

### 场景五：选择｜70—88 秒

宾客嘲笑沈家大小姐砸中乞丐。沈云乔强忍笑意：“姐姐，这绣球已经落了……你不会反悔吧？”沈父脸色难看：“云卿，重新抛！”

乞丐平静地抬头看她。沈云卿又看一眼慕容安，短暂沉默，把手收回来。

沈云卿：“不用。绣球是我抛的。这个夫君——我认。”

沈云乔笑容僵住。乞丐缓缓起身，第一次露出一丝兴趣。切黑，第一集完。

## 四个统一视频生成提示词

设计原则来自此前 B 站案例的有效做法：明确时长分段、起始状态、镜头顺序、视线关系、动作因果、环境声和结束画面；同时去掉“8K”“电影级”等无法核验的堆词，避免照抄原案例的铁路、末世和武侠场景。四条提示词覆盖不同难点，便于判断平台是在简单转售模型，还是提供了稳定的提示词增强、镜头控制、声音和工作流能力。

### V1：受封宴突变——群像、表演、时间压缩与声音

```
竖屏 9:16，15 秒，古装真人短剧质感，最高画质，人物写实稳定，原生声音开启。场景为白天的沈府受封宴，红绸、宾客、香案与宣旨仪仗构成喜庆但克制的空间。开场 0—5 秒：中景轻微推进，沈云卿穿端庄诰命华服接过圣旨，宾客齐声说“恭喜慕容夫人”，锣鼓和人群声清楚但不盖住台词；画面中暂时不要出现匕首。5—10 秒：从人群边缘切到衣衫破旧、神情憔悴的沈云乔，她盯住姐姐，快步穿过人群，抬手亮出匕首；不要血腥特写，只表现沈云卿受袭后踉跄和宾客后退惊呼。10—15 秒：两人近景对切，视线方向准确对应。沈云卿压住震惊问“云乔……你疯了？”，沈云乔含泪说“凭什么？”最后停在姐妹对视和周围喜宴骤然安静的反差上。保持两名女性的脸、发饰和服装前后一致，动作连贯，中文台词口型自然；无字幕、无水印、无现代物件、无多余人物抢镜、无肢体错误、无突然转场。
```

### V2：双双重生——双人视线、微表情、声画同步

```
竖屏 9:16，15 秒，古装真人短剧质感，最高画质，原生声音开启。场景为三年前的沈府绣楼，晴日，红绸与木栏杆，楼下人群模糊可见。0—4 秒：从沈云卿面部特写开始，她被侍女画外音“大小姐！大小姐！”惊醒，急促吸气，低头发现自己双手抱着红绣球；开场时她必须已经在绣楼上，不能先出现前世宴会。4—9 秒：镜头对切到身旁的沈云乔，她同样脸色发白、呼吸急促，下意识抱紧自己的绣球，低声说“三年前……”。9—15 秒：姐妹二人中近景同框，先互相凝视，再几乎同时转头望向楼下；司仪从楼下清晰喊道“沈家二位小姐今日抛绣球择婿！”风轻轻吹动发丝和红绸，两人的震惊要克制真实，眼神和视线方向必须互相对应。保持两人面容、发型、服装和两只绣球稳定；不要把两人生成成同一张脸，不要提前抛球，不要旁白解释重生，不要字幕、水印、现代物件、闪烁或镜头乱晃。
```

### V3：绣球易主——物体轨迹、群像调度与连续动作

```
竖屏 9:16，15 秒，古装真人短剧质感，最高画质，原生声音开启。沈府绣楼外的择婿现场，楼上两位小姐，楼下人群中央是俊朗的慕容安，角落坐着一位衣衫旧但气质沉静的年轻乞丐。0—5 秒：广角建立空间关系，司仪说“二小姐，请——”，沈云乔抢先一步到栏杆前；此时两只红绣球都还在姐妹手中，慕容安和乞丐手里都没有球。5—9 秒：跟随沈云乔的手臂和红绣球形成一条清楚、连续的抛物线，绣球只落入慕容安怀里一次；人群发出惊叹，慕容安抬头，沈云乔露出志在必得的笑。9—15 秒：切到沈云卿准备抛球，沈云乔从侧后方轻撞她并说“姐姐小心！”，第二只绣球脱手越过人群，准确落在角落乞丐怀里；所有人声突然停下，乞丐平静抬眼。两只绣球必须始终可区分，不能复制、消失、倒飞或换手；人物位置和服装连续，动作符合重力；中文台词和环境声清楚，无字幕、无水印、无现代元素、无肢体畸变。
```

### V4：我认这个夫君——情绪递进、台词口型与结尾钩子

```
竖屏 9:16，15 秒，古装真人短剧质感，最高画质，原生声音开启。绣球已经落在楼下年轻乞丐怀里，现场从安静转为窃笑。0—5 秒：宾客低声议论，沈父在楼上严厉说“云卿，重新抛！”，沈云乔侧身看着姐姐，强忍得意；不要让乞丐跪地或乞求。5—10 秒：沈云卿先看向乞丐，再看一眼远处的慕容安，短暂沉默，神情从犹豫变为清醒坚定；镜头稳定轻推，环境声逐渐降低，为台词留出空间。10—15 秒：沈云卿收回准备接新绣球的手，清楚地说“不用。绣球是我抛的，这个夫君——我认。”沈云乔的笑容立即僵住，楼下乞丐缓缓起身，抬眼看向沈云卿，露出极轻的一丝兴趣，最后在二人隔着楼台对视时切黑。保持角色面容、发饰、服装、绣球位置与前一镜一致；中文口型与音频同步，语气克制，不要字幕、水印、夸张表情、现代物件、镜头跳切或多余台词。
```
