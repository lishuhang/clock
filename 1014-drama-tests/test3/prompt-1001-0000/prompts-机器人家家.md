【视听风格】

 

这一段进入深夜“记忆打印／藏起回忆”的段落。整体气质非常安静、克制，并带一点轻微悬疑感。悬疑不是靠惊悚，而是靠：客厅大灯始终关闭、整个空间几乎沉在黑暗里，只有长茶几上有一盏暖黄色的微弱小台灯，勉强照出一小块局部空间；与此同时，家家口部在工作时又会偶尔泄出一点极其微弱的内部工作光。观众最开始先看到的是一个安静、有人尚未睡去的家庭深夜角落，随后才逐渐发现，原来真正的秘密来自家家自己——它在深夜偷偷打印、翻看并珍藏自己和小也过去的照片。

 

整体保持全片统一的手作定格木偶动画逻辑，12fps「on twos」，动作有明确逐格停顿、微小卡顿和木偶重量感；构图稳定、克制，不做现代顺滑CG运镜，不使用运动模糊，不做恐怖片式频闪。

 

本段的光源重新明确为两层：第一层，是长茶几上的暖黄色微弱小台灯，始终常亮，但亮度极低，只形成一个很小的、稳定的暖光区，主要落在茶几表面、木匣、照片边缘、家家身前一小块区域以及附近局部轮廓上；第二层，是家家嘴部内部在打印照片时隐约可见的工作发光，亮度仍然接近萤火虫，只在一张照片缓慢吐出的过程中轻轻泄出一点，时有时无，比小台灯更局部，也更像机器内部运转的痕迹。两种光叠加后，客厅仍然整体偏暗，不会被照亮成明亮空间。

 

卧室里的微光来源也因此更清楚：不是客厅大灯，也不是未知强光，而是这盏小台灯的极弱暖光，加上家家口部工作时偶尔出现的微弱发光，一同从门那边间接漏过去，在黑暗中留下非常淡的亮度差。

 

小也此时已经是青少年女性，不能过于幼态。这一整场她都没有戴眼镜，因为是半夜刚醒。她本身近视，所以看向客厅时会有一点轻微看不清、发懵、呆呆的状态，但仍然是青少年少女的状态，不是低龄儿童式懵懂。

 

所有照片必须严格保持本片统一的手作木偶画风。照片里的小也要保持各年龄阶段既定木偶形象；家家也保持既定形象；小也的父母是普通人类角色，但依旧是本片统一的手作木偶人类，不是机器人，也不是现实真人。绝对禁止出现真人摄影感照片、写实人脸或与影片完全不同的画风。

 

家家的打印方式不要展示任何独立打印机，也不要展示内部打印结构剖面。只表现家家嘴部工作，一张照片慢慢从嘴里出来；照片完整出来以后，家家非常小心地把它取下来。照片是一张一张打印，而且要连续打印很多张，逐渐形成一小沓。

 

家家对照片的态度必须非常珍惜。不是机械归档，而像老人深夜整理自己一生最宝贵的旧照片一样：打印一张、接住、看一下、放好，再打印下一张；之后再一张一张翻看，整理整齐，最后放进珍藏木匣。

 

全段无旁白，无台词，无影视化情绪BGM。声音主要来自夜间房屋底噪、家家体内极轻的机械工作声、照片吐出的纸张摩擦声、照片翻动声、木匣轻响，以及小也非常轻的起身动作声。

 

第十场A｜深夜悬疑建立＋打印来源揭示

 

镜头51 | 夜晚客厅内景 / 中远景 / 平视机位 / 锁定机位 / 客厅大灯关闭。整个空间几乎沉在黑暗里。摄影机像藏在暗处观察这个房间一样，画面前景一侧有一簇非常虚焦的植物叶子挡住部分视线，只出现模糊叶片，不一定看到花盆，形成一点偷窥感。透过模糊叶片看向客厅。家家坐在沙发区域，背对镜头或略微侧背对镜头。它安静地坐在那里，似乎低着头偷偷忙着什么。它前方的长茶几上放着一盏暖黄色微弱光芒的小台灯，小台灯一直开着，但亮度非常低，只在茶几表面形成一个小小的暖光区，轻轻照出木匣轮廓、茶几边缘和家家背影前侧的极少部分。整个客厅其余区域仍然大面积沉在暗处。停一拍。家家口部附近又极轻地出现一点比台灯更弱、更局部的工作微光，像黑暗里一只很小的萤火虫藏在机器内部，淡淡散出一点光，又很快收回去。只够让口部附近和照片边缘隐约亮一下，绝不照亮整个空间。观众能感觉到：这个房间里除了台灯的微弱暖光，还有另一种更秘密的机器工作痕迹。声音：非常安静的室内夜间底噪、极轻的家家内部机械运转声、若有若无的纸张摩擦声。

 

镜头52 | 夜晚卧室内景 / 中远景 / 略微斜拍平视机位 / 锁定机位 / 切到小也卧室。整个卧室同样非常暗。小也作为青少年女孩，没戴眼镜，正躺在床上睡觉。画面不要直接展示门缝本身，而只表现从门口方向漏进来的极微弱光痕。这点光不亮，不刺眼，而是长茶几小台灯的极弱暖光在黑暗中间接漏进来，同时叠加家家嘴部偶尔工作时那一点若隐若现的微光，因此这层光感是很淡的、时而稍稍明显一点、时而几乎看不见。它轻轻落在靠近门的墙边、地面边缘，并且若隐若现地漏到小也被子的局部表面，形成一小片非常淡的亮度差。除被子上的这一点点微弱光感之外，卧室其他阴影处仍保持黑暗。远处传来很轻的机械声和纸张摩擦声。小也还睡着。停一拍。再次传来类似打印般的声音。她慢慢睁开眼睛。因为刚睡醒、又近视没戴眼镜，她望向门的方向时眼神有点发懵、没有完全对焦。她没有一下坐起来，先躺着听，停一拍，随后慢慢撑起一点上半身，像想出去看看外面到底在做什么。声音：卧室极轻夜间底噪、远处打印声、床铺与被子轻微摩擦声。

 

镜头53 | 夜晚卧室门口 / 中近景 / 平视机位 / 锁定机位 / 前景是门板与门框。画面左侧或一侧大部分被门遮挡。青少年小也从门后慢慢探出一点头，再探出一点肩膀和上半身。她没有戴眼镜，刚起床，眼神因为近视和困意显得有一点看不清、呆呆的。她安静地往客厅方向看。客厅里那盏暖黄色小台灯的极弱底光，让门板边缘、她脸侧和肩膀有一点非常轻的暖色轮廓；与此同时，家家口部那点萤火虫般更微弱的工作光又偶尔轻轻掠过，使光影有极细微的变化，但不能把她整张脸照亮。她眯着一点眼，像在努力辨认黑暗里的东西。不说话，也不走出去，只是藏在门后悄悄看。身后的卧室继续完全沉在暗处。声音：打印机械声比上一镜稍近一点，纸张从某个地方慢慢出来的摩擦声也更加清楚。

 

镜头54 | 夜晚客厅内景 / 中近景 / 平视机位 / 锁定机位 / 这一镜正式揭示前几镜那种微弱工作光和打印声的来源。给家家的上半身中近景。长茶几上的小台灯在画面下方或侧前方提供非常弱的暖色底光，轻轻照到茶几局部、木匣和家家的手部下缘，但依然不亮。家家低下头。机体内部传来很轻的运转声。嘴部缓慢打开。一张照片从家家的嘴里一点一点地出来。先露出一小截照片边缘，继续缓慢送出来。每当照片向外移动时，家家嘴部内部都隐约可见一点极微弱的发光，像机器深处在工作，亮度接近萤火虫，比台灯更微小、更集中。绝不出现明显亮斑，也绝不照亮家家的整张脸。照片完全出来以后，内部微光也随之减弱。家家用正常的左手非常轻地把照片拿下来，动作很小心，像生怕照片被折到。停一拍。家家低头看照片。内容此时可以不完全看清，只建立：家家自己刚刚打印了一张照片，而且它非常珍惜。声音：机体内部低低打印声、纸张缓慢滑出的摩擦声、打印停止后的短暂安静。
