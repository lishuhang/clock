## 0. 阅读指南：前情提要

**这个文档在做什么**：给"漫剧智能体横评"设计一套 v2 测试提示词与配套资产。横评在 11 家平台用统一模型（Seedance 2.5 / 2.0）跑同样的提示词，检验"模型相同，不同平台为何出片不同"——即各平台是否有前置的 prompt harness（系统提示词、提示词改写器、模型路由、后处理管线等）。本版按受访创作者的反馈，把测试重构为「文生 / 多参 × 文戏 / 武戏」四段矩阵，并尽可能覆盖 Seedance 2.5 的独有功能点，用于挑出各平台硬伤。

### 0.2 核心测试假设（为何要测 prompt 依从度）

我们的测试不是测模型能力（模型统一是 2.5 / 2.0），而是测**平台 harness**。社区讨论（抖音、B 站、即刻、新片场、v2ex、英文社区）归纳出"同模型不同平台结果差异"的九类成因：

1. **系统提示词不同**——平台在背后附加的规则不同（"你以为在比较模型，其实在比较产品经理写的规则"）；
2. **提示词改写器（prompt rewriter/enhancer）**——平台用另一个 LLM 改写用户 prompt 再喂给模型，且常默认开启；第一方佐证：小云雀官方文档写明"智能意图解析：输入一句核心需求即可自动输出脚本/分镜"；
3. **模型路由与同名不同档**——漫剧行业已有爆料：fast 版冒充标准版、按提示词难度路由小模型、480P 超分拉成 720P；
4. **上下文截断**——超长 prompt 被截断，负面约束段最常被丢；
5. **采样参数默认值不同**（需 4 次抽样排除）；
6. **后处理管线**（超分、插帧、音画分离重混）；
7. **审核合规过滤**（IP 限制收紧会降低自由度）；
8. **灰度实验**（不同账号不同策略）；
9. **产品链路差异**（小云雀智能预演/3D 导演台/涂鸦引导线，ShotLab 画布/导演台等前置交互）。

v2 的提示词设计原则因此是：**写得越像"拍摄执行单"（镜头、时间轴、动作轨迹、声音层级、禁令都写死），平台 harness 一干预就越容易变形，差异就越可观测**。马良 AIGC 社区结论与之一致。

### 0.3 本轮输入（创作者与编辑反馈）

- **半仙黃（Hwang）**：建议测"文戏 + 武戏"两类；文生视频也要带两个人物参考测文戏武戏；多参生视频（附带人物/道具/场景参考）测文戏武戏——即 **4 块：文生文戏、文生武戏、多参文戏、多参武戏**，每平台测 4 个就够；可用电影片段复刻提示词。
- **lishuhang（航通社）**：确认矩阵为"文生、普通量参考图文戏、武戏、多参考图"；提出是否要多转场、大动作、台词对白、字体、更多参考。
- **虎皮尖椒（编辑）**：三个技术疑问——① 秒级时间轴是否准确（v1 只有 T4 有）；② 15 秒分镜太少，可能测不出平台区别；③ 多分镜是不是 s2.5 功能点？具体描述时间轴 vs 自由发挥如何分配（猜测：文生自由发挥，多参武戏固定时间轴）。
- **Seedance 2.5 官方信息**：单次最多 50 个参考素材（图片 ≤30、视频 ≤10、音频 ≤10），详见第 2 节功能点盘点。

### 0.4 本版裁定（对编辑三问的回答）

| 编辑疑问 | 裁定 | 理由 |
|---|---|---|
| 秒级时间轴准不准 | 准，且是 2.5 官方支持的"时间戳级控制"用法 | 官方文档明确：生成阶段可用 prompt 控制特定时间段的叙事、镜头视角、运动与节奏 |
| 15 秒分镜太少 | 加密到 15s / 7–8 镜，另加 30s 加测段 | 多镜头+自然转场正是 2.5 的"镜头级规划"能力；分镜密度低则平台差异被抹平 |
| 多分镜是不是 2.5 功能点 | 是 | 官方："30 秒内组织多个逻辑衔接的镜头，起承转合展开故事"；2.5 自动处理自然剪切与转场 |
| 时间轴 vs 自由发挥如何分配 | **文生段=事件节拍式（不锁秒），多参段=秒级固定时间轴** | 文生无参考锚点，固定秒轴也难以验证，节拍式更能暴露平台自发叙事组织能力与改写痕迹；多参有参考图/音频作锚点，固定秒轴可实现严格依从度比对。与编辑猜测一致，并补充"多参文戏同样固定时间轴" |

## 1. Seedance 2.5 功能点盘点（v2 覆盖依据）

来源：字节跳动 Seed 官方博客《One-take Creation, Flexible Referencing》、火山方舟模型详情页、BytePlus Lumina 产品页。

| # | 功能点 | 官方表述要点 | v2 如何测试 | 平台 harness 可干预点 |
|---|---|---|---|---|
| 1 | **单段 30 秒直出 + 多轮延长** | 单次前向生成最长 30s，支持多轮续接，保持角色/环境/节奏一致 | T5 加测段（30s，仅 2.5 平台）；多轮延长列为可选扩展 | 平台是否真给 2.5、是否截断为 15s、是否自动分段拼接 |
| 2 | **最多 50 参考素材**（30 图 + 10 视频 + 10 音频） | 图/视频/音频自由组合，一次输入 | T3/T4/T5 挂 3 角色图 + 1 场景图 + 1 道具图 + 1 音频参考（6-7 个）；压测上限列为可选扩展 | 平台参考数上限（有的平台只收 1 图/拒音频），超限行为（报错/丢弃/降级） |
| 3 | **多镜头叙事（镜头级规划）** | 30s 内组织多个逻辑衔接镜头，起承转合；自动处理自然剪切与转场 | T3 7 镜、T4 8 镜（15s 密集分镜）；T5 起承转合四段式 | 平台是否执行镜头数/转场（合并镜头、加无意义镜头、跳切） |
| 4 | **时间戳级叙事控制** | 用 prompt 控制特定时间段的叙事、镜头、运动、节奏 | T3/T4/T5 秒级时间轴 prompt | 平台是否忽略秒级指令、是否被 rewriter 抹平 |
| 5 | **长时间一致性** | 角色身份、视觉风格、镜头节奏、场景逻辑长时保持 | T3/T4/T5 要求三木偶外观/服装/场景跨镜连续 | 角色漂移、服装换色、场景突变（平台后处理/分段拼接会破坏） |
| 6 | **多模态参考类型升级**（clay render / motion / creative） | 白模参考可控制空间结构、姿态、运动路径、镜头角度；照明遵循物理法则 | 本轮用成品三视图做角色参考（R2V）；白模 clay render 测试列为 v3 可选项 | 平台是否支持多图角色参考，是否歪曲角色外观 |
| 7 | **原生声音 / 音画同步** | 音频-视频联合生成，对白/音效/BGM 分离可控，音画同步 | 全段带声音设计；T1 对白、T2 音效、T3/T4 挂音频参考、T5 完整声场 | 平台是否丢对白、BGM 失控、音画错位、是否忽略音频参考 |
| 8 | **原生多语言** | 原生支持生成 10 余种语言 | 可选：T1/T5 对白可换英文测多语言 | 平台是否正常输出外语对白 |
| 9 | **物理真实**（重力/碰撞/轨迹） | 衣袖、水袖弧线贴近真实物理 | T2/T4 齿轮飞溅/滚动/接住（轨迹连续不瞬移），T5 暴走物理 | 物体穿模、瞬移、反重力（后处理或低档模型特征） |
| 10 | **减少失控字幕/BGM** | 系统优化字幕与 BGM 的不可控出现 | 全段禁令：无字幕、无 BGM | 平台是否仍给视频加字幕/水印/自动 BGM |
| 11 | **编辑能力**（时间戳编辑/绿幕/视角） | 生成后按时间戳精准修改 | 不在横评主测范围，列为 v3 可选 | — |

**说明**：s2.5 与 2.0 的能力差距集中在 1/3/4/6/8（30s 单段、镜头级规划、时间戳控制、白模参考、多语言）。这些点必须在 prompt 里显式出现，才能区分"平台给的是 2.5 还是 2.0（或 fast 冒充）"。

## 2. v2 测试矩阵

四段主测（全部 15s，所有平台可比）+ 一段加测（30s，仅 2.5 平台）。

| 段 | 生成方式 | 戏型 | 时间轴 | 参考素材 | 声音设计 | 首要探测点 |
|---|---|---|---|---|---|---|
| **T1 深夜来客** | 文生（0 参考） | 文戏 | 事件节拍式（自由发挥） | 无 | 对白 + 环境声 | 纯文生叙事组织、对白口型、rewriter 干预痕迹 |
| **T2 发条暴走** | 文生（0 参考） | 武戏 | 动作序列式（自由发挥） | 无 | 机械音效 + 环境声 | 大动作、物理/轨迹、自发转场运镜 |
| **T3 取钟的人** | 多参（图+音频） | 文戏 | 秒级固定（7 镜） | 3 角色图 + 场景图 + 音频 | 对白 + 环境音参考 | 多角色一致性、分镜依从、音频参考遵循 |
| **T4 齿轮惊魂** | 多参（图+音频） | 武戏 | 秒级固定（8 镜） | 3 角色图 + 场景图 + 齿轮图 + 音频 | 机械音效参考 + 环境声 | 物体轨迹、群像调度、连续大动作、分镜依从 |
| **T5 暴走的钟（加测）** | 多参（图+音频） | 长叙事 | 起承转合（30s） | 3 角色图 + 场景图 + 齿轮图 + 音频 | 完整声场（环境+对白+音效） | 30s 单段、镜头级叙事、长时间一致性、转场 |

**矩阵逻辑**：
- **文生 × 文戏 / 武戏**：无参考锚点，测平台"文本→镜头"的理解与组织能力；用节拍式/动作序列式，让平台自由发挥，观察其自发选择的分镜数、转场方式、叙事结构——这是 rewriter 改写痕迹最容易暴露的场景。
- **多参 × 文戏 / 武戏**：有图/音频锚点，用秒级固定时间轴做严格依从度测试；任何镜头缺失、合并、时序错误、角色漂移、音频参考丢失都可量化记分。
- **武戏**（T2/T4/T5）承担大动作、物理、轨迹、群像、运镜功能点；**文戏**（T1/T3）承担对白、口型、情绪、长镜头功能点。
- 关于"用电影片段复刻提示词"：为避免版权问题，武戏的动作结构借鉴经典追逐/闪避/对抗/收尾范式（如官方示例中的京剧水袖弧线物理），但场景、角色、情节全部原创于钟表铺世界观。

## 3. 四段测试提示词（+加测段）

> 通用风格基底（每段开头使用）：**手作发条机械木偶动画风格，木质发条木偶角色（黄铜关节、漆面五官、深色玻璃珠眼睛、哑光木漆面、关节铰链可见），深夜钟表修理铺内景，暖黄台灯光 + 冷调环境光**。
> 通用禁令（每段结尾使用）：**不要字幕、水印、现代物件、肢体畸变、镜头跳切；无 BGM，仅环境声与机械声**（T3/T4/T5 按场景微调）。
> 提交口径：竖屏 9:16，15 秒（T5 为 30 秒），最高画质，原生声音开启；每段每平台跑 4 次。

### T1 深夜来客（文生 · 文戏 · 事件节拍式）

```
深夜钟表修理铺，手作发条机械木偶动画风格，竖屏 9:16，15 秒，最高画质，原生声音。

开场：深夜，暖黄台灯下，木偶学徒独自在柜台后擦拭柜台，墙上挂钟滴答作响，木轴关节偶尔发出吱呀声。
事件一：一位穿白领衬衫的木偶顾客推门进店，门铃轻响，学徒抬头，放下抹布。
事件二：顾客把取钟单放在柜台上，学徒转身从身后架子上取下一只修好的黄铜挂钟，小心地放上柜台。
事件三：顾客低头端详挂钟，点头说："修得真准。"学徒腼腆地回答："是师傅的手艺。"
事件四：顾客从口袋里摸出几枚黄铜硬币，学徒认真数过，放进柜台的钱匣。
收尾：顾客抱起挂钟转身出门，学徒望着门口，挂钟滴答声渐响，画面停在学徒微笑的侧脸特写。

要求：木偶关节动作符合机械木偶的运动逻辑，台词清晰、口型与声音同步；声音只有环境声（钟摆、门铃、木轴关节声）与对白，无 BGM；不要字幕、水印、现代物件；镜头与分镜请按故事节奏自然组织，允许自由转场。
```

**判定要点**：镜头数（2.5 应有 5 个以上自然镜头）、事件是否按顺序执行、对白是否完整且口型同步、结尾特写是否出现、是否有字幕/BGM 失控。

### T2 发条暴走（文生 · 武戏 · 动作序列式）

```
深夜钟表修理铺，手作发条机械木偶动画风格，竖屏 9:16，15 秒，最高画质，原生声音。

开场：老匠在柜台后给一只落地大挂钟上发条，学徒踮脚在旁边看，挂钟机芯发出规律的上弦声。
发展：学徒趁老匠转身，好奇地用力多拧了几圈发条——机芯突然发出刺耳的金属崩裂声，发条崩断弹出，齿轮从机芯里飞溅而出，挂钟指针疯狂乱转。
高潮：学徒抱头蹲下躲避飞散的零件，一枚齿轮擦着他头顶飞过，钉进身后的木墙；老匠一个箭步跃上柜台，把发条钥匙猛地插进机芯卡住齿轮，机芯剧烈抖动后戛然而止。
收尾：零件散落一地，挂钟指针缓缓停下，老匠和学徒在狼藉中对视，学徒心虚地低头。

要求：动作激烈但不失真，飞溅的齿轮遵循重力与碰撞，运动轨迹连续、不得瞬移或复制；运镜自由，允许手持晃动、快速推拉与节奏性转场；声音以机械音效为主（发条崩断、齿轮碰撞、木料撞击、关节咔嗒），无 BGM；不要字幕、水印、现代物件；木偶肢体不要畸变。
```

**判定要点**：动作是否连续成段（而非静态摆拍）、齿轮轨迹物理是否真实、转场/运镜是否自然、音效是否与动作同步、是否出现肢体畸变。

### T3 取钟的人（多参 · 文戏 · 秒级固定时间轴 7 镜）

```
深夜钟表修理铺，手作发条机械木偶动画风格，竖屏 9:16，15 秒，最高画质，原生声音。
角色参考：@image1 为老匠（灰蓝旧布衣木偶），@image2 为顾客（白领衬衫木偶），@image3 为学徒（深灰 T 恤木偶）；@image4 为钟表铺柜台场景；@audio1 为钟表铺环境音基调，全程保持钟摆与木轴关节的环境声底。

固定分镜时间轴：
0–2 秒，全景：深夜钟表铺柜台，老匠在柜台后低头修钟，学徒在旁整理工具，顾客推门进来，门铃响（场景参考 @image4）。
2–4 秒，中景：顾客走到柜台前，把取钟单放在台面上，老匠抬头，放下螺丝刀。
4–6 秒，特写：老匠从身后架子上取下一只修好的黄铜挂钟，放上柜台，指针轻轻走动。
6–8 秒，近景：顾客低头看钟，点头说："修得真准，多少钱？"老匠伸出三根木手指。
8–10 秒，中景：学徒接过顾客递来的黄铜硬币，认真数完，放进柜台钱匣。
```

### 5.4 硬伤判据速查（由判定要点汇总）

- **给的是不是 2.5**：30s 请求被截 15s、分镜合并到只剩 1–2 个镜头、无法生成多镜头转场、拒绝音频参考；
