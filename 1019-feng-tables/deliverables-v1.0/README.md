## 三、数据溯源与勘误（OVERRIDE 记录）

source-data.csv 逐行记录数值来源与核验状态：**verified 179 行 / estimated 84 行**。

- verified：正文数字、CSV、行和约束（每行六维和=100）、多图互证直接锚定。
- estimated：源图无量纲标注，按几何/像素标定反推（img06 五维、img14 热力格等），已在 notes 列写明推算方法与误差范围。

**唯一人工勘误（OVERRIDE）**：img14《芳华》"其他"一格，源图标签 56% 为笔误——行和约束证明 56 不可能（六格和将超 100），几何实测 36.5%，交付按 **36%** 记录。其余全部从源数据直录，未做任何改动。
