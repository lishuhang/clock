# 剪映工程导入说明

## 工程内容
- `draft_content.json` + `draft_meta_info.json`：剪映草稿（1080x1920竖屏，30fps，总时长约3分钟）
- `assets/`：工程引用的全部素材（41个视频片段、韩红音频、修正后配音、片尾图）

## 导入步骤
1. 把整个 `剪映工程_抓特务口碑反转` 文件夹复制到剪映草稿目录：
   - Windows: `C:\Users\<用户名>\AppData\Local\JianyingPro\User Data\Projects\com.lveditor.draft\`
   - macOS: `~/Movies/JianyingPro/User Data/Projects/com.lveditor.draft/`
2. 打开剪映 → 草稿列表会出现「剪映工程_抓特务口碑反转」
3. 若素材显示"媒体丢失"：右键任一丢失素材 → 「重新关联素材文件」/「媒体丢失」→ 定位到 `assets` 文件夹 → 全选重链（素材文件名与工程内一致，可一次性重链）

## 轨道结构
- 视频轨：40个镜头（硬切），电影片段为原比例画面（可在剪映里自行放大裁切到4:3），图表为1080x1080
- 音频轨1：韩红原声（0-6.2s，源=走个面完整版182.7s处，即"咱北京的兄弟姐们…走个面"）
- 音频轨2：解说配音 `voice_fixed.wav`（6.2s起，已替换3处错读：46.5%混合型/演员节奏/46.1%→56%）
- 文本轨：109条字幕（思源黑体、白字黑边、字号9、居中偏下），可在剪映里统一改样式

## 已知事项
- 电影片段画面为16:9原比例放入竖屏（上下黑底），按工作文档建议可放大到4:3/1:1，剪映里选中片段→裁切/缩放即可
- `voice_fixed.wav` 由原TTS拼接3句重录生成（拼接点有5ms交叉淡化，已ASR验证）
- 成品参考mp4：`../抓特务口碑反转_成品_v1.mp4`
