### 4. 图表生成流程
1. 用 Python 脚本生成单页 HTML（内联 SVG，最简样式）
2. 用 Playwright 截图为 PNG（`device_scale_factor=2` 出 2 倍 DPI 高清）
3. 关键参数：viewport `{"width": 900, "height": 1200}`（3:4 信息图）或 `{"width": 1200, "height": 2400}`（1:2 长图）

### 5. 矢量图数据严格性
- 所有柱状图柱子高度 = `plot_h * value / y_max`（按比例计算）
- 所有折线图点坐标 = `plot_h * (value - y_min) / (y_max - y_min)`
- 所有饼图扇形角度 = `2π * value / total`
- 不要"美化"数据，比例必须严格对应

## 五、遇到的问题与踩坑记录

### 1. 工作区每次会话被清空
**问题**：`/home/z/my-project/workspace/clock/` 目录在新会话开始时不存在，需要重新 git clone。
**解决**：每次会话开始先 `git clone`，然后 `git pull` 拉最新。

### 2. VLM 视觉检查频繁限流
**问题**：用 `z-ai vision` 命令检查 PNG 渲染效果时，经常返回 429 限流或 context deadline exceeded。
**解决**：
- 加 `sleep 60-120` 等待
- 简化 prompt（用最短问题）
- 限流时改用 grep 检查 HTML 结构验证（如 `grep -c 'image href'` 确认 logo 嵌入数量）

### 3. styleguide v2.20 文件过大
**问题**：v2.20-yz-styleguide.html 有 22 万行，无法整体读取。
**解决**：用 `sed -n 'START,ENDp'` 分段读取；用 grep 定位关键 CSS 规则和 SVG symbol 边界。

### 4. 水印 z-index 问题
**问题**：v1 信息图水印 z-index:1，被 z-index:2 的 header/grid/footer 压在下面，水印被 6 个小图盖住看不见。
**解决**：v2 改为 z-index:9999，水印位于所有内容之上，opacity 保持 0.1 让下层可见。

### 5. 字体在手机竖屏看不清
**问题**：1:2 长图在手机竖屏显示时宽度被压缩到约 30%，原来 14px 字体在手机上只有 4.2px。
**解决**：所有字号放大 ~1.8 倍（CSS 字号 + SVG font-size 属性都要改）。SVG 字号映射：11→24, 12→26, 13→28, 14→30, 16→34。

### 6. WebP/SVG logo 转 PNG
**问题**：作者提供的 logo 是 webp/svg 混合格式，需要统一处理。
**解决**：
- webp 用 PIL 转 PNG
- svg 用 `cairosvg -W 800` 转PNG
- 用 PIL `getbbox()` 自动裁剪透明边框
- 按用途缩放：世界杯 logo 高 200px（柱状图标签用 130px），电视台 logo 高 80px
- 最终嵌入 HTML 用 base64 data URI（避免外部文件依赖）

### 7. seatplan.png 颜色识别
**问题**：作者要求"根据图例颜色重新设计场地图"，但不知道 seatplan 各区域颜色对应。
**解决**：用 VLM 识别 seatplan 颜色含义——Cat 1 金色（内圈）、Cat 2 红色、Cat 3 蓝色、Cat 4 绿色，然后用相同颜色做图例。

### 8. 历届世界杯 logo 嵌入柱状图
**问题**：作者要求"世界杯年份用该届 logo 代替"。
**解决**：
- 把 2014/2018/2022/2026 logo 作为 `<image href="data:image/png;base64,...">` 嵌入 SVG
- logo 放在柱子下方居中，高度 130px，下方再标注年份文字
- margin_b 加大到 220px 给 logo 留空间

### 9. 饼图图例重叠
**问题**：v1 饼图图例标题在 y+20，数值在 y+30，只差 10px 严重重叠。
**解决**：v2 图例每行 90px 间距，标题在 y+20，数值在 y+50，彻底分开。

### 10. p09 横排改竖排
**问题**：v1 p09 是水平柱状图，与其他竖排图表不一致。
**解决**：v2 改为竖排柱状图，电视台 logo 放在柱子下方（高 70px），下方再标注国家/地区文字。

### 11. 决赛比分核查
**问题**：用户最初提到"阿根廷点球 4-2 胜西班牙"，但 research 子代理发现网上有矛盾说法（"2-1"和"4-2 点球"都有）。
