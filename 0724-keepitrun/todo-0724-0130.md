**规避方法**: 只能使用已知的 7 个 album_id。如需发现新合集，需用户提供或从文章页面底部的"合集"链接提取。

### 2. restore commit 的副作用

`f2a7f5b` (2026-07-05) 的本意是恢复 137 篇丢失图片引用的博客文章，但恢复脚本按 git history 查找时，把已删除的 daily 文件也一起恢复了。

**教训**: 恢复类脚本应额外检查文件是否应存在（如按 slug 模式过滤 daily 文章），不能盲目按 git history 恢复。

### 3. VERSION_TASK_CHANGES 缺少 v1.10-v1.13 条目

v1.14 的 `VERSION_TASK_CHANGES` 字典从 `"1.9"` 直接跳到 `"1.14"`，缺少 v1.10-v1.13 的条目。

**影响**: 仅影响从 v1.9 或更早版本直接升级到 v1.14 的用户（会漏触发 v1.10-v1.13 的任务）。从 v1.13 升级到 v1.14 不受影响。

**v1.15 未修复此问题**（避免引入不必要的任务触发）。如需修复，可补全 v1.10-v1.13 的条目，但需评估每个版本的实际变更。
