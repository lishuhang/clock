▶API · AI Agent 调用说明

本站提供纯 HTTP 上传接口：AI Agent / 脚本无需打开或操作本页面，直接 POST 即可获取永久图片外链。无需登录、无需 Cookie、无 token。

接口定义

方法POST /upload
Content-Typemultipart/form-data
字段 img图片文件（必需；亦接受 file / upfile）
字段 channel可选渠道：HX（默认）/ JM / PP

调用示例

curl -F "img=@photo.png" -F "channel=PP" https://imgbd.lishuhang.com/upload

# Python
import requests
r = requests.post("https://imgbd.lishuhang.com/upload",
    files={"img": open("photo.png","rb")},
    data={"channel": "PP"})
print(r.json()["url"])   # -> 永久外链

响应（JSON）

{"result": 1, "msg": "文件上传成功", "url": "https://...", "channel": "PP"}
# 失败: {"result": 0, "msg": "原因..."}

渠道差异

channel支持格式限制
HXPNG / JPG≤10MB；网页 <img> 引用建议加 referrerpolicy="no-referrer"
JMPNG / JPG / GIF≤10MB；无防盗链；有频率限制（约 10 秒 1 张）
PPPNG / JPG / GIF / WebP / BMP≤10MB；无防盗链

机器可读接口清单：GET /api（JSON）· GET /llms.txt（纯文本）。Agent 可将其注册为图片上传 skill：输入本地图片文件，输出可公开访问的图片 URL。
