## 1. 本次完成的工作（增量）

### 1.1 抖音 adapter（✅ 完整跑通）

**探查发现**：
- 视频上传：`input[type=file][accept*='video']`（class `upload-btn-input-UY_qeY`）
- 标题：`input[placeholder*='填写作品标题']`，限制 30 字
- 简介：`div[data-slate-editor=true][contenteditable=true]`（**Slate 富文本编辑器**）
- 封面：上传后弹出裁剪窗口，需点"完成"
- 存草稿按钮：文字是"**暂存离开**"（不是"存草稿"），class `cancel-btn-zy_rHA`

**踩坑与解决**：
1. **简介 selector 超时**：wait_for_selector(state=visible) 超时 5 秒 ×3 个 selector
   - 解决：改用 `page.evaluate` 直接 focus contenteditable 元素
2. **封面裁剪弹窗阻挡**：上传封面后弹出"设置封面"窗口
   - 解决：增加 `_close_cover_editor()`，点"完成"按钮
3. **存草稿按钮找不到**：文字是"暂存离开"不是"存草稿"
   - 解决：从 HTML 快照 grep 分析找到 `<button class="cancel-btn-zy_rHA">暂存离开</button>`

**实测结果**：✅ status=success，URL 跳转 `content/upload`（草稿页）

### 1.2 小红书 adapter（✅ 完整跑通）

**探查发现**：
- 视频上传：`input.upload-input[accept*='mp4']`
- 标题/简介：contenteditable（小红书无独立标题框，标题+简介都填同一处）
- 存草稿：Web Component `<xhs-publish-btn save-text="暂存离开">`

**踩坑与解决**：
1. **Shadow DOM 不可访问**：`<xhs-publish-btn>` 是 closed shadow root，`el.shadowRoot` 返回 null
   - 解决方案 1：Playwright piercing selector `xhs-publish-btn >>> button`
   - 解决方案 2（实测有效）：用 `getBoundingClientRect` 取按钮坐标，`page.mouse.click(x, y)` 点左侧 25%（暂存按钮通常在左）
2. **话题含特殊符号被拒**：v0.2 中的点号触发"话题内不允许包含特殊符号"错误
   - 已知问题，编辑需注意话题命名

**实测结果**：✅ status=success，坐标点击 (458, 755) 成功

## 2. 踩坑与突出问题（增量，下一个 agent 必读）

### 5.19 抖音/小红书存草稿按钮叫"暂存离开"
- 抖音和小红书的存草稿按钮文字都是"**暂存离开**"（不是"存草稿"）
- 通用 selector 应包含 `text=暂存离开`

### 5.20 抖音简介用 Slate 富文本编辑器
- selector：`div[data-slate-editor='true'][contenteditable='true']`
- `wait_for_selector(state=visible)` 会超时
- 解决：`page.evaluate` 直接 `el.focus()` + `page.keyboard.type()`

### 5.21 小红书 Web Component closed shadow DOM
- `<xhs-publish-btn>` 是 closed shadow root
- `el.shadowRoot` 返回 null，无法用 JS 穿透
- Playwright piercing selector `>>>` 可能无效（实测未确认）
- **有效方案**：用 `getBoundingClientRect` 取宿主元素坐标，`page.mouse.click(x, y)` 点相应位置

### 5.22 快手无独立标题框
- 快手只有"作品描述"（`#work-description-edit` contenteditable）
- 标题+简介都填这里
- selector：`#work-description-edit` 或 `[id*='work-description']`

### 5.23 快手引导教程 tooltip
- 上传视频后弹出 4 步教程
- Skip 按钮：`div[title='Skip']`
- 下一步按钮：`._tooltip-btns_d7f44_63 ._button-primary_3a3lq_60`

### 5.24 抖音封面裁剪弹窗
- 上传封面后弹出"设置封面"窗口
- 需点"完成"按钮关闭
- selector：`text=完成`

### 5.25 话题含特殊符号被拒
- 小红书话题含 `.`（如 v0.2）会被拒绝
- 编辑需注意话题命名，避免特殊符号

### 5.26 测试超时处理
- bash 工具默认 120 秒超时，不够完整测试
- 用 `timeout 200 python3 script.py` 确保
- 或后台运行 + 轮询检查
