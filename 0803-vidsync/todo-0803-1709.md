### 5.5 B站 adapter selector 问题
- **封面上传**：当前 selector `.cover-upload input[type=file]` 等都不对。B站实际 UI 是一个"添加主封面"按钮，点击后才出现 file input。修复方案：
  ```python
  # 先点击"添加主封面"按钮
  page.click("text=添加主封面")
  # 然后等 file chooser
  with page.expect_file_chooser() as fc_info:
      page.click("text=添加主封面")
  fc = fc_info.value
  fc.set_files(cover_path)
  ```
