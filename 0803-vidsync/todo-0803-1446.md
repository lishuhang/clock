### 3.3 核心调研结论（下一个 agent 必读）

#### A. 已有工具盘点
- **最佳底座**：`dreammis/social-auto-upload`（14k stars，MIT，Python+Playwright，覆盖 13 个平台中的 6 个：抖音/B站/小红书/快手/视频号/百家号）
- **架构参考**：`hanliang97/MatrixMedia`（GPL-2.0，不能直接 fork，但 MCP server + HTTP API 设计值得借鉴）
- **法律警示**：`SocialSisterYi/bilibili-API-collect` 已于 2026 年 1 月被 B站律师函下架归档。**反编译 API 集合有法律风险，应走浏览器自动化路线**
- **SaaS 路线**：蚁小二、融媒宝、易撰等**均不开放 API**，是封闭商业生态，不可走

#### B. 平台覆盖缺口
7 个平台在已有开源工具中**完全无覆盖**，需要自建 adapter：
- 微博视频、腾讯视频、喜马拉雅、虎嗅、36氪、支付宝生活号、企鹅号

#### C. 用户提到的格式差异已全部核实
- ✅ B站 + 虎嗅 横屏封面（B站 1146×717；虎嗅 800×450）— **已确认**
- ⚠️ 36kr / 腾讯新闻 二次裁剪 — 腾讯系确认有裁剪；36kr 因 misopen 是 JS SPA，需实际测试才能确认裁剪规则
- ⚠️ 36kr 最多 5 个标签 — 业界常引述但官方文档未明示
- ✅ B站 10 个标签 — 已确认
- ✅ 微博 #话题# 双 # — 已确认（学术来源 PMC7856455）

#### D. 新发现的关键差异（用户未提及但重要）
- **B站草稿 10 天过期** — 不能作为长期存储，编辑需及时复核
- **抖音 55 字标题含 #话题** — 实际可用仅 30-40 字，预算很紧
- **支付宝生活号** 是 13 个平台中**唯一官方 OpenAPI 最完善**的，强烈建议走 API 而非浏览器
- **小红书** creator.xiaohongshu.com 海外 GeoIP 被封，需用 creator.rednote.com 备用域名
- **企鹅号** Chrome = 4GB 上限，其他浏览器只有 500MB（必须用 Chrome）
- **视频号** Chrome 不支持 H.265 上传，需转 H.264
- **微博标题 ≥6 字**（罕见最低限制）
- **小红书** 有 A/B 封面测试机制（1 默认 + 3 PK，10 小时后系统选 CTR 最高的）
- **抖音** 中央网信办 2025 新规：6 类必选标签（AI 生成/虚构演绎/时事信息等）

#### E. 平台难度分层（用于排期）
- **Tier 1（已有 adapter，1-2 周）**：抖音、B站、快手、小红书
- **Tier 2（可适配，2-3 周）**：视频号、百家号、支付宝（OpenAPI）、企鹅号（RSS sync）
- **Tier 3（自建，2-3 周）**：微博、腾讯视频、喜马拉雅（OpenAPI）
- **Tier 4（半自动，1 周）**：虎嗅、36氪（编辑审稿平台，无法完全自动化）

## 5. 踩坑与突出问题（下一个 agent 必读，避免重蹈）

### 5.1 凭据管理红线
- **绝不在 todo / 代码 / commit message / 注释 / 文档里出现任何明文凭据**
- 凭据存本地 `/home/z/my-project/secrets/credentials.env`（chmod 600）

- 下一个 agent 接手前先 `source /home/z/my-project/secrets/credentials.env` 加载凭据到环境变量

### 5.2 GitHub commit 频率
- 用户明确要求"避免过多 commit 冲击 GitHub"
- **每次工作会话只 commit 一次**，把所有改动一次性 push
- 不要为每个小文件单独 commit

### 5.3 反编译 API 法律风险
- 不要使用 `SocialSisterYi/bilibili-API-collect` 等已被下架的反编译 API 集合
- 走浏览器自动化（Playwright + patchright）路线，法律风险最低
- B站 WBI 签名用 `biliup` 这个 pip 包处理（社区维护，未被下架）

### 5.4 平台 UI 易变
- 平台前端 selector 经常变，adapter 必须内置 health check
- selector 失效时截图 + 写入报告，让编辑手动 fallback
- 不要 hardcode selector，建议用 `data-testid` / `aria-label` / 多 selector fallback

### 5.5 小红书特殊处理
- 海外 GeoIP 封锁 creator.xiaohongshu.com，必须用 creator.rednote.com
- 检测 Electron/Headless，必须用 patchright + 真实 Chrome 模式

### 5.6 抖音二次验证
- 抖音偶尔要 SMS 二次验证，social-auto-upload 用 `verify_code.txt` 机制
- 编辑同事需要在 CLI 提示时手动输入验证码到指定文件

### 5.7 视频号 H.265
- Chrome 上传 H.265 会失败，必须先转 H.264
- 建议在 processors/video.py 加自动转码（ffmpeg）

### 5.8 支付宝 & 喜马拉雅
- 这两个平台**走 OpenAPI 而非浏览器**，更稳定
- 操作员需要去对应开放平台申请 app_id / client_id
- 此信息必须告知编辑同事

### 5.9 36kr 作者认证
- 36kr 投稿前必须先完成"作者认证"（身份证、微信号、辅助认证信息）
- 这是**一次性人工操作**，不能自动化
- 编辑同事首次需要花 5-10 分钟完成认证

### 5.10 虎嗅只能投稿微信公众号链接
- 虎嗅的视频投稿必须填一个**已发布的微信公众号文章链接**
- 不能直接粘贴视频或正文
- 这意味着系统必须先在视频号/公众号发布成功，才能去虎嗅投稿
- 工作流上必须排序：视频号 → 虎嗅

### 5.11 B站草稿 10 天过期
- B站视频草稿 10 天后自动删除
- 系统必须提示编辑同事在 10 天内复核
- 或在报告里加"草稿过期日期"字段

### 5.12 企鹅号浏览器差异
- 企鹅号上传视频：Chrome 上限 4GB，其他浏览器只有 500MB
- 系统必须用 Chrome 内核（Chromium / patchright 都基于 Chrome，OK）
