## 三、新增踩坑

### 坑 44：body.play 触发导致浏览器白屏
- 用 `body.play` 类触发动画时，浏览器直接打开 HTML 没有 JS 添加 .play，动画不播放
- **解决**：CSS 动画不加 `body.play` 前缀，直接 page load 自动播放
- **注意**：录屏时也不再需要 `page.evaluate("body.classList.add('play')")`

### 坑 45：垂直错开标签导致截断
- 用不同 bottom 值垂直错开标签时，下方标签可能超出容器被截断
- **解决**：用 transform translateX 水平错开，两个标签同一 bottom 值
- 红字 translateX(-30px) 偏左，蓝字 translateX(30px) 偏右

### 坑 46：ffmpeg reverse 180帧需要足够内存
- 6s 入场 = 180帧 1080×1080，ffmpeg reverse 需要把所有帧加载到内存
- 偶发 concat 失败（只生成 entrance，缺 static/exit）
- **解决**：分步执行 ffmpeg，每步检查输出文件大小
