## 一、用户原始 prompt

> 我和老板对齐了一下，是我们理解有点问题…
> 是同一部电影，随着时间的变化而变化
> 你这个只是10张图，做了渐变
>
> lishuhang: 是不是这样：2012年只有第一行，然后2015年有前三行……直到2026年有最后一行，屏幕上只有三个颜色的点在随着时间移动，从上映年份开始移动到最近一年，不包含箭头，但可以留下移动轨迹
>
> 每一行有三个点，因为静态图不得不拆开三个点所以它们不是在一条水平线上而是一个年份/电影从上到下三色点，咱们做图可以三个点放大一些移动，最后屏幕上到2026的时候，留下的是每部电影三条移动轨迹，以及每部电影三个点最终的位置就可以了。
> 输出 round 3.7 的这一张图

### Agent 蒸馏回应

#### 设计方案
- **Y 轴**：10 部电影从上到下（2012→2026）
- **X 轴**：评价维度占比（0-75%）
- **每部电影**：3 个彩色点（专业能力/民族国家/社会文化性别），Y 轴微错位（-12/0/+12px）避免重叠
- **动画**：
  1. 10 部电影逐行出现（1s/部，1s-11s）
  2. 每部电影出现时，3 个点从"上映初期"位置滑动到"近一年"位置
  3. 滑动过程留下半透明连线（移动轨迹）
  4. 起点显示空心圆 + 百分比，终点显示实心圆 + 百分比
- **最终画面**：10 行 × 3 条轨迹 + 3 个终点圆点

#### 时间线（13s）
| 阶段 | 时间 | 内容 |
|------|------|------|
| 淡入 | 0-1s | logo→title→SVG→图例 |
| 电影1 | 1-1.5s | 2012《我是特种兵》3点滑动 |
| 电影2 | 2-2.5s | 2015《杀破狼2》 |
| ... | 每1s一部 | |
| 电影10 | 10-10.5s | 2026《镖人》 |
| 定格 | 10.5-11.5s | 全部10部完整显示 |
| 淡出 | 11.5-12.5s | 淡出至白 |

#### 技术实现
- SVG 绘制图表，CSS animation 控制每个点的滑动
- `stroke-dasharray` + `stroke-dashoffset` 实现轨迹绘制效果
- Playwright video recording 录屏，ffmpeg trim 到 13s

#### VLM 验证
- t=0.5s：淡入中，标题+logo 可见 ✓
- t=2s：3行数据点（前3部电影）✓
- t=5s：约5行数据 ✓
- t=10s：全部10行数据完整，每行3色点+连线轨迹 ✓
- t=11s：开始淡出 ✓
- t=12s：全白 ✓
