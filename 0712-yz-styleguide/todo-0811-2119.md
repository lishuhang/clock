## 四、新增踩坑与注意事项

### 坑 15：CSS 定位计算要算标签全高
- `top:-52px` 不意味着标签离参照元素 52px，而是标签顶部在参照元素顶部上方 52px 处。
- 标签底部 = 标签顶部 + 标签高度（22px）= 参照元素上方 30px 处。
- 如果父元素 gap 只有 24px，标签会穿透到上一行。
- **公式**：标签顶部到父元素底部的距离 = gap - top_offset - label_height。必须 > 0。

### 坑 16：CSS stacking context 陷阱
- `position:relative + z-index:数值` 创建独立 stacking context。
- 水印要在所有内容之上，必须：
  1. 水印和内容在同一个 stacking context（通常是 .chart-container 的直接子元素）
  2. 水印 z-index > 所有内容 z-index
  3. 内容元素 z-index 设为 auto（不创建 context），或其 z-index < 水印
- 如果内容父元素（如 .chart-body）有 z-index:2，它会"困住"内部内容的 z-index，使水印无法覆盖。
- **修复**：`.chart-body{ z-index:auto !important; }` 解除 context 陷阱。

### 坑 17：workspace 崩溃后脚本全丢
- `/home/z/my-project/scripts/` 不在 git 仓库，workspace 崩溃后所有 Python 脚本丢失。
