## 五、新增踩坑与注意事项

### 坑 27：VLM 目测字号不准
- VLM 在 1080×1080 画布上判断字号时，会按"标准屏幕字号"目测，28px 可能被判断为 14px。
- **解决**：用 Playwright `getComputedStyle` 检查实际 CSS 像素值，不以 VLM 目测为准。
- **后续 agent 注意**：字号验证用 Playwright 检查 computed font-size，不要只靠 VLM。

### 坑 28：image-search 首次结果可能不匹配
- 搜索"流浪地球 吴京"首次返回《登月》配音照片。
- 搜索"镖人风起大漠 吴京"首次返回李连杰剧照。
- **解决**：每次搜索取 3-5 张候选，用 VLM 逐一验证内容是否匹配，选正确的。
- **后续 agent 注意**：图片下载后必须 VLM 验证内容匹配度，不能假设第一张就是对的。

### 坑 29：VLM 年份识别可能不准
- VLM 把《我是特种兵之利刃出鞘》年份识别为 2017，实际是 2012 年播出。
- **解决**：对关键事实数据（年份、评分、票房等）进行人工事实核查。
- **后续 agent 注意**：VLM 识别的数据如有事实性错误，以人工核查为准。

### 坑 30：base64 内嵌图片让 HTML 体积大增
- img4 的 4 张 HTML 因内嵌剧照 base64，体积 1-2.4MB。
- 截图时 Playwright 加载时间略增，但可接受。
- **替代方案**：如需减小 HTML 体积，可把图片放在 assets/ 目录，HTML 用相对路径引用。但 base64 内嵌的好处是 HTML 自包含，可独立移动。
