## 三、v2.21a 使用说明（给任何 agent）

当用户说"请根据 v2.21a-yz-styleguide.html 的指示将下列图表转换成符合公司vi的样式"时，agent 应：

1. 打开 `v2.21a-yz-styleguide.html`
2. 复制 `<template id="yz-chart-styled-template">` 内的全部内容到新文件
3. 替换 3 个占位符：
   - `【TITLE_HERE】` → 图表标题（不得含"图N："前缀）
   - `【CHART_BODY_HERE】` → 图表主体 HTML（参考模板内的 6 种示例代码）
   - `【SOURCE_FOOTER_HERE】` → 脚注
4. 保存为 `{name}-styled.html`
5. 浏览器打开，等字体加载（控制台 `document.fonts.ready`）
6. 执行 `yzSelfCheck()`，必须返回 true
7. 截图 `.chart-container` 元素（不含 body 外框和自检横幅）

**v2.21a 已固化所有 round1.1+1.2 修复，agent 无需额外 prompt 即可输出正确图片。**

## 四、v2.21b 使用说明（给任何 agent）

当用户说"请根据 v2.21b-yz-styleguide.html 将大图拆成 1:1 小图"时，agent 应：

1. 打开 `v2.21b-yz-styleguide.html`
2. 分析原图内容，按内容密度拆分（参考拆图规则）
3. 每张拆分图复制 `<template id="yz-chart-1x1-template">` 内容
4. 替换 4 个占位符：
   - `【TITLE_HERE】` → 原图标题（所有拆分图共用）
   - `【CHART_BODY_HERE】` → 本张图的图表主体
   - `【SOURCE_FOOTER_HERE】` → 脚注
   - `【PART_NUM_HERE】` → 序号（如"1/3"）
5. 保存为 `img{n}-part{m}-styled.html`
6. 截图 `.chart-container-1x1` 元素

**拆图密度原则**：1:1 画布在 9:16 竖屏居中显示时最小字体仍清晰可见。中心区域约 4:3，头尾合计画幅 1/4。
