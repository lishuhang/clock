## 修订原因与结论

round3.3 的实现错误地将静态画面分区覆盖到白底画布上，导致用户看到中心白色遮罩，并且表3没有复用既有的完整对比动效。本轮已废弃该方案。round2.4 和 round3.4 均基于 `0811-test/round3.4` 的元素级 `fadeIn`、`growRight`、`rowFade`、`pieSweep` 等定义，以及 `0811-test/round3.9/img5-simultaneous-styled.html` 的同步 SVG 图元逻辑；**不使用**白色遮罩、中心裁切、`overlay_crop`、`clip-path: inset` 或 CSS mask。

## 逐类动画规则

评论卡先由右侧电影海报在 0.65 秒淡入，之后左侧引用从 1.42 秒开始按每字 45ms 快速打字机呈现，元信息在 2.1 秒淡入。整个评论卡的布局元素自行出现，画布其余空白始终是透明/白色背景而非盖在内容上的遮罩。

十部作品热力表沿 DOM 阅读顺序从左上至右下逐格 `yzBloom`，单元格通过透明度与轻微缩放形成“绽放”，每格间隔 70ms；未对整张表使用遮罩或统一块状淡入。专业能力堆叠条的每行和每个子段从自身左侧生长，标签随后出现。

表3先由 logo、标题、坐标轴、作品名、基线、页脚和图例按原有层级入场。空心点代表热映期、实心点代表近年回看，30 组官方数据端点和连线在同一 SVG 中以线性时间轴同时从热映期值移动到近年回看值，直接复用 round3.9 的“同图、同刻、逐图元移动”语义；不再将上方和下方拆开淡入。

## 录制、核验与复现

录制器 `record_round34_browser.py` 运行隔离 Chromium，捕获 HTML/CSS/SVG 原生动画。为消除无头浏览器录制速度造成的时间漂移，录制时暂停 Web Animations，并为每个输出帧设置标准帧时间对应的 `currentTime`。这保证了浏览器直接渲染每一帧的元素状态，并非把静态图遮罩拼接为视频。
