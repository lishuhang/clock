## 一、用户原始 prompt

> 有一图是"对比上映初期与当下，网友对吴京作品评价的维度在变化"
> 目前是分了三种颜色x10部电影，平铺开的，但其实因为10部电影是在不同年份线性上映的，其实完全一种颜色可以缩到一条时间线上，整个图片只显示三条线。然后，缓慢显示三条线上的线段，如同滑块一样在底色上面来回滑动的样子。
> 可以从纯白淡入，定格到 2012 我是特种兵 电影时候三个颜色的样子，停留1秒，然后一年一年的演进滑动直到2026年镖人，停留1秒，淡出
> 只做这一张图，输出这张图到round3.5

### Agent 蒸馏回应

#### 设计方案
- **3 条折线**：专业能力（橙#fc8166）、民族国家（金#f5a623）、社会文化/性别（蓝#7fd3f0）
- **X 轴**：10 部电影按年份线性排列（2012→2026）
- **每部电影**：哑铃段（上映初期空心圆 → 近一年实心圆）+ 数值标签
- **滑块光标**：虚线垂直线，从左滑到右，带年份标签
- **折线**：连接所有电影的同维度值，形成 3 条趋势线

#### 动画时间线（12s）
| 阶段 | 时间 | 内容 |
|------|------|------|
| 淡入 | 0-1s | logo→title→图例→SVG 依次淡入 |
| 2012 定格 | 1-2s | 滑块在 2012 位置，显示第一部电影数据 |
| 滑动 | 2-10s | 滑块逐年移动（每 0.8s 一部电影），依次显示数据 |
| 2026 定格 | 10-11s | 全部 10 部电影显示完成 |
| 淡出 | 11-12s | 整个画布淡出至白 |

#### 技术实现
- **HTML**：1080×1080 画布，SVG 绘制图表
- **动画**：JS setTimeout 控制时间线（CSS animation 不可靠已弃用）
- **录屏**：Playwright video recording（page.screenshot 在 4s 后白屏，video recording 稳定）
- **后处理**：ffmpeg trim 到 12s

#### VLM 验证
- t=0.5s：淡入中，标题+logo 刚出现 ✓
- t=1.5s：2012 数据完整，3条线+数据点 ✓
- t=9s：10部电影全部显示，3条折线完整 ✓
- t=11s：淡出变白 ✓

## 三、新增踩坑

### 坑 50：CSS animation 在录屏循环中不可靠
- CSS animation + `forwards` 在 Playwright page.screenshot 循环中，4s 后突然白屏
- 原因可能是 GPU 渲染进程在频繁截图时崩溃
- **解决**：改用 JS setTimeout 控制时间线

### 坑 51：page.screenshot 在 30fps 循环中 4s 后白屏
- 即使 JS 正确执行，page.screenshot 在高频循环中也会在 4s 后开始返回白屏
- `--disable-gpu` 无效
- **解决**：改用 Playwright video recording（`record_video_dir`），稳定捕获

### 坑 52：Playwright video recording 含 goto 加载时间
- video 从 context 创建就开始录，包含 goto 的 1-2s 加载时间
- **解决**：录 14s（2s 加载 + 12s 动画），ffmpeg trim 到最后 12s
