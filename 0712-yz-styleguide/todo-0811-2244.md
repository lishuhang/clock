## 五、新增踩坑与注意事项

### 坑 24：re.sub 返回整个字符串，不是替换部分
- `re.sub(r'^\s*(\d+)', r'\1', "1 动作演员")` 返回 `"1 动作演员"`（替换后的整个字符串）
- 要提取匹配部分：`re.match(r'^\s*(\d+)', s).group(1)`
- **后续 agent 切记**：提取字符串中的某部分用 `re.match` + `.group()`，不要用 `re.sub`。

### 坑 25：短内容无法物理铺满 1080×1080
- img4 引言卡内容只有一句话（如"喜欢吴京这硬汉类的人"10 字），即使字号 60px 也无法铺满 1080×1080 画布。
- VLM 会报告"留白"，但这是内容长度限制，不是布局问题。
- **解决**：字号已放大到 60px（正文 40px 的 1.5 倍），卡片 `flex:1` 撑满 chart-body，内容 `justify-content:center` 居中。这是短内容的最佳布局。
- **后续 agent 注意**：如果用户仍不满意短内容的留白，可考虑：1) 增大引言字号到 72px+；2) 添加背景装饰元素填充；3) 改为引言+点评双栏布局。

### 坑 26：v2.21b 模板内 CSS 未同步到 1080
- v2.21b 的顶部注释已更新为 1080×1080 规格，但模板内 `<template>` 的 CSS 仍是 900×900。
- **步骤 5 待办**：同步模板内 CSS 到 1080×1080（画布尺寸 + 字号 + padding 等）。
- 当前 round2.1 的 HTML 是直接用 build_round2.1.py 内联的 1080 模板生成的，不依赖 v2.21b 的 `<template>`。
