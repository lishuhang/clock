## 一、沈腾稿件（文章1：风评十年三次转向，《龙餐馆》让沈腾回归"好演员"）

抽样口径：2015–2026 年十部电影、每部 160 条热门 + 100 条最新，共 2600 条，按六大维度（专业能力 / 道德人格 / 民族国家 / 商业资本 / 社会文化·性别 / 身份符号）归类。

### 年代划分（文中三阶段）
- **定型期 2015–2018**：《夏洛特烦恼》《羞羞的铁拳》《西虹市首富》——"喜剧/搞笑"维度稳定 75%+，非喜剧专业能力约 15%。

- **转型期 2023–2026**：《满江红》《抓娃娃》《逆鳞》《欢迎来龙餐馆》——演技肯定升温，"欠他一个影帝"集中爆发；《龙餐馆》豆瓣开分 8.4（主演电影最高）。

## 二、吴京稿件（文章2：14年4次舆论转向，吴京剥下"战狼"标签了吗）

抽样口径：2012–2026 年十部代表作 2968 条豆瓣短评。形象四阶段：
