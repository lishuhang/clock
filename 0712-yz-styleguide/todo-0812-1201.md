## 三、新增踩坑

### 坑 37：CSS mask 动画与 opacity 冲突
- 一个元素只能有一个 `animation` 属性，如果设了 `opacity:0` 初始 + `animation: pieSweep`（只改 mask），opacity 永远是 0。
- **解决**：用 mask 控制可见性时，opacity 保持 1，只靠 mask 的角度变化显隐。
- **后续 agent 注意**：mask 动画方案需要 opacity 始终为 1。

### 坑 38：Python 正则匹配嵌套 div
- `<div class="db5-sub-title">.*?</div>` 用非贪婪 `.*?` 匹配，但如果内部有嵌套 div 会提前结束。
- 本例 sub-title 内只有一个 span + 文本，无嵌套，所以安全。
- **后续 agent 注意**：嵌套 div 匹配用 `re.DOTALL` + 非贪婪，或用 HTML parser。

### 坑 39：ffmpeg concat 偶发失败
- 3-step ffmpeg 中，concat 步骤偶发生成 3.5s MP4（只含 entrance，缺 static 和 exit）。
- **原因**：concat.txt 的文件路径用相对路径时可能找不到文件。
- **解决**：用绝对路径，且每次重新生成 concat.txt。
