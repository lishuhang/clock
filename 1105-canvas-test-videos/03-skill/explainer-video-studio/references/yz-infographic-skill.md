# 娱乐资本论信息图 A/B/C v3.2（3.2.1）

## 0. 执行方式

完整阅读本文件后再工作。不要读取 SVG 路径或字体二进制；只按相对路径引用 `assets/`。A 是数据与视觉母版，B 必须由 A（或原图）拆解，C 必须原样复制已批准的 B 后靠属性驱动动效。

优先级：用户对当前项目的明确要求 > 本文件 > HTML 模板。用户没有明确要求时不得自行覆盖规范。第 12 节“微操清单”是编辑逐条验收过的细则，与正文同等效力。

只有三种结果：

- `compliant`：全部检查通过，可以交付。
- `diagnosable_failure`：缺少数据、截图原件、身份、字体、Logo、浏览器或编码器，停止该项并说明缺项。
- `noncompliant_fallback`：使用了替代字体、文字 Logo、估算数据冒充原值、重打字代替截图等回退；禁止交付。

## 1. 固定文件及用途

- `style-a.html`：900px 宽的静态信息图完整模板。
- `style-b.html`：1080×1080 分解图完整模板，含 `.yz-legend / .yz-plot / .yz-note` 三段式主体和自检。
- `style-c.html`：与 B 相同的 DOM + 11 秒确定性动效引擎（按 `data-yz-chart` 与 `data-yz-role` 自动排时间）。
- `assets/logo-icon.svg`：独立河豚图标。
- `assets/logo-text.svg`：独立“娱乐资本论 Entertainment Capital”字标。
- 三个字体文件：AliPuHui 400/700/900。
- `assets/render.mjs`：A/B 只截画布；C 录 165 帧正放后逐帧倒序拼成 330 帧并编码 MP4。
- `assets/validate.py`：验证技能包或产出目录（含 C 与 B 的 YZ_EDIT 一致性比对）。

复制模板时只修改 `YZ_EDIT_*_BEGIN/END` 区域。不得重写字体、颜色变量、画布、品牌位、自检函数或时间轴。

## 2. 必须依次完成的工作

1. 阅读文章正文和全部图片，列出图片序号（按原文 `imgIndex`，命名 `img{两位数}`）、标题、对象、值、单位、时间、来源及歧义。用视觉逐张确认：题图、分隔条（POINT 图）、AI 插画、二维码/宣传图、GIF 一律排除；评论截图单独列为“截图卡”。原文或问题清单引用的图片若因防盗链、环境无法联网而下载不到，开工时就列出文件名（含所在位置）请编辑打包上传，不要等到交付时才说缺图；等待期间先完成其余图。
2. 数据来源优先级：原始 CSV/表格/文档 > 正文可复制文字 > 设计源文件（.ai/.pdf/.svg 矢量坐标）> OCR 并人工核对 > 视觉估读。`.ai` 文件按 PDF 解析，可直接读取矢量图元坐标与颜色；以网格线或已知数值做线性标定，残差写进 notes。
3. 建立 `source-data.csv`。每个视觉数字必须能回指一行；`verification_status` 只用 `verified / vector / estimated / override`。
4. 先做 A（或确认原图即 A），再从 A 拆 B。装不下就拆页（part1、part2…）；不得缩字、不得拉长、不得让内容被裁掉。
5. 从已批准的 B 复制 C：YZ_EDIT_1/2/3/4 区与 B 逐字一致，只换模板。
6. 运行 `assets/validate.py`，再用 `assets/render.mjs` 截图或录制；浏览器 `yzCheck()` 必须 `compliant`。
7. 目检 B 静态图和 C 的 0、0.5、1.0、1.5、2.0、2.5、3.0、9.5 秒关键帧（9.5 秒应与 1.5 秒画面一致）。
8. 确认文件真实存在后交付。motion HTML 不是 MP4。

## 3. 共同视觉规范

品牌色固定：强调 `#fc8166`、深强调 `#e55b46`、正文 `#312e2e`、次级 `#6b6666`、灰字 `#9a9595`、分隔线 `#e7e3e1`、背景白色。

分类配色例外：原图用 4 类及以上的分类色（如六种评价维度、六类专业焦点、六条折线）时，沿用原图色系（从源文件取色），不要硬套品牌色；单序列、强调、两期对比用品牌色。

字体固定：Regular 400 正文与普通标签；Bold 700 重点、数值、表头；Black 900 主标题。禁止 CDN 和系统字体静默替代，截图前等待 `document.fonts.ready`。

品牌固定：SVG 只保存河豚图标和中英文字标两个原子部件；横版、竖版组合在 HTML 中完成；禁止第三个组合 Logo、文字/emoji/色块冒充 Logo；禁止阴影、无来源渐变、装饰点、英文翻译、slug、徽章和口号。

标题只出现一次，不带“图1：”等前缀。图例只保留一次；不得添加原文没有的结论。

## 4. A：静态信息图

- 画布宽 900px；按内容选择 900、1080 或 1350px 的合理高度，禁止宽高比超过约 1:1.5 的细长条。
- 标题 68px / Black，按第 5.2 节规则手动分行；默认正文 28px；来源 26px。
- 内容区使用竖版组合 Logo 水印：容器宽约 420px、透明度 0.1；页脚横版组合 Logo 整体高约 62px。
- `.chart-body` 填满可用空间；只截 `.chart-container`。

## 5. B：1:1 分解图

### 5.1 画布与字号

- 画布固定 1080×1080；头部标题约占 80%，右上河豚图标约占 20%；标题 48px / Black。
- 主体普通文字（行标签、片名、数值）不得低于 40px；辅助文字（图例、度量、年份、坐标刻度、n 值、注）不得低于 28px；来源不得低于 27px；分段号不得低于 24px。
- 默认无大水印、无底部横版 Logo。

### 5.2 标题断句（必做）

- 标题按语义手动分行，每行一个 `<span class="yz-tl">`，最多两行；浏览器不得自动折行（自检 `title-overflow`）。
- 换行点优先放在逗号后，其次放在两个语义块之间；不得把词、人名、片名、书名号内文字拆开；第二行不得以标点或“的、了、地、得”开头（自检 `title-break`）。
- 一行放得下的标题保持一行。示例：
  - `对冯小刚的评价，从单一的` / `专业能力，走向多元框架`
  - `《抓特务》上线流媒体后，` / `抗议性一星几乎消失`
  - `冯小刚“专业能力”评价焦点的` / `三十年变迁（1997-2026）`
  - `现在的观众更关注冯小刚` / `及作品里的时代身份与社会文化`

### 5.3 主体三段式

`.chart-body` 内只有三块，顺序固定：

1. `.yz-legend`：图例、度量说明与单位，如“该维度评价占比（%）”“占该期样本比例（%）”；原图副标题可作第一行 `.yz-sub`。
2. `.yz-plot`：唯一的“主体区域”，写 `data-yz-chart="table|bar|dumbbell|line|image|other"`，主体元素标 `data-yz-role`（B 中不生效，供 C 使用）。
3. `.yz-note`：只放抽样口径等说明，可删除。

### 5.4 单位、术语与冗余

- 单位只说一次：数值不带 % 时，必须在图例行写“（%）”（自检 `unit`）。
- 禁止把 pp、p 值、显著性等统计术语放进图面（自检 `jargon`），需要时写进 source-data 的 notes。
- 禁止同义反复：不加复述标题或图形的结论句（如“连坐式评论从46.7%降为0”）；图例已表达的不在注里重复（如“空圈为院线期，实心点为流媒体期”“左为院线期，右为流媒体期”）；度量说明放图例行，不放注里。

### 5.5 拆页与防裁切

- 13 个对象默认 4-4-5 拆三页；同一图的各页保持同一标题、同一标签列宽、同一比例尺和同一配色，页码 `1/3`、`2/3`、`3/3`。
- 任何主体元素超出 `.chart-body` 即判失败（自检 `clipped`）：v1.0 曾因 `overflow:hidden` 静默裁掉最后一部影片。
- 内容少时放大间距或元素填满主体，不留大块空白。

### 5.6 各图型细则

- **热力表**：保留“颜色越深，占比越高”的编码——单色相顺序色阶按 0–100 绝对值取色，0 用中性浅灰，深底用白字；图例行写说明并附 5 级色块。用表格网格，不做“片名大标题 + 小标签”卡片流。维度表头不缩写，放不下就两行（`专业<br>能力`）；片名 40px 常规体、年份 28px 品牌红置于上方；数值统一一位小数（0 写作 0）。
- **条形/堆叠条**：从左侧基线画起；短条数值放条外、长条（≥300px）放条内白字；堆叠条按图例顺序排段，下方数值行配同色色块。
- **维度变迁（哑铃）图**：图例只在顶部出现一次，禁止每行重复图例；左侧为维度/片名，右侧为“起点 → 终点”数值（若原图有可核实数值）。起点空心圈、终点实心点；箭头用固定尺寸深色 V 形，两点间空隙放得下就放中间，否则放到终点外侧并指向变化方向，保证 0.4 个百分点的变化也看得见。没有刻度时，按比例把轴拉满整行宽度（标签和数值放在轴上方一行，轴在下方）。原图只有坐标、没有数值的（如 13 部影片三维度图），保留顶部刻度和网格，不自行印估读数值。
- **折线图**：沿用原图改编逻辑——所有序列放在同一张图，不按序列拆页；4 条以上沿用原图配色；不加原图以外的辅助柱（如“无效评论”半透明柱）。数据点必须实心，图例标记与图中标记一致（线 + 实心圆点），不用圆角方块；纵轴刻度带 %。
- **评论截图卡**：标题写“《片名》部分豆瓣短评”“《片名》部分腾讯视频评论”“《片名》在2018年部分豆瓣短评”等；编辑把多条评论拆开的，一条一张；截图完整放入主体、不裁切、不重打字，加 1px 浅灰描边和圆角；截图上下与页脚分隔线至少留 14px，不得贴线（模板 `.yz-shot` 已限高 `calc(100% - 28px)`）；来源写“截图来源：豆瓣/腾讯视频”。截图原件缺失即 `diagnosable_failure`。
- **人物排行榜**：优先 3+2、2+2 或“主气泡＋卫星指标”；一人一个独立头像文件，`object-fit:cover; object-position:center`；禁止 sprite、榜单截图裁脸、共享背景定位；必须用目标微博账号抓取时正在使用的头像并核对 UID、认证、简介。

### 5.7 数据呈现

- 图上印出的数字必须是 `verified` 值（原图标注、正文、原始表格、CSV 重算）；`vector` 值可用于定位图元，若必须印出，要么与 verified 值互证，要么在注中标明“按原图比例量取”。
- 原图标注与几何/行和矛盾时（如“其他 56%”使行和超过 100），以几何量取值改正并在 source-data 记 `override` 与理由。
- 原图截断、错字（如“映前院线期”“试听/制作”“欢我不是潘金莲”）按原意改正并记录。

## 6. C：由 B 生成动效

### 6.1 时间轴（固定）

```text
11.000s · 30fps · 330帧
0.0–0.7s  大黑标题淡入（第一秒内完成）
0.6–1.5s  主体以外的元素从上到下依次淡入：Logo → 上方图例/灰字 → 下方注 → 页脚来源与页码（1.5s 前全部完成）
1.5–3.0s  主体区域按图型入场（3.0s 前全部完成）
3.0–8.0s  静止定格 5 秒
8.0–11.0s 严格倒放退场（与 0–3s 逐帧镜像），最后一帧回到纯白
```

第 0 帧必须是纯白画布（render.mjs 检查白像素 ≥99.95%）。禁止整页或整个 `.chart-body` 一次淡入淡出；禁止用 mask、clip-path、覆盖层模拟绘制。

### 6.2 主体入场（由 `data-yz-chart` 决定）

- `table` 表格：所有 `data-yz-role="cell"`（含表头）按 DOM 行优先顺序，从左上到右下像多米诺骨牌一样逐格淡入。
- `bar` 条形：`bar`（单条）或 `stack`（堆叠，内含 `seg`）在 1 秒内从基线长出，堆叠段从左到右接力；之后 `label`、`value`、`axis` 淡入。
- `dumbbell` 维度变迁：先 `axis`（轴线/刻度/网格），再每行按箭头方向依次出现 `start`（空心圈）→ `link`（连线，SVG 按长度绘制）+ `head`（V 形箭头）→ `end`（实心点），2 秒内完成；右侧数字同步转变（`num-start` 随起点、`num-arrow` 随连线、`num-end` 随终点），左侧 `label` 同时淡入（1 秒内）。行容器标 `row`。
- `line` 折线：`axis`（网格、轴线、刻度与横轴阶段名）与折线同时开始淡入；每条序列按 `point`(i=0) → `seg`(i=0) → `point`(i=1) → … 直到终点，`data-yz-series` 区分序列、`data-yz-i` 标序号。
- `image` 截图：其他元素出现后，主体图片 `image` 淡入。
- `other`：`item` 依次淡入。

主体里任何可见元素都必须自身或祖先带角色（自检 `unscheduled`），否则会在第 0 帧露出。

### 6.3 实现与录制

- C 的 YZ_EDIT 区从 B 原样粘贴；不手写逐元素时间，引擎按上面规则自动排程，`yzSetTime(ms)` 供逐帧录制，打开 HTML 自动循环播放预览。
- `render.mjs c` 录 0–5.5s 共 165 帧，再把这 165 帧倒序接在后面，得到 330 帧；倒放因此与入场严格对称，定格正好 5 秒。
- 编码 H.264、`yuv420p`、恒定 30fps、CRF 18。

## 10. 必须拒绝的情况

1. 字标被输入文字替代，或河豚/字标不是提供的 SVG。
2. 竖版水印用伪元素、旋转文字或组合 SVG 代替两个原子部件。
3. 字体从 CDN 加载或回退为微软雅黑、Noto Sans、Arial 等。
4. 标题含“图N：”、浏览器自动折行、断在词中或第二行以标点/虚词开头。
5. 为塞内容把 B 正文缩到 40px 以下、拉成长条，或主体内容被裁掉（`clipped`）。
6. 估算数据冒充原始值，单位缺失，统计术语上图，或添加同义反复的结论句。
7. 每行重复图例；折线图点空心或图例标记与图中标记不一致；分类数据硬套品牌色导致与原图逻辑不符。
8. 从 sprite 裁头像、错位、错误同名账号，或用旧照片替换当前头像。
9. 截图卡用重打字、示意图或占位图代替原截图。
10. C 不是 11s/30fps/330 帧、第 0 帧不是纯白、退场不是入场的严格倒放、整页淡入，或 HTML 被当成视频。
11. 截入画布外灰边、滚动条、调试信息或浏览器页面。
12. 缺失 HTML、PNG、MP4、来源数据或头像来源记录；覆盖了旧版本目录。
13. 任何 Cookie、令牌、授权头或会话信息进入产物或提交。
