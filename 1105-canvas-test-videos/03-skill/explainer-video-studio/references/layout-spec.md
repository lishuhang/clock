# 画面规格与 canvas 模板（references/layout-spec.md）

> 默认竖屏 9:16 知识区规格；横评项目实测版式。母版实现：`assets/h5_templates/vertical_master.html`（受控时钟 `renderFrame(payload)` + 自检 `yzCheck()`）。

## 一、画布分区（1080×1920，v1.2 安全框正解）

| 区 | Y 范围 | 内容 | 硬约束 |
|---|---|---|---|
| 顶部黑边 | 0~555 | 进度条（8px）+章节胶囊预览；成品里为背景延续区 | 主体内容禁入 |
| **4:3 主舞台（横屏比例）** | **555~1365** | 全部主体内容（1080×810，4:3 横屏比例） | `#stage{top:555px;height:810px}`；内边距：左右 36 / 上 14 / 下 22；**切掉上下黑边 = B站横屏版**，主体必须在框内 0 溢出（布局审计脚本验收） |
| 底部黑边 | 1365~1920 | 字幕条（Y1435~1545） | 主体内容禁入；背景延续区 |

> ⚠ v1.1 及以前的「4:3 安全框 = Y240~1680（1080×1440 竖框）」是错误理解：按它排布的内容切横屏后上下都丢。v1.2 起全部镜头按 Y555~1365 排布并跑布局审计（Playwright 快进到镜末量元素 rect，0 溢出合规）。

**画布内最小字号（1080 宽基准）**：正文 ≥28px、标签/角标/来源注 ≥24px、卡片标题 ≥28px；logo 图片显示高度 ≥78px（网格内）/≥84px（单行展示）。竖屏与横屏 1:1 共用画面，过小字号在两个版本都无法辨认。

**字幕位规 v2（用户图上实测）**：字幕框顶部 Y=1435、底部 Y=1545、高 110px、宽 720px（左右各留白 180px），位于 4:3 框外底部黑边内；≤16 字/条，阿里普惠体 68px 白字黑边（Outline 7）；ASS：Alignment 2 + **MarginV=375 + MarginL/R=180**；动态字号：视觉长度>10.2 字→`{\fs56}`、>12.5 字→`{\fs48}`（WrapStyle=2 不折行）；关键词 `<em>` 高亮。旧 1740 位作废。

素材适配：信息图 HTML（900×1350 竖版）→ 高 ≤740 等比缩入；16:9 截图 → 宽 ≤1008；9:16 素材（720×1280）→ 高 ≤500 居中或 2/4 宫格。

## 二b、黑底暗色系（本类解说片专用换肤，v2.0）

> 适用：小Lin说式黑底竖屏解说片（如 1105 画布横评三部曲）。**黑底白字、橙色高亮不违反品牌规范**——这是本类片的合法主题换肤，不回传改 yz-infographic 通用规范（其白底规范继续用于图文信息图产出）。

| 元素 | 亮色版（信息图默认） | 黑底版（本类片） |
|---|---|---|
| 页面底 | `#f6f4f2~#fff` | `#131110`（近黑暖灰） |
| 面板/卡片 | `#fff` | `#1e1b19`，边 `#3a3634` |
| 正文 | `#312e2e` | `#f2efec` |
| 次级文字 | `#6b6666` | `#b5aea9`（来源行 `#a8a19b` 起） |
| 分隔线 | `#e7e3e1` | `#3a3634` |
| **强调橙** | `#fc8166`/`#e55b46` | **原样保留，无需调整** |
| 品牌浅色 tint | `#fdf1ec`/`#fff4f0` | `rgba(252,129,102,.12~.10)` |
| 成功绿 | `#2e8b57` | `#4caf7d`（提亮） |
| 金色系 | `#8a6d3b`/`#b98a3e` | `#e0b571`/`#d9a952`（提亮） |
| 阴影 | `rgba(49,46,46,.08)` | `rgba(0,0,0,.4~.5)` |

配套规则：
1. **yz-infographic 白底信息图进入本类视频前必须换肤**（上表映射；`dark_convert.py` 思路：CSS 变量上下文替换 + `background:var(--ink)` 深底白字块反转为浅色芯片浅底深字 + 渐变逐一映射）。
2. 白底网页截图（充值页/官网/新闻段落）用 `#1e1b19` 深色卡片 + `#3a3634` 描边承托，不拉伸不裁字。
3. logo 处理：白底 logo 先"白键出"（距白欧氏距离 <8 → alpha 0，≥30 全不透明，中间过渡）+ 自动裁切到字形 + 方形画布居中；纯黑/深灰单色字形（如 libtv）直接反转白色；深色 app 图标（如小云雀）做反色副本。暗字形彩色 logo 用 HSV V 通道提亮（保色相）。
4. 深底白字胶囊（`background:var(--ink)` 类）反转为浅底深字芯片；橙色胶囊不动。
5. 视频片段背景叠底：scrim `rgba(0,0,0,.82)`（视频净亮度 18%），前景证据卡照常。

## 四、动效实现规范（受控时钟）

1. 每镜一个 `S##.html`（复制母版，只改 `YZ_EDIT_STAGE` 区），元素标 `data-anim="pop|fade|up|stamp|typing" data-t="出现秒" data-d="时长"`
2. **所有动效由 `renderFrame({t})` 纯函数驱动**；禁止 CSS 自动播放、禁止 setInterval；同一 t 永远同一画面
3. 截帧策略（v4）：开场窗 0.5s@30fps ∪ 自动入场窗（渲染器解析 data-t，每个入场 ±0.45s@15fps；data-counter 按 ramp 全程@12fps）∪ 2fps 基础网格（承载环境微动）∪ DENSE 窗 ∪ 尾帧
4. 字幕条内容来自 timeline 的 `subs`（对齐器按字数权重切分），KTV 高亮词用 `<em>`
5. 信息图 HTML 复用：900px 宽静态图源文件 → 包一层 stage 容器，按 `data-anim` 给标题/图例/条形标注出现时序（参考信息图 skill 的 C 型动效规则：非主体 1.5s 内从上到下、主体按图型入场、3s 完成入场）

## 四b、环境动效原语与定格≤3s 执行细则（v1.1）

> 目的：铁律 21「画面定格≤3s」的落地手段——静态画面保持动感 + 入场按台词逐级浮现。

**入场侧**：元素 `data-t` ≈ 该内容在配音中被念到的时刻（句内按字符占比估算即可，误差≤1s）；长镜头（>8s）的列表项/卡片/ logo 按读音间隔逐个弹入（例：10 个平台名被念 14.5s，则每个 logo 间隔≈1.45s）。

**环境侧（入场完成后持续微动，与 data-anim 可叠加）**：

| 原语 | 用法 | 参数 | 适用 |
|---|---|---|---|
| `float` | 上下漂浮 | `data-ambient="float" data-amp="4~8" data-sp="≤0.32" data-ph0="相位"` | 胶囊/卡片/chip/logo |
| `pulse` | 缩放呼吸 | `data-ambient="pulse" data-amp="0.005~0.012" data-sp="≤0.45"` | 大字/KPI/印章 |
| `typing` | 打字机入场 | `data-anim="typing" data-text="全文本" data-t data-d` | 聊天框/搜索框模拟 |
| `kb` | 缓推 | `data-anim="kb" data-kb="1,1,1.04,1.04"` | 背景图/截图（配 overflow:hidden 容器） |

**频率红线（2fps 采样网格适配）**：float 的 `data-sp` ≤0.32、pulse ≤0.45，否则相邻采样帧位移>6px，物化到 30fps 后可见跳变。多个环境动效元素用 `data-ph0` 错开相位（0/0.7/1.4…），避免整齐划一像机械波。

**动效统一（铁律 23）**：同一镜内只用一套入场原语（如全 pop 或全 up），环境微动全片一套参数；镜间硬切是节奏，镜内不硬切。

## 五、音效包（assets/sfx/，可自备替换）

`boom.wav`（HP 砸屏）/ `pop.wav`（FL 弹入）/ `whoosh.wav`（转场）/ `stamp.wav`（盖章）/ `cash.wav`（收银机）/ `ding.wav`（提示）。BGM 143.8s 无缝循环，人声下方 -13.5dB，章节切换 0.5s 闪避（sidechaincompress），片尾 8s 渐出。

## 六、B-roll 影片素材模式（v1.1）

外部影片/实拍/屏录素材进入画面时的标准结构（铁律 16 的细化，保障观众看清素材本身 + 4:3 合规）：

1. **前景展示阶段（约 2~3s）**：影片以全屏前景、无叠层纯净播放（canvas 页为空透明页，视频由 ffmpeg 直出）；此时不加任何文字。
2. **淡出压暗阶段**：scrim 以 0.6s 淡入（`data-anim="fade" data-t="0" data-d="0.6"` 写在透明页 bg 层），影片降为背景；亮色屏幕录像类源（白底 UI）需更深渐变 scrim（上 0.72 / 中 0.16 / 下 0.80）。
3. **故事板叠层阶段**：主体信息卡按台词逐级推入，全部落在 4:3 安全框（Y555~1365）内。
4. **实现**：镜头分拆为 `S##a`（纯净展示）+ `S##b`（叠层）两镜，时长之和 = 原镜；bg 视频按帧边界连续切割（`-ss offset` + `-frames:v n`），拼接无缝；两镜都进 `TRANSPARENT_SHOTS`。

## 七、分镜分拆与成片提速（v1.1）

- **分拆**：任何镜头都可拆 a/b/c 多页，shots JSON 按新 ID 重算 start/dur，Σn 帧数不变；字幕按句独立，不受影响。
- **成片整体提速**（若用户要求）：不在管线前段改时间轴，在最终压片一步完成：`[0:v]setpts=PTS/k,fps=30` + `[0:a]atempo=k`（不变调），外挂 srt 全部时间戳 ÷k 重定时；QC 按新时长/帧数验收。

## 八、抽象镜头动画化方法论（v1.2，铁律 28 落地）

> 原则：**在分镜阶段就用推理能力想「这个概念怎么用动画讲」**，而不是做成静态文字卡后靠入场动效补救。抽象概念 → 视觉隐喻 → 连续运动（一直动 = 定格红线的合法豁免）。

**设计流程**：①取台词里的抽象名词（沉没成本/迁移难/同质化/门槛/翻车）；②找一个观众 0.5s 就懂的身体经验或游戏隐喻（推箱子、走迷宫、下台阶、金币沉底、盖章、走钢丝）；③把台词时序映射到动画节拍（台词念到哪动画演到哪）；④结尾定格在结论大字（stamp）。

**1105 价格篇 v5 三个样板**：

| 镜 | 抽象概念 | 隐喻动画 | 节拍（1x） |
|---|---|---|---|
| S08 | 创作资产极难迁移/沉没成本 | 小人推「角色/工作流/素材」三箱向右，顶住「平台边界」墙推不动，坐下歇，冒出「沉没成本」大字 | 箱子按读音弹出 0.8~1.5s → 推行 1.9~5.2s → 顶墙发抖冒汗 5.2~7.4s → 坐下 7.4s → 大字 7.9s |
| S09 | 功能同质化 | 10 平台 logo 密集网格快速逐个弹出 → 斜盖「功能同质化」红章（rotate -6°） | logo 每 0.24s 一个 → 3.3s 盖章 |
| S29 | 透明度四级台阶 | 列表改真台阶：每行错位递增 margin-left（0/12/24/36%）+亮度递减（1.0→0.82），「越往下越难」直接被看见 | 台阶按台词逐级入场 |

**实现要点**：①包装 `window.renderFrame`（`var _rf=window.renderFrame; window.renderFrame=function(p){_rf(p); myAnim(p.t);}`）用 t 驱动小人姿势/位移/汗滴周期；②姿势用两个容器切换（推姿/坐姿）；③`SHOOT_DENSE=[[0,dur,12]]` 全程 12fps（连续动画密度）；④盖印章勿叠加 pulse 环境动效（transform 会覆盖 rotate 倾斜）；⑤章/大字用 stamp 入场；⑥小人用纯 CSS 几何件（圆头+圆角矩形身+腿两根），暗色系里白描边风格即可，不必精美——叙事优先。
