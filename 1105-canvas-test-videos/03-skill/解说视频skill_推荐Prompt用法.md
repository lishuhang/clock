# 解说视频 skill · 推荐 Prompt 用法说明（随附文件，不属于 skill 本体）

> skill 本体（`explainer-video-studio/`）内不含提示词模板；本文是给"人"的用法参考，按需复制修改。

## 一、标准一句话（最简启动）

```
用 explainer-video-studio skill 做一支B站知识区风格的竖屏解说视频：
风格参照小Lin说（70%）+差评/晚点质感（30%），主题是《XXX》，目标时长10分钟，9:16竖屏、主体内容4:3安全框、框外字幕条。
素材来源：[百度网盘（token见下）/ 本地文件 / 需要你外采]，文案[我提供终稿附后 / 请先按skill风格指南改写后给我确认]。
百度网盘 access_token：XXXXX
```

## 二、推荐补充参数（按需追加）

| 想控制什么 | 追加一句 |
|---|---|
| 已有配音 | 「配音已做好，文件在（网盘路径/附件），按实测时长反推语速对齐分镜」 |
| 品牌视觉 | 「视觉用娱乐资本论品牌系（#fc8166/#e55b46+阿里普惠体+河豚logo），水印常驻右上」 |
| 工作仓 | 「GitHub 作为工作目录即时保活：repo XXX，token XXXX，中间件入 XX 子目录，网盘源文件不入库」 |
| 审批节奏 | 「分镜表先给我批准，再开始制作」（默认即如此） |
| 事实口径 | 「所有数字过事实门禁；与既有文章打架的口径列出来问我，不要自行改数」 |
| 外采边界 | 「外部素材每镜失败重试最多1次，回退canvas自制动效」 |
| 时长压缩 | 「V3 语速上调10%把时长压到12分半以内」 |

## 三、三类典型场景的推荐完整 Prompt

**A. 只有一个题目（从零）**
```
用 explainer-video-studio skill 做一支10分钟B站竖屏解说视频，主题《2026年AI短剧的钱都被谁赚走了》。
先给我：①选题角度与大纲 ②口播文案（按skill风格指南：3秒反差hook、B端视角、2400-3200字）。
文案我批准后再出分镜表，分镜批准后才制作。数据全部过事实门禁，检索不到的宁可不写。
```

**B. 有文章要改编（最常见）**
```
用 explainer-video-studio skill 把附件这篇文章改编成10分钟竖屏解说视频（文章见附件/网盘路径+token）。
改编按skill风格指南：保留85%核心商业逻辑，书面语翻成有画面感的口语，结构六模块。
风格：小Lin说70%+差评冷幽默+晚点克制30%。改完的文案先给我确认。
```

**C. 万事俱备只要出片**
```
用 explainer-video-studio skill 直接投产：文案终稿、配音mp3、BGM、水印、信息图HTML都在网盘（token见下，素材清单按网盘 XX 目录）。
按skill十步状态机走：先出三集分镜表（timeline JSON按真实配音校准），批准后逐镜生产canvas动效并组装，质检BUILD_SUCCESS后交付。
```

## 四、会话中途的常用短指令

- 「分镜表 V3 的 S31-S33 砍掉，压回12分钟」
- 「第2集改用横屏16:9重排」（skill 母版改 viewport 与分区即可）
- 「把这一镜换成网盘 XX 截图，做红框取证动效」
- 「BGM 换成 XXX，闪避降到 -15dB」

## 五、什么情况不该用这个 skill

- 需要真人出镜/口型视频（本 skill 是不露脸 H5 动效管线）
- 30 秒以内极短视频（杀鸡用牛刀，直接手排 6 镜更快）
- 需要复杂三维/粒子特效（canvas 模板是信息动效级别，不是 AE）
