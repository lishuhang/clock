# 1105-canvas-test-videos · AI视频画布横评 → B站竖屏解说视频三部曲

## 任务目标

把网盘 `/202610-AI视频画布横评/成品稿件/` 的三篇文章（价格篇/功能篇/实测篇）转为 **B站知识区风格竖屏解说视频**：

- 比例 **9:16（1080×1920）**，主体内容在 **4:3 安全框（1080×1440 居中）** 内呈现，**框外上下字幕条**
- 风格基准：小Lin说叙事节奏（70%基底）+ 差评冷幽默 + 晚点克制事实呈现（30%），详见文案终稿尾部的《风格微调报告》
- 画面管线：**HTML canvas 动态网页 → 受控时钟截帧/录屏 → ffmpeg 组装**（不露脸、无真人出镜）
- 配音：第一篇已有成品配音 `1105-1200-第一篇.mp3`（740.4s）；BGM 循环使用 `娱资日更视频BGM`；角标使用 `浮水印-简版竖版黑字alpha.png`

## 硬性工作规则（用户原话归纳）

1. **网盘只读**：素材只从 `我的网盘/202610-AI视频画布横评/` 拉取，**不上传任何内容**到网盘
2. **GitHub 是工作目录与增量备份**：中间件（脚本/切片/分镜表/canvas HTML）即时 commit+push，防沙盒回收丢失；**网盘源文件（文章/音频/视频原件）一律不进 GitHub**，只进切片、分割、加工好的待组装半成品；**HTML canvas 动态网页可以传**
3. **token 永不入库**：百度网盘 token、GitHub token 只走环境变量，不写入任何文件/日志/产物
4. 成片不得含 Remotion 元数据水印（若用 Remotion 渲染，交付前跑 `strip_metadata.sh`，见 skills/remotion-video-studio）
5. **素材切片化（2026-11-07 用户原则）**：大素材首次下载即切片（单片<20MB，目标几百KB~几MB），`clips/MANIFEST.json` 标名用途；之后任何会话只引用切片，不重新下载大文件；叠层元素（水印等）等比缩放永不拉伸；水印/裁切/变速/字幕全部后置脚本段（最后烧），不烧 token
