## 文件管理约定

`tv-versions/tv-app-v1.5.html` 是 **唯一产品源文件**。以后功能或界面修改均只改 HTML，并先在本地验证。`tv-versions/tv-app-v1.5-worker.js` 是由 HTML 和 PWA 图标生成的 **部署包装产物**，只用于同步到 Cloudflare Worker；不应直接作为业务源文件编辑。

PWA 的 `manifest.webmanifest`、`sw.js`、`icon-192.png` 和 `icon-512.png` 由生产 Worker 在运行时提供，因此不会破坏产品源文件为单 HTML 的约定。
