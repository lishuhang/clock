# MonitorHub v1.6 交接：Edge PWA 标题栏修复

> **记录时间：** 2026-08-17 00:57（GMT+8）  
> **生产地址：** <https://tv.lishuhang.workers.dev/>  
> **产品源文件：** `tv-versions/tv-app-v1.6.html`

## 问题与根因

v1.5 的 PWA 清单声明了 `display_override: ["window-controls-overlay", "standalone"]`。在 Edge 中，该声明会选择窗口控件覆盖模式，使系统标题栏消失、最小化／最大化／关闭按钮叠加到网页右上角，并遮挡应用浮动导航栏。该应用不是按无边框窗口布局设计，因此不应声明该覆盖模式。

## v1.6 修复

| 项目 | 结果 |
|---|---|
| PWA 显示模式 | 完全删除 `display_override`，只保留标准 `display: "standalone"`。浏览器应保留自身常规标题栏与窗口拖动区域，不再把系统控件覆盖到应用导航栏。 |
| 产品版本 | HTML 标题、导航品牌、运行时 `APP_VERSION` 与 Changelog 更新为 **v1.6**。 |
| PWA 功能 | 保留 v1.5 的 manifest、192px／512px 白底显示器安装图标、Service Worker、独立窗口模式及可安装性。 |
| 本地归档 | 已新增 `tv-versions/tv-app-v1.6.html`（唯一产品源文件）及 `tv-versions/tv-app-v1.6-worker.js`（由 HTML 生成的部署包装）。 |
| 生产部署 | Cloudflare Worker `tv` 已于 2026-08-17 00:57（GMT+8）更新为 v1.6。 |

## 验证结论

生产页面已实际打开，标题为 `MonitorHub · v1.6`。生产清单返回 HTTP 200，`display` 为 `standalone`，并且 **不含** `display_override`；Service Worker 仍可注册。HTML 与 Worker 通过 JavaScript 语法检查。

## Edge 使用说明

已安装的 v1.5 Edge 应用可能保留旧清单。先关闭该应用并重新打开一次；若仍出现无边框／控件覆盖，请在 Edge 的应用管理中卸载旧 MonitorHub 安装项，再从 `https://tv.lishuhang.com` 重新安装。v1.6 清单不再请求窗口控件覆盖模式。

## 后续维护

只编辑 `tv-app-v1.6.html` 作为产品源文件。修改完成后重新生成同版本 Worker 部署包装并部署；不要直接在 Worker `.js` 中维护业务界面代码。
