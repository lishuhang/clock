## 偏差与踩坑

### Python 替换模板字面量中的反引号失败
文件是 const HTML_BODY = `...` 格式，内部反引号用 \\` 转义。Python 脚本中的 triple-quoted string 和 \\ 结尾会被解释为行续行，导致替换 pattern 不匹配。解决：对 changelog 和死代码这类含反引号的位置，改用逐行遍历或 python3 -c 内联脚本处理。

### agent-browser eval 的变量名冲突
同一个 browser session 中，agent-browser eval "const x = ..." 如果执行多次，第二次会报 Identifier 'x' has already been declared。解决：用不同变量名或用 var 声明，或关闭浏览器重新打开。

### Node.js v24 不支持直接 eval worker 代码
node -e 'try{new Function(code)}catch(e){}' 会因 TypeScript 类型检查报错。解决：用 node --check file.js 做语法检查。

### CF API Content-Type
必须用 application/javascript（不是 application/javascript+module）。
