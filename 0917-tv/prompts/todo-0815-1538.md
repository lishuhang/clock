## 关键实现细节与踩坑

1. **最初 GitHub 推送三次遭 403 拒绝**，用户扩展授权后已恢复。以后若推送失败，先检查授权范围与仓库写权限，不要反复无效重试。
2. Cloudflare 下载 Worker 的多部分响应包含非普通 JSON 包装，简单 JSON 解析失败；以现有仓库源与生产路由交叉验证更可靠。
3. 345 上游播放页当前的变量名是随机的，不能硬编码变量名。修复采用已有 `parseXac` 的数据表达式解析和函数形态匹配，**不 eval / 不执行不可信上游脚本**。
4. 构建脚本的 xuexi 路由原先插在 `/cat` 前，但通用 m3u8 正则早于 `/cat`，故仍错误。必须插在通用 m3u8 路由标记前；隔离构建已用合成输入验证路由行序。
5. 状态页的 `ysp error` 由一个采样频道错误即可触发，不能代表全部 YSP 频道均失效；要参照逐条探测 JSON。
6. 在处理长时间全量探测时，工具每完成一项都会原子写 checkpoint；恢复时不要删除 JSON，以免再次重压上游。
7. 对官方网页入口（看看新闻、TVB 新闻、央视）仅确认了公开网页层面的观看入口，**没有**擅自提取、代理或写入可能受地域/授权约束的内部媒体 URL。
