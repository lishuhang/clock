## 本次新增功能

| 功能 | 实现与行为 |
|---|---|
| 临时播放 | 每个屏幕配置行均新增“临时播放”复选框和 URL 输入框。输入合法 HTTP(S) 地址后按 Enter 或离开输入框即播放；支持 HLS 直播和浏览器可播放的常规视频文件。 |
| 临时内容回退 | 有限时视频播放结束会清空临时 URL 并回到原定直播源。无限时直播在用户手动暂停时同样回退。非法／播放失败 URL 在“自动换台”或“轮询线路”模式下直接回退；在“反复重试当前线路”模式下按退避策略重试。 |
| 屏幕预设 | 支持保存激活屏幕、频道、固定线路、静音偏好、频道引用及当前临时播放 URL；可载入、上移、下移、重命名、删除。最多 20 组，列表固定显示约四行并支持滚动。 |
| 源操作命名 | 内容源页的按钮已改为“导入源（.txt）”“导出源（.txt）”“保存并刷新源”。TXT 导出名为 `monitorhub-sources-YYYYMMDD-HHMMSS.txt`。 |
| 完整配置备份 | 通用页底部新增“导入配置（.json）”“导出配置（.json）”。JSON 包含应用选项、预设、内容源文本、当前激活屏幕、频道、固定线路、静音偏好及临时播放 URL；导出名为 `monitorhub-config-YYYYMMDD-HHMMSS.json`。 |
