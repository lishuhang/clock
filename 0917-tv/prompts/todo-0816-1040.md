## v1.5 完成内容

本次保留原有导航栏自动隐藏/固定、设置框拖动、主题、导入导出、HLS 播放、静音偏好、线路 pill 与浏览器原生视频控制等既有功能，并完成下列变更。

| 范畴 | 已完成变更 |
|---|---|
| 单文件应用 | 从 Worker 内嵌模板字符串恢复为独立 `tv-app-v1.5.html`；Worker 不再是源代码唯一载体。 |
| 固定线路 | 固定某一 URL 后，`ended`、致命错误、超时和持续停滞都会继续重试该 URL，不自动换台。 |
| 自适应清晰度 | 新增“自适应”。单块画面高度 `≤480px` 时优先不超过 480p；`481–720px` 时优先 720p，不存在时选择最近更高层级；窗口 resize 后同步刷新各 HLS 实例的质量上限。 |
| 动态屏幕布局 | 仅按容器宽高比选择候选行×列组合。N=1–4 时按组合宽高比最接近原则选择；并列取更方正方案；空位固定在右下。每次窗口调整都会重新计算布局，同时搬移已有视频 DOM，避免重建存活播放器。 |
| 两级频道选择 | 选择分类后，频道下拉先显示“选择频道”，不会假装已经选择该分类的第一项；频道名称不再重复显示 `[分类名]` 前缀。 |
| 文字与内容源页 | 完成全部指定的中文措辞更新；删除“Auto-Level”；“内容源”页顺序为导入/导出、文本框、保存并刷新、说明。说明已替换为用户提供的规则。 |
| 国际化 | “通用”页底部新增语言选择，可切换简体中文与 English。页面 UI、动态设置控件、内容源说明、状态提示与 README 随语言切换；Changelog 保持原始记录语言。翻译表集中在 `I18N` 常量中，便于扩展。 |
| 内容源变更迁移 | 屏幕分配同时记录频道名称、类别和位置。更新内容源后先按“同类别同名”，再按“同名”恢复；均找不到时才按旧序号选择，并将超出新列表长度的位置从尾部夹紧。 |
| README / Changelog | README 按用户提供的新产品说明更新并新增英文版；Changelog 新增 v1.5 条目。 |

## 后续维护要求

后续修改应以 `tv-versions/tv-app-v1.5.html` 为唯一产品源文件。修改后先在本地浏览器验证，执行 JavaScript 语法检查，然后重新生成 `tv-app-v1.5-worker.js` 部署包装。不要直接在 Cloudflare 中把 Worker 包装当作主源文件编辑；每次部署都要打开生产地址检查版本、播放、设置窗口和控制台错误。
